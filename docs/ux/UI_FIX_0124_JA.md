# v0.12.4 見つけられない操作とスクロール不具合への対処

## 目的
ユーザーの実機報告を基に、PMX/VMD登録、GLB/VRMプレビュー、およびコンビネーション操作の発見性と到達可能性を改善する。

## 変更
- 上部に「＋ PMX / VMDを登録」と「▶ GLB / VRM素材を見る」の入口を設置。
- PMX/VMD画面の入力欄を枠付きで明示し、選択→保存→再生の順序を記載。
- 統合素材画面ではGLB/VRMプレビューを長い素材リストより前に移動。素材リストは開閉と内部スクロール対応。
- コンビネーションの追加/再生/お気に入り操作を上部に配置し、履歴・変換設定・登録一覧を独立スクロール領域に収納。
- 追加操作後に一覧と情報領域へスクロール誘導。

## 既知の制限
- UI構造の改善であり、PMX/VMDの全形式に対する読込成功を保証するものではない。
- 統合GLB/VRMの既存モーションをFBX専用チェインへ自動変換する処理は未実装。操作上の失敗は引き続き診断ログ対象。
- 元のGLB/VRM描画、3画面比較、VRMリターゲティング、PMX/VMDの実モデル試験は実機確認待ち。
- WebMCP/標準MCPの既存操作を変更せず、UIの入口とレイアウトのみ改修した。

## 実機受け入れチェック
1. PMX/VMD登録ボタンを押して、A/B PMX・素材・VMD選択欄が見える。
2. 中央「統合素材」画面で再生ボタンと比較操作が長い素材一覧より先に見える。
3. 右側で追加/再生ボタンが固定され、履歴・VMD変換設定・登録一覧までスクロールできる。
4. FBX登録済みのモーションを選び追加し、登録一覧の増加が見える。
5. PMX/VMDアップロードの成功/失敗をログで確認する。
