# v0.16.7 実モデル初期骨格位置の読み取り基盤

## 今回実装
- GLB/VRM のスキンジョイントから親子ノード階層、ローカル変換（TRS/行列）を解析し、初期ワールド位置を算出。
- VRM 0.x / 1.0 の humanoid bone 役割をノードIDへ対応付け。
- PMX の各ボーンに親ボーン基準の `local_offset` を付加。
- 既存の骨格解析 `inspect` API/MCPが返す `metadata.bones_detail` を拡張。元データは読み取り専用。
- 循環階層、無効なジョイント、数値異常をエラーとして拒否。

## 対応外・品質上の制限
- FBXは従来のBlender抽出経路を維持（改修なし）。
- glTF `inverseBindMatrices`、スキン変形時のバインド姿勢、PMXローカル軸、PMX/VRM間の倍率と左右軸変換は未補正。
- 実PMX/VRMにアニメーションを書き込む処理、足IK適用、VMD出力の視覚検証は未実装。
- 画面に専用の初期姿勢校正エディターはまだない。既存の骨格解析結果として利用可能。
- テスト61件は合成GLB/VRMの計算と既存Python回帰を中心とする。Windowsブラウザ、実PMX/VRM、標準MCPの操作試験ではない。
