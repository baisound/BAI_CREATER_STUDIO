# v0.16.22 実GLB/VRM基準姿勢×回転サンプルの数値プレビュー

- 登録GLB/VRM両モデルの親階層を含めた基準回転を利用し、**利用者が与えた回転デルタサンプル**を、役割別に共通ワールド基準で数値変換する。
- モデル・モーションの変更、VMD書込、IK、自動校正は実行しない。
- 元と先の座標規約が確認されていない場合は400を返す。反転・非均一スケール・せん断を持つ役割はスキップする。
- 入力は最大2000件、リクエスト上限512KiB。未対応役割はunmappedを返す。
- UI、HTTP、WebMCP、stdio MCPから同一機能へアクセスできる。MCP実通信およびブラウザ実操作、実モデル再生は環境依存で未検証。
- **重要**：世界基準での差分試算であり、各VRMボーンに直接設定可能なローカルアニメーション回転を意味しない。glTF内部の入力回転の補間、inverseBindMatrices、VRM Humanoid正規化、階層の動的変化やひねり補正は未対応。
