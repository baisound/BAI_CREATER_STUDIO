# v0.15.2 骨格補正候補生成（検証用）

## 目的
前段の骨格抽出結果を比較し、FBX / PMXで利用可能なボーンの基準位置に基づく**候補**を生成する。元データは変更しない。

## 操作
骨格解析・リターゲティング準備から元モーションと対象モデルを選択して「補正候補を表示」を押す。現在、候補はJSONで表示する。PMXの正しい姿勢に適用する機能やVMD書き出しではない。

## API
`GET /api/retarget/calibration?source=<registered-id>&target=<registered-id>`

共通ボーン役割（左右腕・脚・腰・頭など）の名称候補を対応付ける。PMXのボーン位置とFBXのBlenderで取り込んだ骨頭位置から該当区間の長さを算出し、長さ比の中央値を**スケール候補**とする。単位の相違・姿勢の違いにより誤差があるので自動採用しない。`scale_proposal=null`は計測可能な区間がないことを示す。`axis_metadata`は抽出された軸情報の参照用であり、そこから補正クォータニオンを算出していない。

保存済みモデル別対応表は従来の`/api/retarget/profiles`を使用する。新しい候補はユーザーが確認するまで保存されない。

## AI向け
WebMCPと標準MCPツール `mixamo_retarget_calibration(source,target)` を追加。どちらも読み取り専用。AIなしでも同じ操作が可能。

## 未完成と安全性
- T/Aポーズの差分校正、ボーン軸補正クォータニオンの生成
- ボーン回転の実際の転写、ルート移動の正規化、足IK、接地補正
- VMD出力とPMX実機品質検証
- GLB/VRMは骨格名を取れても、現解析の`bones_detail`に基準位置がない場合は長さを計算できない
- FBX解析にはBlenderが必要。出力がない場合は架空の補正値を返さない
