# v0.16.3 — VMDバイナリ再読込・一致検証

## 実装済み
- `motion_vmd_bridge.convert()` にVMD書き出し直後のバイナリ再読込・データ一致検証を追加。
- `vmd_readback.read_vmd_bones()` でVMD 0002のモデル名・ボーンキーフレームを安全に解析。
- ボーン名（CP932）、フレーム番号、位置、回転、四元数長、破損や切断を検証。
- `convert()` の戻り値と `*.report.json` に `binary_readback` を追加。
- 回転四元数をVMD書き出し前に正規化。
- 新規4件、全体42件のunittestを実行し成功。

## 制限事項
- バイナリ再読込は書き出したデータの機械的な一致確認であり、**PMX/VRMで正しく動くことの証明ではありません**。
- モーションの座標軸差、基準姿勢差、骨格長、実際のIK、親子骨変換は未補正。
- FBXのフルモーション抽出、およびVRM向けGLBアニメーション書き出しは未完成。
- WebMCP/標準MCPの実接続および実ブラウザ操作は今回の検証対象外。
- 元のVMDファイルを上書きする運用ではなく、新規出力パスを指定すること。
