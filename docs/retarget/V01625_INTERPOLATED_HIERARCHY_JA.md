# v0.16.25 GLB回転補間・親階層解析

## 追加内容
- 既存の `/api` 経由の階層回転プレビューの計算を改良。従来の完全一致キーフレームのみから、GLB LINEAR（四元数SLERP、最短回転経路）、STEP（直前キー値）に対応。
- 親のキー時刻と子のキー時刻が異なっても、親が補間可能な範囲では階層回転を評価する。
- 範囲外は外挿せず、スキップの理由を返す。元ファイル、対象モデル、VMDは変更しない。
- アニメーションクリップ、UI/API/MCPの既存呼び出し口を維持。

## 制約
- サンプル時刻は回転トラックのキー時刻の和集合。一定FPSサンプリング・連続再生ではない。
- CUBICSPLINE、translation/scale、アニメーション途中のワールド位置、VRM Humanoid正規化、実モデル転写、足IK、VMD保存は対象外。
- GLBローダーの回転トラック抽出はLINEAR/STEPのみ。matrixノードは従来どおり校正が必要。
- 実ブラウザ表示・Windows実モデル/MCP実通信は未検証。

`python -m unittest discover -s tests -q` 107件成功。親キー0秒と2秒、子キー1秒の中間回転のSLERP/STEP単体・結合テストを追加。
