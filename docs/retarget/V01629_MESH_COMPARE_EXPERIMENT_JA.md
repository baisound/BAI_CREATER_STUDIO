# v0.16.29 GLB/VRM 2体比較（試験）

## 追加
- 転写先GLB/VRMファイルをブラウザ内で2回読み込み、2つの独立したシーンオブジェクトとして左右に配置。
- `/api/retarget/vrm-local-transfer-preview` の戻り値に含まれる `samples` から指定フレームの暫定的なローカル回転を選び、右側モデルの対応ノードにだけ設定。
- 対象フレーム・適用件数・除外件数の表示。操作はオプトインで、元モデルは変更しない。
- Ollama/AIとは独立。既存APIを再利用し、API/MCPの新規機能追加はない。

## 制約
- 三次元表示はブラウザのThree.js/glTFLoaderに依存し、初回取得時には既存importmapのCDNが必要。完全オフライン保証なし。
- 実ブラウザ/WebGL/VRM実機およびVRMスキニングの見た目は未検証。
- PMXは未対応。物理、表情、モーションの同期再生、補間、トラック編集は未対応。
- `samples` はv0.16.28暫定転写の品質ゲートが `blocked_for_production` とした候補。正確なモーションの証明ではない。
- 対象フレームの部分ボーンの一時姿勢比較だけで、プロジェクトやVMDを書き換えない。
- 転写元・転写先の座標系が一致するというチェックは利用者による確認であり、自動校正ではない。

## 検証
- JavaScript構文検査、Pythonユニットテスト、ZIPファイル整合性を実施。ブラウザ実機テストなし。
