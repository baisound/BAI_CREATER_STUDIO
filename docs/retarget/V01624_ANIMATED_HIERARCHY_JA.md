# v0.16.24 GLB親アニメーション階層回転の読取専用プレビュー

GLB/VRMの実アニメーションの回転キーを抽出し、同じ時刻で利用できる親ノードのローカル回転を親→子へ合成して、ソース側のワールド回転を検査します。

* UI: 「骨格解析・リターゲティング準備」の「GLBの親アニメーション回転を解析（読取のみ）」
* API: POST `/api/retarget/glb-clip-hierarchy-inspection`、`source`（登録済みGLB/VRMアセットID）、任意 `clip`、`fps`。
* WebMCP/標準MCP: `bai_retarget_glb_clip_hierarchy_inspection`。
* 安全性: 完全読み取り専用。元モデル、VMD、プロファイルを変更しない。Ollama不要。
* **重要な制限**: アニメーションする祖先のキーフレームがサンプルと完全一致する場合のみ評価します。補間による再サンプルは行わず、不一致は `skipped` に残します。glTFノードのmatrix指定など校正が必要な場合も保留します。
* 出力はソース側の階層回転メタデータで、VRM転写先のローカル回転、IK補正、実メッシュアニメーション、VMD出力ではありません。アニメーション付きの親の平行移動・スケールは扱いません。
* テスト: 合成GLBで親の回転の伝播・親キー欠損・上限・入力不変を確認。実PMX/VRMの描画・スキニングは未検証。
