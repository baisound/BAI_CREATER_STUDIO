# v0.16.41 — GLB/VRM フレーム比較の安全性改善

## 今回実装

- 比較用GLB/VRMが「転写先モデルと同じ」ことをユーザーが明示確認してから比較開始。
- GLBバイナリヘッダー、GLB JSONチャンク、ノード数と全候補キーのノード番号・フレーム・四元数を検査。異常時はプレビューを拒否。
- 読み込んだノード参照を事前キャッシュし、フレーム切替中の非同期読み取り競合を避ける。
- モデルファイル変更時に以前のレポートを破棄し、保存ボタンを無効化。
- 比較用モデル変更／再読込時のResizeObserverを解放。

## 制約・未完了

- ファイルが登録済みターゲットと同じかの照合は**ユーザー確認**であり、暗号学的ハッシュ照合ではない。ノード番号が一致するだけではボーンの同一性は保証できない。
- VRM Humanoidメタデータ、VRM 0.x/1.0正規化基準、メッシュスキニング、再生品質の実ブラウザ検証は未実施。
- PMX直接描画、足IK補正、補正VMDの実モデル検証は未実装。
- 転写候補はあくまで未校正・非破壊の表示。VMD出力は引き続き禁止。
