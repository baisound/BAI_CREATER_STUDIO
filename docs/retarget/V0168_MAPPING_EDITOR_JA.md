# v0.16.8 ボーン対応表エディター

## 追加内容
- 骨格解析パネル内で元ボーンごとに転写先を選択する手動編集UI。
- 名称による自動候補、既存プロファイルの再読込、保存。
- 同じ転写先ボーンへの重複割当は保存前にエラーとして通知。
- 素材選択変更時は表示を破棄し、違う組合せへの誤保存を避ける。
- `/api/retarget/profiles` の既存APIを使用。対応するWebMCP・標準MCPプロファイル機能も引き続き利用可能。

## 制限・次の課題
- 自動候補は名称一致に基づき、基準姿勢・軸・ボーン長・動作適合を保証しない。
- 元ボーン表示は既存`inspect().bones`に従い最大500件。大規模モデルの全骨格編集は未対応。
- プロファイル保存でVMDを書き換えたり、実モデルの動作を補正したりしない。
- 複数ブラウザからの同時編集の競合検知・実ブラウザのE2E検証は未実施。
- 既存の補正候補画面はJSON表示のままで、変換前後の並列3D比較は既存GLB→VRM仮転写表示の範囲。
