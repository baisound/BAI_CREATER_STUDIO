# v0.15.8 足の接地・滑り診断／非破壊補正候補

## 実装範囲
- 足先のワールド空間XYZ位置をフレーム順に受け取る。
- 床高さとの距離から接地候補区間を検出し、区間開始からのXZ移動を足滑りとして測定。
- 許容値より下へ沈んだフレームを列挙。
- 一つの足を基準にしたルートXZ移動補正「候補」を生成。適用はしない。
- HTTP POST `/api/qa/foot-contact`、WebMCP `mixamo_foot_contact_qa`、標準MCP同名ツール、手動UIを実装。

## 入力例
```json
{"ground_y":0,"height_tolerance":0.06,"motion_tolerance":0.025,"samples":[{"frame":0,"position":[0,0.01,0]},{"frame":1,"position":[0.1,0.01,0]}],"propose_root_offsets":true}
```

## 重要な制約
現在は位置サンプルを手入力/ツールから供給する必要がある。PMX・VRMのボーン階層から足の**ワールド座標を自動サンプリングする機能は未実装**。高さ近接の閾値判定であり、力学的な接地の保証ではない。足IKソルバー、左右の足を同時固定する拘束、自然な姿勢補間、VMDへのベイクは未実装。実モデルでの画面・動作テストが必要。

## 完了条件
- 同じJSONに対してUI/WebMCP/標準MCPが同じ結果を返す。
- 非接地区間を滑りとして誤報しない。
- 異常サンプル・同一フレームを拒否する。
- 元FBX/GLB/BVH/VMDを変更しない。
- 次段階でPMX/VRMの足先ワールド座標自動抽出→二足IK→ベイクに拡張。
