# v0.16.17 VRM Humanoid対応プレビュー

## 実装
- VRM 0.x / 1.0のHumanoid roleを、ボーン名やノード番号に依存せず対応付ける。
- 対応ボーン、基準姿勢のワールド座標、欠落ロールを読み取り専用で出力する。
- `POST /api/retarget/vrm-humanoid-preview` に `{"source":"登録済み素材ID","target":"登録済み素材ID"}` を送信する。
- 既存の登録済み素材だけが対象。APIは元のファイルを変更しない。
