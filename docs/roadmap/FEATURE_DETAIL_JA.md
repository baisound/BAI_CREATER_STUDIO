# 機能詳細仕様（機能ID単位）

各項目の「期待動作」は要求から抽出した設計要件です。**実装済みを意味しません**。

## 全機能共通の受け入れ基準

- UIのメニューまたは操作導線が明示される
- WebMCP・標準MCPから機能の取得/操作が行え、同一ロジックを使う
- 正常系・異常系・非接続系をテストし、破壊的操作には確認を設ける
- 入出力とバージョン管理は原本を保持し、制作状態を復元できる
- 実装の有無・検証ログと環境依存を機能IDに紐付けて記録する


### CORE-001
**機能:** AI無しの全機能手動操作  
**優先:** Phase 01  
**依存:** なし  
**確認状態:** 要検証（証拠未照合）

**目的・要求:** AIクレジット・MCP停止時もUI使用可。

**実装チェック:** 手動UI操作、共通API、WebMCPツール、標準MCPツール、設定永続化、Undo/Redo対象、例外/権限処理、テスト、文書を同一IDで紐付ける。

**受け入れ条件:** 指定した入力に対し期待される編集・表示・保存結果が得られ、再起動後に復元でき、元の素材を変更しない。該当する3D/動画変換では実データを使った比較検証を必須とする。
