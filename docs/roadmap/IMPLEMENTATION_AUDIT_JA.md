## 基本検証チェック

- GitタグとHEADが正しい。
- 既存FBX・保存JSON・お気に入りを保持。
- Windows BAT/Linux SHから起動できる。
- UIからの操作とWebMCP/標準MCPの結果が一致。
- 切断中の通常利用、保存、再起動後の復元が成功。
- FBX/GLB/BVH→PMX/VMD、足IK、物理、カメラ、レンダリングは実素材で検証。
