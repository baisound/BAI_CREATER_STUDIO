# 推奨開発順序と依存関係

## あなたの用途からみた優先度

- MMD/PMXへの実用VMD変換とダンスMV制作を最優先する。
- Codexのクレジットが切れても手動で作業できる設計を最初に確立する。
- モーション変換→個別振付・フォーメーション→歌唱・カメラ→動画出力で早く成果を得る。
- クリティカルな品質検査は最終フェーズに集約せず各段階に導入する。

## 依存関係の注意

- 動画出力とJIZURAは早期に入出力形式を固め、3D表現統合は後続とする。
- カメラVMDのF値/焦点距離は標準VMDにそのまま保存できない。拡張JSON必須。
- Ray-MMD/MMEのFXはそのままブラウザで動かない。プレビュー近似とMMDへの設定出力を分ける。
- PMXリターゲット・IK・物理ベイクは別物。自動変換成功と動作の自然さを分離して検証。
- WebMCPと標準MCPを共通APIに収束させ、外部変更の競合・権限制御を必須化。
