# v0.5 最短制作経路 — 2026-10-23 Owner指定

## 目的と適用順

PR #65でmainに取り込んだ`/studio/v05/index.html`を今後の制作UIとして育てる。既存Studioで登録・保存された素材と作品を原本のまま利用できるよう接続し、**素材登録→同じ作品のタイムラインに配置→プレビュー→書き出し**を最短で通す。この経路に必要な接続と、下表のOwner指定機能を他の拡張より優先する。旧UIは移行中の作業と既存データの入口として保持し、v0.5への接続を検証する前に削除しない。

この文書は実装の**優先順と終了条件**を更新する。機能IDの完了状態、既存の要件内容、証拠のない実機合格を変更しない。v0.5の総合進捗37%は2026-10-23時点の暫定評価であり、枝番61やmainへのマージを完成と解釈しない。

順1〜3は最短の縦断経路として、後段の全機能完成を待たずに通し確認する。順4のPMX表情・口は、その後の専門機能で最優先にする。順2〜7は同じ作品ID、素材参照、シーン、時刻、保存状態を共有し、画面だけの独立したデモを完成扱いにしない。途中で必要な依存修正は元の要件IDと理由を記録する。

2026-10-24の順1途中経過：既存素材一覧、画像の新規登録、実IDの配置保存、小型GLBの既存3D表示・再読込を隔離Chromeで確認した。素材管理の高度な参照操作は折りたたみ、固定診断欄と折り返しメニューの重なりを修正した。対応形式すべての実見本、音声・動画の同時刻再生、出力までの通し条件は未達。検証範囲は[素材接続記録](../v05/ASSET_LIBRARY_BRIDGE_20261023_JA.md)を参照する。

同日の後続作業で、実動作プレビューのフレーム表示・再生操作を既存の音楽・ダンス画面の実クロックへ接続し、素材管理のデスクトップ幅では中央一覧だけをスクロールするよう修正した。音声・モーションの共通作品配置と書き出しは未接続のまま。[試験記録](../v05/LIVE_TRANSPORT_AND_LIBRARY_SCROLL_20261024_JA.md)と[カテゴリー別の横断Issue #69](https://github.com/baisound/BAI_CREATER_STUDIO/issues/69)を参照する。

同じく音声画面の表示用波形・再生・EQ・ミキサーを整理し、登録WAV/MP3の実波形、30fps試聴、開始/頭出し位置の保存再読込を既存の音楽・ダンス共有配置へ部分接続した。v0.5作品ごとの音声配置と映像への出力はまだ未接続。[音声画面の試験記録](../v05/AUDIO_WORKSPACE_20261024_JA.md)を参照する。

書き出し範囲の準備として、v0.5作品の保存済み配置と作品FPSから最終フレームを計算し、タイムラインの保存済み再生位置からIn/Outをフレーム単位で記録できるようにした。未設定時は0〜最終フレームを表示する。実動画レンダーと音声多重化は未接続であり、書き出し画面もその状態を示す。[範囲保存の試験記録](../v05/RENDER_RANGE_20261024_JA.md)。

## 共通の完了ゲート

各段階で手動UI、共通API、WebMCP、標準MCPの対応範囲、保存・再読込、Windows/Linux、隔離試験、実素材の画面・音・出力、失敗時の原本保持を分けて記録する。未対応は画面にも台帳にも明記する。最低1件の既存登録素材と1件の新規登録素材を同じ作品で通し、旧データのハッシュを変えずに完成物へ到達するまで「最短制作経路完成」と呼ばない。

PMX顔の編集はモデルの既存モーフ値とタイムラインキーを対象とし、アバター制作の骨・ウェイト操作を自動的に許可しない。画像・動画の成果物を新たに制作した場合はOwner指定のEagle登録規則を適用する。検証用の大量連番や入力資料を成果物扱いしない。

## 既存の計画との関係

旧`P2→Phase E→リップシンク・表情・歌音声→F→MMDエフェクト→C→D残り→G残り→H`は2026-10-20時点の順序として履歴に残す。2026-10-23以降の**実施順**は上表を優先する。未完成のP2/Phase E/F項目は必要な段階に割り付けて進め、全機能の完了を前段のブロッカーにしない。MMDエフェクト、追加の複数ダンサー演出、分析・自動提案など最短経路に不要な拡張は順1〜7の後に扱う。既承認の機能を取り消す意味ではない。

進捗正本は従来の機能台帳、Phase E状況JSONとv0.5の進捗記録であり、この優先順だけでは実装完了・Owner採用を示さない。Issue #63に画面間のシーン・時計接続を、Issue #37に素材登録を記録する。
