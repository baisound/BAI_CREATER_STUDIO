# モーション素材プレビューと3Dビュー操作（2026-10-21）

依頼Issue: [素材プレビュー #28](https://github.com/baisound/BAI_CREATER_STUDIO/issues/28)、[3D操作 #29](https://github.com/baisound/BAI_CREATER_STUDIO/issues/29)。旧UIカメラの正面撮影・再生・周回の調査は[別Issue #30](https://github.com/baisound/BAI_CREATER_STUDIO/issues/30)。

## オーナー要望

- SCR-08 のモーション素材は形式アイコンだけでは動きが伝わらない。FBXなどの実際の動作が見えるサムネイルと再生プレビューを提供する（MOTION-016、P2-WP-02/05）。
- 3Dビューの操作を一般的な制作ソフトの中ボタン操作にそろえる（P2-WP-04/05）。[Blenderの公式ナビゲーション説明](https://docs.blender.org/manual/en/3.2/editors/3dview/navigate/navigation.html)に合わせ、中ドラッグは回転、Shift＋中ドラッグは画面平面で左右・上下移動、Ctrl＋中ドラッグとホイールは前後移動とする。左ドラッグ回転・右ドラッグ平行移動は互換として残す。

## 検証対象

- 3Dの新UIは `studio/js/viewport/three-host.js` の共通ホストをSCR-05/06/12/13が共有する。カメラ旧画面は `camera_3d.js` の自由視点が別実装。撮影カメラのキーやレールは操作対象外。
- 素材は現在60件（FBXモーション35件、GLBモーション10件、VMD2件ほか）。カードごとに常駐WebGLを作らず、プレビューの読み込みと描画は選択・表示中の素材に限定する。キャッシュと読み込み失敗表示を設け、原本へ書き込まない。
- FBX/GLB/VRMのモーションはファイルに含まれるモデル・骨・クリップを使用する。VMDは登録済みPMXとの組み合わせが必要で、使用するモデル名を画面に明示する。合わない素材は理由を表示する。

## 受け入れ条件

1. 新UIの各3D画面で中ドラッグ回転、Shift＋中ドラッグ平行移動、Ctrl＋中ドラッグ／ホイール前後移動が効き、操作を画面内で読める。視点操作は制作データを変更しない。
2. SCR-08の動きのある素材を見分ける画像が表示され、詳細では動作再生・停止・シークができる。再生中に別素材を選ぶと古いプレビューは破棄する。
3. 実在FBX/GLB/VMDで画面を確認し、元ファイルと既存ウェイトを不変に保つ。GPU実機性能は別途未検証として記録する。

設計・調査：高性能モデル区分。実装・テスト：標準モデル区分。

## 2026-10-21 実装と検証（Issue #28・#29）

- Issue #29：共通3Dビュー、旧カメラ自由視点、旧統合ビューの中ドラッグ操作と案内を実装。Chrome/SwiftShaderで `studio-p2-viewport.test.cjs` 19件、`legacy-ui-layout.test.cjs` 1件に合格。物理マウス・GPUでの操作感は未検証。
- Issue #28：SCR-08の表示中カードから順に、開始・中間・終了の骨格姿勢画像をメモリ内で生成。FBX/GLBは素材内のモデルとクリップ、VMDは登録済みPMX（既定A、画面で変更可）で再生する。右の詳細欄で再生・一時停止・シーク・全身表示・クリップ選択を操作できる。統合登録のFBXも既存の読み取りAPIから取得する。古い読み込み結果は選択変更時に破棄し、制作状態は更新しない。
- 実素材でFBX・統合FBX・複数クリップGLB・VMD＋PMXの表示と再生をChrome/SwiftShaderで確認。GLBの変形後の頂点範囲でカメラを合わせ、一覧名と一致するクリップを既定で選ぶ。PMXとVMDのSHA-256は着手前後で同じ。画像はオーナー確認画像フォルダに保存し、公開できるFBX画面をIssue #28へ直接添付した。
- 既存の隔離ブラウザ・API・台帳検査 `node tools/run_evidence_tests.mjs` は120/120合格、実データ5ファイルのハッシュ不変。
- 残る確認：GPU実機の表示速度と多数カードの長時間閲覧、全てのFBX/GLB/VMDの読み込み、物理マウスでの操作感、オーナーによる画面採用。サムネイル生成は画面内の表示機能であり、元素材や制作状態への保存・共通API/WebMCP/標準MCPの新設はこの変更に含めない。機能台帳は「要検証」のまま保持する。
