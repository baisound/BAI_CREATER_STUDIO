# F直後に前倒しする D/G 横断詳細設計（第1稿）

**順序:** 2026-10-20の後続所有者決定に従い、P2→E→リップシンク・表情・歌音声配置（AUDIO-001）→F→MMDエフェクト→C→D残り→G残り→H。MMDエフェクトはFの後に維持する。

## リップシンク（LIP-001〜008）
- 入力SRT/歌唱ステム/既存VMD、任意の手動音素・口形キー。音声AIや解析が未利用でも**手打ちだけで成立**。
- 口形の意味層を`A,I,U,E,O,Closed,Rest`などの中立チャンネルとして保存し、VRM/PMXの利用可能なモーフへ明示マップする。未対応モーフは警告し、勝手な代替を保存しない。
- 時刻は共通フレームで編集。音素境界・長音・閉口・子音先行オフセットは非破壊補正トラック。音声波形/字幕と口形を重ね、適用前後をAB比較。
- 元口形/推定口形/人手修正を別レイヤー保持。VMD書出時は書出可能なモーフ・補間の制約と欠落情報をレポート。

## 表情（LIP-009〜011）
- 眉/目/まばたき/視線/感情プリセットを口パクとは独立に制御し、ブレンド優先順位と排他セットをモデルごと設定。
- 表情ベース→演技オーバーライド→瞬き/視線→手動上書き、の順で評価し、モーフ重みは検証・制限して破綻を警告。身体モーションとの同期は共通時刻で保つ。
- 口表情の無いVRMでは対応なし表示＋モーフ追加/外部修正導線。モーフの存在や変換品質を推測しない。

## MMDエフェクト（RENDER-011〜015周辺）
- **互換を分類**: (a)再現可能なネイティブ効果、(b)見た目を近似する効果、(c)非対応。MMEの.fxをWebGLにそのまま実行できるとは約束しない。
- FXアセットレジストリ: id, source, license, parameters, supportedEngine, fallbacks, renderParityStatus。効果ごとに画面とレンダーの対応表を維持。
- 承認済みの初期FX内蔵対象: Bloom/AutoLuminous風発光、MotionBlur。後続の所有者指示で、見た目が変わる霧、細かな塵、舞う桜、きらめき、影の強調、ボケ／ブラーを優先して検証する。奥行き霧と粒子は `RENDER-013`、影とFXのブラー等は `RENDER-012`、FX効果別の対象・強度・順序は `RENDER-014` に紐付ける。ピントのボケ／DOFはカメラ `CAM-005/E-FOCUS-01/02/F-DOF-01` が所有し、FXは参照・重ね合わせを検証する。トゥーン陰影・リムライトはこの優先指示による採用候補として扱わない。Ray-MMDは異なるシェーダー体系を前提に、登録・MMD向け設定出力から始める。詳細は [`A3_VISUAL_EFFECT_PRIORITY_JA.md`](../specs/A3_VISUAL_EFFECT_PRIORITY_JA.md)。
- エフェクトはシーン/被写体/素材別に付与し、ON/OFF、強度キー、品質段階、プレビュー・レンダリング差分テストを持つ。

## 共通API・MCP・受入
- `createLipTrack`, `mapMouthMorphs`, `setPhonemeKey`, `previewLip`, `createExpressionTrack`, `setExpressionKey`, `attachEffect`, `setEffectParamKey`, `compareFxRender`を手動UIと同じサービスへ接続。
- 非破壊保存/Undo/Redo、モデル固有対応の明示、音声ずれと書出欠落の診断を必須にする。
- 実VRMと実PMX（利用可能な場合）で対応モーフを列挙し、基準音声とフレーム単位の口形・表情・FX結果を検証。現時点では**設計のみ**。
