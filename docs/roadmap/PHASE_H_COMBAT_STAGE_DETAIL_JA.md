# Phase H 格闘・演出・ステージ 詳細設計 v1

対象 DANCE-008〜012、LYRIC-008〜010、MOTION-021〜022（格闘関連は多Phase間依存）。E/Fをブロックしない。

## 格闘
`InteractionPair {attacker_id, defender_id, attack_clip_id, reaction_clip_id, contact_events, root_alignment, safety_distance}`。拳・足・武器・掴み対象の接触点をローカル骨参照＋ワールド変換で保存。攻撃開始・接触・反応・回復のイベントをタイムラインで合わせる。打撃や衝突の見た目を優先する編集と、実物理判定は区別。

2026-10-20 所有者決定 `O-COMBAT-01=A`: 同一フレームの接点距離・方向・時刻差と映像オーバーレイを併記する。数値のしきい値は警告用とし、演出の合否や精密物理・人物安全を自動断定しない。骨欠損・座標変換失敗は未評価と表示する。[B4決定記録](../specs/B4_COMBAT_STAGE_DECISIONS_JA.md)を参照。

## ステージ
`.blend/.fbx/.glb`の取り込みは単位・座標・階層・マテリアル・テクスチャの変換ログを残す。PMX出力は変換可能な幾何・マテリアルに限定し、Blender modifier、物理、ノード全互換を保証しない。大型ステージは空間チャンクとLOD、接地床コライダ、扉の可動ピボット、ギミックイベントを個別管理。

2026-10-20 所有者決定 `O-LYRIC-03=A`: `LYRIC-008` は変換前に対応／欠落要素を一覧化し、利用者の明示確認後だけ対応部分を別名PMXへ部分出力する。結果は `partial` とし、欠落レポート・元資産hash・変換器版・出力hashを保存する。既存PMXと原ステージは不変。PMX再読込と実MMDの代表ステージ確認まで互換を未検証とする。[B3決定記録](../specs/B3_LYRICS_STAGE_DECISIONS_JA.md)を参照。

`O-COMBAT-03=A`: B3で登録した実在可動ピボットと状態キー・時刻付きイベントを連動する。扉等の登録済み可動物を対象にし、ピボット欠損・可動範囲外・循環イベントを拒否する。未承認のゲームロジックを加えず、原ステージを変更しない。

## MMD物理ベイク
シミュレーションのバージョン/seed/時間刻み/入力ハッシュを記録し、衣装/髪/身体の部分再計算をサポート設計。ベイク結果は新規レイヤーとして保存し、元の生データは保持する。異常貫通やピクつきはレポートで可視化。

`O-COMBAT-02=A`: モデル・モーション・物理設定・対象部位・区間のhash、solver版・seed・時間刻み・環境を照合し、同条件の代表再計算で出力一致を確認した環境だけ既存ベイクを再利用可とする。条件差・再現性未確認は失効または再計算し、異なるOS/GPUの一致を推測しない。`MOTION-021` の台帳状態「要検証」と新UIの未実装表示は今回の判断だけで変更しない。
