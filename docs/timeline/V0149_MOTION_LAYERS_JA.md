# v0.14.9 非破壊モーション補正レイヤー（実験版）

## 概要
v0.14.8のタイムライン再生に、モデルAのFBXボーン回転の補正レイヤーを追加。元素材は変更しない。

## UI
タイムライン編集の下に「非破壊モーション補正レイヤー」。レイヤー追加、ボーン名、ON/OFF、現在フレームへのキー追加、XYZ回転角（度）編集、キー削除、保存、復元。入力はボーン名を直接入力する初期仕様。

## API/MCP
GET/POST `/api/motion-layers`。形式は `{ "schema":1,"layers":[{"name":"腕","bone":"mixamorigRightArm","enabled":true,"keys":[{"frame":0,"x":0,"y":0,"z":0}]}]}`。WebMCP・標準MCPツール `mixamo_motion_layers_get` / `mixamo_motion_layers_set`。

## 補間と既知の制約
キーフレーム間を線形補間し、元のFBX AnimationMixerによる姿勢評価の後にボーンのXYZローカル回転へ相対加算する。原本モーションの非破壊性を維持。対象はFBXモデルAのタイムライン再生のみ。厳密な四元数ベース補間・IK・ポーズ変更の自動検出・PMX/VRM・VMD書き出し・非再生状態でのキー編集プレビューは未実装。未知のボーン名は安全に無視されるがUIでの候補提示は未実装。これらを完成と報告しない。

## 回帰・受け入れ基準
Python/JS構文・HTTP保存復元・OFF切替・キー補間を検査する。実際の3D姿勢はWindows実ブラウザで別途確認が必要。MCP経由の更新は再読込または次回同期が必要な場合がある。
