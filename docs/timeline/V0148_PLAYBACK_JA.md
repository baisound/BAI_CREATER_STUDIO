# v0.14.8 タイムライン実再生（基礎）

## 内容
- タイムラインに設定した開始フレーム（30fps基準）、速度、長さを実FBXモデルAのプレビューに反映。
- 重なったクリップは開始時刻の遅いものを優先。切替時に設定ブレンドフレームに基づくcrossFadeを試行。
- 再生、停止、シークの手動UIを追加。既存 `/api/timeline-editor` 保存、WebMCP/標準MCPからの設定更新を維持。
- 非破壊：素材FBXは上書きしない。

## 制限・注意
- 実FBXモデルAと対応モーション登録が前提。PMX/VRMへのタイムライン直接適用、VMD出力は未実装。
- ルート位置の加算は簡易方式。重なりクリップの厳密なルートブレンド、足IK、姿勢一致は未完成。
- クロスフェード時にmixerの時間を直接調整する実装はブラウザ実機で品質未検証。
- MCPはクリップデータ更新に対応。再生/停止/シーク専用ツールは未実装。

## 手動確認
1. FBXモデルAとモーションを登録。タイムラインに2クリップ追加。
2. 開始F、速度、長さ、補間Fを変更。
3. 「▶ タイムライン再生」を押し、再生状態・時刻とモデル動作を確認。
4. 「■ 停止」とシークを試す。ブラウザ更新後に値が保存されているか確認。

## 回帰
コンビネーションの再生・停止、お気に入り、制作状態保存、診断ログを確認。
