# v0.16.0 手動ポーズ補助・IK基礎仕様

## 提供範囲
- 2セグメントの解析IK（XY平面）を追加。腕と脚の目標位置をドラッグして関節座標を算出。
- 元FBX・PMX・VRM・VMDへの適用は**未実装**。実モデル操作と誤認させないようUIに明記。
- サンプルのIK目標位置、フレーム番号を data/pose_ik_last.json へ原子的に保存。
- UI: `pose_ik_ui.js` / API: GET `/api/pose/last`, POST `/api/pose/solve`, POST `/api/pose/save`。
- WebMCPと標準MCP: `bai_pose_ik_get/solve/save`。
- Ollamaを一切呼ばず、AI未接続で動作。入力の距離が届かない場合は腕・脚の可動距離に制限し通知。

## 次工程
対象PMX/VRMのワールド座標の骨格へIKを適用するには、ボーン軸、スケール、関節制約、極方向、コンストレイント、足接地を統合する必要がある。現在はプロキシへの姿勢計算のみ。

## UI方針
独立したポーズ補助セクションで操作。選択→ドラッグ→確認→保存。ホバー説明と失敗メッセージあり。今後は固定3Dビューに組み込む。
