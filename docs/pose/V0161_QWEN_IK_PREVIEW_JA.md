# v0.16.1 Qwen → 手動IKプレビュー

日本語指示をQwenで列挙型の制約にし、既存2D IKターゲット位置を安全に増分変更して検査する試作です。

- 手動IKポーズ補助の現在の設定（未保存でも可）を使います。
- AI Managerの「IKプレビュー生成」は保存データを読み、Ollamaに問い合わせ、**2Dプロキシの計算結果のみ**返します。「IK画面で確認」を押すと、その提案を編集画面へ読み込みますが保存しません。
- 扱う操作: 右腕/左腕/右脚/左脚の上下・前後・保持。各移動幅は仮の座標0.15単位です。左右や実モデルの軸への正規化は未実装です。
- AIが回答しても、自動適用・自動保存・VMDキーフレーム作成・PMX/VRM変更はしません。
- 未対応の部位・動作は ignored に記載し、実行しません。
- Ollama未起動時はHTTP 503で応答し、手動IK操作に影響しません。
- API: POST /api/ai/ik-preview には text と baseline（手動ポーズと同じ形式）を渡します。WebMCP/標準MCP: bai_ai_ik_preview。
- テストはスタブ制約による単体テストが中心。Windows上の実Qwen推論、UI操作、実PMX/VRMへの反映は未検証・未実装です。
