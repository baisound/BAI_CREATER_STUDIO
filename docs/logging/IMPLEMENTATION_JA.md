# Phase 00 診断ログ実装仕様

- JSONL形式、UTC時刻、イベント、レベル、フィールドを記録。
- `data/logs/server.jsonl`、2MiB到達でローテーション、バックアップ5世代（環境変数 `MIXAMO_LOG_MAX_BYTES` で容量を変更可能）。
- GET `/api/diagnostics/recent?limit=100` で最新ログを取得（上限300件）。ブラウザの「診断ログ」タブから閲覧・コピー可能。
- POST `/api/diagnostics/client` は同一オリジンのブラウザ障害レポートを受信。4KiBのペイロード制限。WebGL Context Lost、ブラウザ例外・Promise拒否が対象。
- リクエスト本文、トークン、URLクエリ、素材ファイル内容はログに含めない。一般文字列中の機密値はベストエフォートでマスク。共有前に必ず内容を確認。
- APIログはメソッド・パス・HTTPステータスのみ。ファイル名を含むパスが一部残る可能性があるため、共有前のレビューが必要。
- 制約：保存日数による自動削除、診断ZIPの自動匿名化、Blender/FFmpeg子プロセスの完全なログ収集、MCP個別ツールの詳細記録は今後の課題。
- ログ閲覧APIはローカルユーザーに開放されます。127.0.0.1 バインドを維持し、外部公開しないでください。
