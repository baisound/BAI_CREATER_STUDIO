# 新規機能候補（P4・未承認／実装禁止キュー）

## 区分ルール
- `existing_audit`: 既存機能またはPhase内構想があるためソースを調査する。新規扱いしない。
- `new_candidate`: 25画面に描かれたが現行ソースで確認していない機能。**未確認=未実装と断定しない**。
- `design_only`: 美術的な表現・架空データ・画面装飾であり実装要件に昇格しない。

## 重複・不一致注意
- SCR-08アセット管理とSCR-11画像管理は別々の素材データベースを作らず、同一ID/索引に統合。
- SCR-02,03,06,14,15,16はカメラ・フォーカス・VMD・シーケンスの横断領域。カメラ実装を複製しない。
- SCR-17のAOV/EXR/GPUなどは現行ブラウザ描画エンジンの対応状況を必ず確認。
- SCR-19のAI接続状態・GPU負荷・進捗率などの静止画像サンプル値は**架空**。未接続なら未接続と表示。
- SCR-22ワークフローの自動操作は既存承認ロードマップに新たに混入させない。
- SCR-15は以前の誤生成を避けた専用構成図。ファイル由来を確認。
