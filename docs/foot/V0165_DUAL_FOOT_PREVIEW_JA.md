# v0.16.5 両足の接地・ルート補正候補プレビュー

- 目的: 左右の足が同時に接地している際、片足の補正案だけで他方が滑る事態を避ける。
- 入力: `left_samples`/`right_samples` はそれぞれ `[{"frame":0,"position":[x,y,z]},...]` と床高さY。同じ座標軸・単位・フレーム原点であることが必要。
- API: POST `/api/qa/dual-foot-preview`。応答は接地レポート2件とフレーム単位の非破壊候補。
- 同時接地フレームは左右のルート補正要求の差を測定し、既定0.05を超えたら `conflict:true` として移動候補をゼロに保留する。許容範囲内なら平均値を採用し、既定0.2以下に制限する。
- 片足だけ接地したフレームでは、その足の水平補正候補を使用する。
- `applied:false`。実IK補正・PMX/VRMボーン・VMDへの適用は**未実装**。物理や接触力は計算しない。
- 手動UI、WebMCP `bai_dual_foot_preview`、標準MCP `bai_dual_foot_preview` は同じAPIを利用。
- Ollama接続の有無に依存しない。元データを更新しない。
