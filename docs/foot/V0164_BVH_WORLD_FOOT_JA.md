# v0.16.4 — BVH実モーションの足ボーン追跡・接地診断

## 追加事項
- `bvh_foot_world.py`: BVHの階層、OFFSET、位置/回転チャンネルをソース記載順で合成し、指定した足関節のワールド座標をフレームごとに算出。
- `POST /api/qa/bvh-foot-world`: `{ "bvh_text": "...", "foot_bone": "LeftFoot", "stride": 1, "ground_y": 0 }` を受け、足位置サンプルと接地/滑り/貫通診断を返す。
- 手動UIの「足の接地・滑り診断」からBVHファイルを選択して実行可能。
- `bai_bvh_foot_world_qa` をWebMCP・標準MCPへ追加。

## 制限と誤判定の回避
- **実PMX/VRMの足IK、床コンストレイント、補正済みVMD出力は未実装。**
- 座標はBVH元データの軸と単位。接地診断はY-upを前提とするため、元BVHがZ-upなら軸変換が別途必要。
- 足関節の位置は足裏の接地点ではない。モデルごとの足裏オフセット・床基準の較正が必要。
- ファイルは最大2MB、ボーンは最大512、フレームは最大10000。原本ファイルは書き換えない。
- OllamaやRAGを使用せず動作。

## 確認
- サンプルBVHから親子回転・ルート位置の座標算出、欠落ボーン、破損、間引き検査。
- Python全体テスト、JS構文検査。実モデル、ブラウザ操作、MCP実機でのE2Eは別途検証。
