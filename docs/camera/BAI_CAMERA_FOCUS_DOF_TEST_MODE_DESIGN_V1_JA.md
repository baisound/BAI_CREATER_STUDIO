## 1. 目的と定義

撮影カメラが選択した**被写体の狙った部位**（例: 顔・左右眼・胴体）にピントを合わせているか、また動く被写体が被写界深度から外れないかを、撮影前・再生中に把握する。`focusDistance` はカメラのセンサー面からフォーカス面までの距離（単位 m）。被写体の位置は当該フレームのポーズ評価後のワールド座標を使用する。

**重要**: ピントは焦点面で最良となり、前後へ連続的に甘くなる。被写界深度の「合焦範囲」は許容錯乱円に依存する近似であり、厳密な二値判定ではない。テストモードは以下を別々に表示する。

1. **幾何学的フォーカス誤差**: カメラの光軸方向に測った注目点と焦点面の距離差（m）。視野外・カメラ背後も別表示。
2. **推定被写界深度**: センサー幅、焦点距離、F値、焦点距離、許容錯乱円から算出した近点・遠点、過焦点距離。焦点面からのずれと近似的なボケ量を表示。
3. **実画像プレビュー**: DOF実装と実モデル描画が使用可能なときに、右側で実際の見た目を表示。描画不能時は「視覚検証未対応」と明示し、計算だけで高画質な合焦を保証しない。

## 2. 画面構成とモード

撮影画面右上に「フォーカステスト」トグル。通常編集・テストの切り替えは**表示オーバーレイのみ**で、カメラ位置・キー・レンズを変更しない。

- 左 Scene View: 撮影カメラ、前方フラスタム、焦点面、近点/遠点面、被写体の注目点を3Dガイドとして表示。深度ガイドは個別ON/OFF可能。モデルの遮蔽が強いときは半透明・線画に切り替え。
- 右 Camera View: 被写体の実映像と、任意で深度カラー表示（通常映像／カラー／左右比較／ブラー差分）。ガイドの映り込みは**書き出し動画には含めない**。深度表示はレンダラ対応時のみ有効。
- 下段: フォーカス距離、対象深度、差分、推定近点/遠点、判定、センサー・レンズ条件、レンダラ状態を常時表示。色だけでなくテキスト＋数値で状態を説明。
- 操作: `F` は Scene View の選択対象フレーミングと競合するため、フォーカステスト切替に割り当てない。ボタンと設定可能なショートカットを用意する。
- 注目点を顔ボーン・左右眼・全身中心・手動ピックから選択できる。ボーンがない場合、BBox中心へ代替したことを明示。左右眼の複数点判定では最悪値も表示。

## 3. カラー区分（プレビュー補助・凡例固定）

| 状態 | 表示 | 条件 |
|---|---|---|
| 手前ボケ | マゼンタ | 注目点が推定近点より手前 |
| 合焦近傍 | 青 | 注目点の焦点面誤差が指定した厳密許容値以内 |
| 許容範囲 | 緑 | 推定近点〜遠点内。ただし厳密許容域の外 |
| 奥ボケ | 黄／橙 | 注目点が推定遠点より奥 |
| 判定不可 | 灰色・斜線 | 対象不明／座標未解決／カメラ背後／数値不正／深度データ不足 |

青と緑はどちらも厳密な「シャープ保証」を意味しない。動画の色分けを参考とするが、色の閾値・凡例は BAI 独自の明示仕様。カラーユニバーサルデザイン向けに模様と文字を必ず併用。

## 4. 計算仕様

- レンズデータ: `focalLengthMm`, `fNumber`, `sensorWidthMm`, `focusDistanceM`, `circleOfConfusionMm`。センサー幅の初期値は36mm（ユーザー変更可能）、CoC初期値は0.03mm（フルサイズ相当の便宜的デフォルト、用途に応じ変更）。必ず単位を記載。
- 幾何学: 被写体ワールド位置をカメラ座標へ変換し、前方軸への投影深度 `zM` を算出。視野外は警告を併記。被写体までのユークリッド距離のみで判定しない。
- 薄レンズ近似: `H = f²/(N*c)+f`、`Dn = H*s/(H+(s-f))`、`Df = H*s/(H-(s-f))`（分母 <= 0 の場合 `Infinity`）。式では `f,s,H,c` を mm に統一。`s <= f` や非有限値をエラー扱い。近点/遠点はm表示。無限遠境界は明示。
- 許容誤差: 焦点面との差の「厳密許容値」はユーザー指定可能な別パラメータ（初期値は暫定0.02m。レンズ条件に依存しない目安で、フォーカス精度の保証ではない）。DOF範囲と混同しない。
- シネマDOFレンダラの実際のボケと薄レンズ近似には差があり得る。使用レンズモデル、ポストプロセス、解像度、レンダラスケールを診断結果に記録する。
- カメラアニメーション・モデルアニメーションの両方を**同一フレーム時刻**で評価。切替ショット、被写体切替、追従先変更時はキャッシュ無効化。

## 5. 操作・時間方向の検証

- 現在フレーム診断: 即時更新。焦点距離/F値/焦点距離(ピント位置)/対象が変われば再評価。
- 範囲診断: 指定開始〜終了フレーム、指定間隔（既定1フレーム）を評価。最小・最大の焦点面誤差、範囲外フレーム、連続逸脱区間、対象見失い区間を一覧・タイムライン色帯で表示。処理中止・進行状況・長尺サンプリング制限を設ける。
- 「フォーカスを対象に合わせる」アクション: 現フレームで対象深度を計算し、**プレビューのみ**更新→ユーザー確定で既存のトランザクション規則に従いカメラのフォーカス距離キーを1件更新。自動キーON/OFFに従う。テストトグル自身はキーを作らない。
- AF追従モードは別機能として扱い、被写体移動に伴う自動キー生成を初期OFFにする。追従遅延・平滑化・外れ値・対象消失時の挙動は実装時に別途定義する。
- カメラVMDはフォーカス距離/F値などを直接表現できないため、既存設計に従ってサイドカーJSONに保存。読み戻し・書き出し検証では紛失検出。

## 6. 永続化・API・MCP（設計上の名前、現状未実装）

永続データ `CameraFocusTestSettings { enabled, viewMode, targetId, targetMarker, sensorWidthMm, circleOfConfusionMm, strictToleranceM, showNearFarPlanes, rangeScanStepFrames, ... }`。`enabled` と視覚設定はユーザーUI状態として保存し、撮影キー情報と分離。テスト結果は派生データで原則保存せず、必要なら実行条件・タイムスタンプとともに明示的にエクスポート。

| 共通アプリサービス/API案 | 意図 | 編集可否 |
|---|---|---|
| `camera.focus_test.get_settings` / `set_settings` | 画面・条件の参照と変更 | 撮影キー不変 |
| `camera.focus_test.evaluate_frame` | フレームごとの幾何/近似診断 | 読取専用 |
| `camera.focus_test.evaluate_range` | 長尺の逸脱検出 | 読取専用 |
| `camera.focus_test.preview_focus_target` | 対象に合わせる候補値プレビュー | 未確定 |
| `camera.focus_test.commit_focus_target` | ユーザー承認後のレンズキー確定 | 編集トランザクション |
| `camera.focus_test.export_report` | CSV/JSONで結果を書き出し | 出力のみ |

UI・WebMCP・標準MCPは同じ検証サービスへ接続。APIの認証、対象ID、プロジェクトversion/etag、範囲上限、処理キャンセル、競合検出を共通化。外部実行からのキー更新もUndo単位を保持。モデルがロードされていない場合に架空のモデル位置を成功扱いで返さない。

## 7. Phase E/F への配置と実装順

- **Phase E追加 (E-FOCUS-01)**: 幾何計算、現在フレーム診断、2画面上のガイド・凡例、対象選択、操作トランザクション（実モデル接続が前提）。
- **Phase E追加 (E-FOCUS-02)**: 範囲診断・タイムライン逸脱区間・結果エクスポート・MCP公開。
- **Phase F連携 (F-DOF-01)**: 実レンダラによるDOFカラー/ブラー差分、レンダー品質・AF挙動の実画像比較。実レンダラなしに視覚確認完了としない。
- 現行バージョン表記は開発順序のみであり、細分化した機能の実施時期は他のE/F進捗に合わせる。B残件はブロッカーにしないが、対象モデルが描画・時間同期できない状態では「フレーム判定完成」は宣言しない。

## 8. 必須テスト／完成ゲート

1. 焦点面上・手前・奥・無限遠境界で理論値と一致し、m/mm変換ミスがない。
2. カメラ移動、F値変更、焦点距離変更、カメラVMD、被写体のアニメーション、ショット切替で評価が更新される。
3. 左右眼・顔・全身など指定部位の切替、ボーン未存在、モデル未読込、カメラ背後、画面外、NaN・負数を適切に表示。
4. フォーカステストをON/OFFしても撮影キー、Undo履歴、書き出し映像にガイドが混入しない。
5. 「フォーカスを合わせる」確定時のみレンズキーが保存され、Esc/キャンセルで変更が破棄される。
6. 300フレームを越える長尺、複数カメラ、被写体切替、MCPからの同時編集で逸脱区間と競合管理が正しい。
7. 実FBX/VRMと実アニメーションで両画面を用い、レンダラDOFとの誤差と実画像結果を検証する。
8. UI、API、WebMCP、標準MCP、保存・読込、実モデル検証のすべてに対応するまで完了扱いにしない。

## 9. 未決事項と注意

- 動画内の色区分は参考表現であり、実際の色閾値が開示されているわけではない。上の閾値は実装仕様として新たに明文化。
- レンズのブリージング、収差、被写体表面全ピクセルのMTFによる真の合焦度は本機能の初期スコープ外。
- 非物理的なDOFシェーダーでは数式による被写界深度と視覚結果が乖離する可能性を診断画面に説明。
- 実装・ブラウザ実動作・動画書き出し品質は未検証。ロードマップへ追加したことを実装完了と混同しない。
