# MMDカメラVMD：生データサンプリングの追加

- 基準コミット: a8c4dec
- 追加コミット: 171063d
- 機能: 6チャネル（中心XYZ、回転、距離、視野角）のVMD 4点Bezier曲線を逆解法（二分探索）でサンプリング。
- フレーム間の補間では終端キーに格納された曲線を使用する。
- 元のVMDバイト列、カメラプロジェクト、MCP操作は変更しない。
- 未完成: MMDカメラ姿勢→Three.js等ブラウザ座標系への正式変換、実3Dプレビュー、UI再生連動、VMDエクスポート、MCPエンドポイント。
- サンプルは生MMD値であり、実映像の一致確認を済ませたものではない。
- 既存の31テストに補間・端点・不正入力検証を追加して合計34件成功。

## 注意点
MMDのカメラ曲線は6チャネル×4バイトで、0〜127を正規化した制御点を使用します。モデル/カメラ環境の実差異については本番VMDを用いた評価が別途必要です。現段階では閲覧・解析モジュール内での読み取り専用操作です。
