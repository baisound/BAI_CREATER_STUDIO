# MMDカメラVMD書き出し — 2026-10-18

## 追加した機能

- 既存の読み取り専用カメラVMD解析結果に対し、カメラキーのみをVMD 0002形式にシリアライズ。
- POST `/api/camera/vmd/export-camera-only`（JSON入力、application/octet-stream出力）。
- カメラ画面で解析後に「解析したカメラキーをVMDで書き出す（カメラのみ）」が利用可能。
- フレーム、注視中心、距離、Euler回転、24バイト補間、画角、透視フラグを記録。
- 同一フォーマットでの再読み込みテスト、重複フレーム・不正補間・NaN・範囲外数値の拒否を追加。

## 限界・未完成（必読）

- カメラ専用VMDへの書き出しであり、オリジナルVMDのボーン・モーフ・照明・シャドウ・IKその他の内容は保存しない。元VMDファイルそのもののラウンドトリップではない。
- 読み込み時に浮動小数点はPython floatへ解釈するため元のバイト列の完全な保持保証はない。
- **編集したBAIカメラプロジェクトをMMDカメラVMDへ変換する機能ではない**。表示中の解析済みRAWカメラキーを再シリアライズする機能。
- MMD独自のカメラ軸とWebプレビュー座標系の一致、実3Dカメラ再生、実VMD/実ブラウザE2E、MCP連携は未完了。
- 自動テスト成功をPhase E完成と扱わない。
