# 新UI 導線点検（制作の流れ5本＋ヘルプ）2026-10-20

対象：`studio/`（`/workspace/01`〜`25`、`python3 server.py` で配信）。基準コミット `10a5342`。コードは変更していない。
方法：Playwright（chromium、`--enable-unsafe-swiftshader`）で 1600×900 と 1280×720 の両方を、ホーム画面から「初めて使う制作者」の操作で実際にクリックして確認した。25画面すべての可視コントロール数も数えた（サイドバーとトップバーを除く＝画面本体のみ）。
スクリーンショット（git管理外）：所有者PC `D:\BAI\BAI_CREATER_STUDIO\_Claude確認画像\new-ui-flow-audit-20261020\`（7枚、末尾の一覧参照）。
前提：新UIは「見た目の正本」であり、現状は操作モック（所有者決定 2026-10-20）。モックが「未実装」なのは仕様どおりで、ここで見るのは「未実装だとしても、利用者が迷わず次へ進めるか」である。

## 1. 総合判定

**判定：骨格（左メニュー・画面の型・状態バッジ）は良いが、このままでは「制作の流れ」が1本も最後までつながらない。P2 ②③ が入る前に、モック側で直せる導線の欠陥が多い。**

- 新UI内で完結する流れは **0本**。J1〜J5 のすべてで、必須の操作が「◇ 未実装」ダイアログか「現行画面へ移動」で終わる。これは P2 の範囲として正しいが、**終わり方が不親切**（「次にどこで何をすればよいか」が書かれていない）。
- 最大の導線問題は「現行画面へ飛ばされる」こと。素材登録のボタンを押すと新UIから抜けて旧画面（`/`）に遷移し、**戻る導線は旧画面側の小さなリンクのみ**。旧画面は所有者が「レイアウトが崩れて操作できない」と判断済みの画面である（J2 の最初の一歩で出会う）。
- ホームの「最近のプロジェクト」4件はすべて仮データで、押しても「開けません」と出るだけ。初見の利用者には最も目立つ場所が行き止まりになっている。
- 左メニューは25項目・9グループで、作業の流れ順になっていない（「カメラ」が先頭、「プロジェクト」「ヘルプ」は下の方）。1280×720 では25項目中11項目（保存・復元、ヘルプを含む）がスクロールしないと見えない。
- 画面の重複が多い（モーション：05/13/12、レンダリング：07/17、シーケンス：04/16、素材：08/11）。
- 肯定面：横スクロールなし（25画面×2解像度）、コンソールエラー0（新UI内。唯一の失敗は旧画面側の外部資源読み込み）、状態バッジ（実機能／既存・部分／サンプル表示／未実装）は正直で、ダイアログに関連ID・予定フェーズが出る。画面ごとの密度は多くが適正。

## 2. 5つの制作の流れ（定義）

| 記号 | 初めての制作者の目的 |
|---|---|
| J1 | アプリを開く → プロジェクトを新規作成／開く → 保存する |
| J2 | 素材（FBX/GLB/VRM/PMX/VMD）を取り込む → 素材管理で見つける → シーンで使う |
| J3 | キャラクター／ステージを置く → 3Dビューで見る |
| J4 | モーションを当てる → タイムライン → 再生 |
| J5 | カメラのショットを作る → レンダリング／書き出し |
| J6 | ヘルプ・設定を探す |

重大度：高＝流れが止まる／誤解させる、中＝迷う・遠回り、低＝見た目・用語。
