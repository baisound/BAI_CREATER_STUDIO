# 新UI デザインシステム（P1-A）

> **正本（2026-10-20 所有者決定）**：BAI Creator Studio の見た目・レイアウトは新UIモック（`studio/`）を正本とする。左サイドメニュー、各画面のパネル構成と中身、既定のナイト配色を含む。現行画面は移植（P2。Phase E より前、作業の流れ順）でこれに合わせる。下の「比較した2案」は経緯として残す。

## 採用理由
- 映像制作ソフト（DaVinci Resolve、Blender、Unreal Editor 等）の**情報密度・ドッキング構成**を参考にし、外観は模写しない。
- 参考画像の青紫ネオン・グラデーション・発光枠・カード大量羅列は不採用。
- 色は意味のある状態だけに使用。状態は色＋文字＋枠線種（実線/破線）で区別し、色覚に依存しない。

## 構成
- 上部バー：ブランド、戻る/進む、パンくず、FX（SCR-26）・歌詞（SCR-27）への共通リンク、画面検索（Ctrl+K）、現行画面へのリンク。
- 左：グループ別ナビ（27画面、番号付き、状態ドット）。SCR-26/27 は2026-10-20のOwner判断で追加した専用モック画面。
- 画面：ヘッダー（画面ID・モード切替・ツールバー）→ 左パネル / 中央ビュー / 右インスペクター（タブ、最後に「実装状態」タブ）/ 下部タイムライン（折りたたみ可）。各パネルは内部スクロール（UX-002）。
- 幅1180px以下で左パネルを切替表示、820px以下で縦積み＋ハンバーガーメニュー。横スクロールなし（テストで確認）。

## 状態表示の契約
| バッジ | 条件 |
|---|---|
| 実機能 | 既存Python APIを**読み書き**し、その結果を表示している。かつ、台帳（`screens.js` の `evidence`）に書いた自動ブラウザーテストが合格している。テストが無い・失敗中なら「既存・部分」のまま。シェル自体が機能を果たす区画（テーマ・ヘルプ等）は `shell` を付け、`tests/studio-ui.test.cjs` を根拠にする |
| 既存・部分 | 現行画面にコードがある（新UIへ未移植） |
| サンプル表示 | 画面内の仮データ。保存しない |
| ◇ 未実装 | 押すと説明ダイアログ（関連ID・予定フェーズ・**今できること**と移動先ボタン） |

偽の成功・接続中・測定値は表示しない（未計測は「未計測」、取得失敗は「未接続」）。

### 未接続の区画の薄い表示（2026-10-20 オーナー決定、P2-WP-00c）
- 状態が「実機能」以外（既存・部分／サンプル表示／◇ 未実装）の区画は、**薄く表示**し、見出しの横に「**未接続（まだ使えません）**」とバッジを出す。対象はパネル・カード・左右の一覧・右タブの節・タイムライン・ビューポート。
- 機能は消さない。**操作は押せるまま**で、キーボードのフォーカスも通常どおり（押したときの ◇ ダイアログやトーストはこれまでどおり）。
- 区画の状態は `screens.js` の `status` だけから決める（別の印は作らない）。移植が済んで `status` を「実機能」にすると、自動で通常の表示に戻る。
- 「通常の表示なのに未接続」「薄いのに実機能」を防ぐため、`tests/test_screen_status_honesty.mjs`（`real` には `evidence` か `shell` が必須）と `tests/studio-ui.test.cjs` の `unconnected sections are dimmed and labelled` が検査する。

### 導線の約束（導線点検 §5 の項目1〜5、2026-10-20）
- ◇ 未実装のダイアログは行き止まりにしない。「今できること」の1行と、移動先のボタンを必ず付ける。旧画面で実際に行えるものだけ「今は現行画面で行えます。」と旧画面へのボタン、それ以外は「この機能は「{予定}」で入る予定です。今はこの画面では使えません。」と［ホームへ］。
- 新UIから現行（旧）画面へ移るリンク・ボタンは、先に「新UIから離れます」の確認（［移動する］［キャンセル］）を出す。
- 模擬の再生・位置スライダー・シーンツリーのある画面（02・05・06・13）は、3Dビューの区画が「実機能」になるまで、上部に「サンプル再生（3D未接続）」を常に出す。
- 仮のプロジェクトのカードには「サンプル」のリボンを付ける。新規プロジェクトの作成は、取り消しのできない上書きになるため回答（Q1）まで ◇ 未実装（SCR-01 の5か所すべて）。

## アクセシビリティ
フォーカスリング、Tab/矢印キー（タブ・一覧・メニュー）、Esc でダイアログを閉じる、ダイアログ内フォーカス固定、`aria-current`/`aria-selected`、`prefers-reduced-motion`、表示密度「ゆったり」。

## 製品らしい見た目への刷新（2026-10-20、オーナー指示）
オーナー確認で「管理画面っぽい」「仮の画像でよいので完成イメージを出してほしい」「参考画像と同じ見た目で、AIっぽい紫は使わない」との指示を受けて刷新した。

- **既定テーマを N: ナイトに変更**：深いスレート（青みの黒 `#0c0f13`〜`#252c36`）＋琥珀色アクセント `#e2a54c`。紫・マゼンタ・ネオン発光は使わない。A（グラファイト）・B（ペーパー）は「テーマ・レイアウト」画面で切替可能。
- **画像中心の構成**：参考画像から切り出した仮画像（`studio/assets/samples/`、約0.55MB、紫系の色味は彩度を下げた）を、ホームのヒーロー・プロジェクトカード、素材管理のグリッドと詳細、3Dビューポート、マルチビュー、カメラプリセット、ショットのサムネイルに使う。画面上には必ず「サンプル画像」と表示する。
- **パネルの浮遊配置**：枠線で区切った管理画面風ではなく、角丸12pxのパネルを8pxの間隔で配置。サイドバーは線画アイコン付き。
- **素材管理（SCR-08）**：参考画像08と同じ構成（左：カテゴリと件数・お気に入り・コレクション、中央：場所タブ・検索・形式・並び替え・グリッド／リスト・サイズ、カード、インポートキュー、右：大きなプレビュー・情報・タグ・依存素材・操作）。検索・絞り込み・並び替え・お気に入りは画面内のサンプルデータで実際に動く（保存はしない）。
- **正直な表示は維持**：進み具合のバーは「表示例」と明記、「シーンで使う」等は ◇ 未実装、件数はサンプル素材の実数。
