# 新UI デザインシステム（P1-A）

## 比較した2案
| | A: グラファイト（採用） | B: ペーパー（比較） |
|---|---|---|
| 背景/パネル | #171615 / #232220（温かいチャコール） | #e7e4de / #f7f6f2（オフホワイト） |
| 文字 | #e6e2da / 補助 #b3aea4 | #22211e / 補助 #55524b |
| アクセント | 真鍮 #c79b55（選択・現在位置・主操作のみ） | 深緑 #2f6b53 |
| 用途 | 3Dビュー・映像の色判断を邪魔しない既定 | 文書・設定・素材整理向け。ビューポートは暗色維持 |

切替：SCR-21「テーマ・レイアウト」、または各画面の「表示」メニュー（ブラウザに保存）。

## 採用理由
- 映像制作ソフト（DaVinci Resolve、Blender、Unreal Editor 等）の**情報密度・ドッキング構成**を参考にし、外観は模写しない。
- 参考画像の青紫ネオン・グラデーション・発光枠・カード大量羅列は不採用。
- 色は意味のある状態だけに使用。状態は色＋文字＋枠線種（実線/破線）で区別し、色覚に依存しない。

## 構成
- 上部バー：ブランド、戻る/進む、パンくず、画面検索（Ctrl+K）、現行画面へのリンク。
- 左：グループ別ナビ（25画面、番号付き、状態ドット）。
- 画面：ヘッダー（画面ID・モード切替・ツールバー）→ 左パネル / 中央ビュー / 右インスペクター（タブ、最後に「実装状態」タブ）/ 下部タイムライン（折りたたみ可）。各パネルは内部スクロール（UX-002）。
- 幅1180px以下で左パネルを切替表示、820px以下で縦積み＋ハンバーガーメニュー。横スクロールなし（テストで確認）。

## 状態表示の契約
| バッジ | 条件 |
|---|---|
| 実機能 | 既存Python APIを読み取り表示している |
| 既存・部分 | 現行画面にコードがある（新UIへ未移植） |
| サンプル表示 | 画面内の仮データ。保存しない |
| ◇ 未実装 | 押すと説明ダイアログ（関連ID・予定フェーズ） |

偽の成功・接続中・測定値は表示しない（未計測は「未計測」、取得失敗は「未接続」）。

## アクセシビリティ
フォーカスリング、Tab/矢印キー（タブ・一覧・メニュー）、Esc でダイアログを閉じる、ダイアログ内フォーカス固定、`aria-current`/`aria-selected`、`prefers-reduced-motion`、表示密度「ゆったり」。
