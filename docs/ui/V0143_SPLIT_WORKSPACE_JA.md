# v0.14.3 固定プレビュー／素材一覧UI

- 「統合素材」タブは、上段に3Dプレビューを固定し、下段のみ素材登録・検索・一覧をスクロールする構造へ変更。
- 登録済み素材を選択するUIを下段にまとめる。既存ファイル・カタログ・Git履歴を保持。
- GLB再生停止はアニメーションアクションを停止し、ボタン表示を再生へ戻す。同期比較モードも停止。
- UI/サーバーAPI/WebMCPの既存経路を維持。今回の新規レイアウト自体にMCPコマンドは不要。
- 未完了: PMXを含む完全な素材共通API、3画面独立カメラ、ブラウザ実機レイアウト検証。
- 視覚検証: 1366x768、1920x1080で上段が動かず下段が独立スクロールし、停止でアニメーションが止まること。
