# 枝番04 — 非破壊のプロジェクト別保存スナップショット

- 作品IDに対応する独立JSONへ、既存`/api/project/bundle`の制作状態（組み合わせ＋カメラ、任意のworkspace）をスナップショット保存する。
- **制約**：読み込みはデータを取得するだけ。既存の稼働中エンジン状態に自動適用しない。作品切替、全素材の格納、完全なプロジェクト復元は未実装。
- UI/API/MCP/WebMCP全操作の本格統合は継続課題。サーバー側の保存/取得操作を提供する。
- 元の `project_state.json`、`camera_project.json` は変更しない。作業中データの初期化は一切しない。
- 検証対象：入力拒否、未知ID拒否、破損JSON保持、保存読み込み、従来ルートの回帰。
