# v0.12.6 — PMX ZIP登録とコンビネーションUIのスクロール構造

## 変更点

- PMX+テクスチャをZIP単位で登録。素材のPMXからの相対ディレクトリ構造を保持し、A/Bスロットで保存する。
- PMXを1つだけ含むZIPを対象とする。ZIP中に複数PMXがあれば明示的に拒否する。上限400MiB圧縮／600MiB展開／1500ファイル。
- パストラバーサル、暗号化ファイル、シンボリックリンクの混入を拒否する。許可した拡張子以外は取り込まない。
- 既存のVMDアップロード、個別PMXファイル登録は維持する。
- `#chain-side` を高さ制限付きGridへ変更。常時表示する主要操作、編集中リスト、設定・履歴を独立したスクロール領域にする。
- viewportが狭い場合はページスクロールを維持し、画面下の操作要素へ到達できるようにする。

## 操作手順

1. 「📁 PMX・VMD登録／再生」を選ぶ。
2. 「PMXモデル＋テクスチャをZIPから登録」でZIPを選び、A/Bを指定。
3. 「ZIPを登録して表示」を押す。ステータスに登録件数・表示結果が示される。
4. コンビネーションは右パネル上部から追加／再生／停止。直下の一覧をスクロールする。履歴やVMD設定はその下の独立したスクロール領域を使う。

## API

`POST /api/pmx-zip-upload?slot=A|B`。body = ZIP bytes。応答 `{ok,slot,model,model_path,files}`。ZIP内のPMXは厳密に1つ。`GET /api/mmd-assets` と `GET /api/mmd-file/<slot>/<relative_path>` で登録素材を参照する。

## AI操作

既存のファイル登録手段は保持。新しいZIP登録は同じローカルAPIを手動UIから使用し、WebMCP／標準MCPの専用ラッパーは次工程の追加対象。**WebMCP・標準MCPからのZIP一括登録は現時点では未対応**であり、共通仕様の完了条件をまだ満たさない。
