# v0.12.8 UI再設計のCritic×3 / Judge

基準: v0.12.7および利用者の実機報告。コードの存在だけを実機合格としない。

## Critic 1：情報設計 / 判定: 要修正
問題: 機能別の後付けタブ、GLBインポートなし、モデル選択がプレビューより下に配置。
修正: タブ名を短縮、制作順ガイド・接続状態、同梱VRM選択をプレビュー前に配置。
残存: PMX/GLB/VRM/VMDの共通インポートは未完成。ガイドに「未対応」と表示。

## Critic 2：スクロール・保存 / 判定: 条件付き改善
問題: 固定高さ・sticky・overflow:hiddenの競合。操作バーや詳細が見切れる。
修正: 新しい統一レイアウトCSSを末尾に適用。デスクトップでは左右中央のパネル領域を独立スクロール、コンビネーション操作バー・リスト・詳細を分離。狭い画面では縦積み、ページスクロールに切替。既存の自動保存APIから状態を表示。
残存: 1366x768/1920x1080等での実ブラウザ検証未完了。

## Critic 3：回帰・AI経路 / 判定: 保留
既存のIDと操作ハンドラ・保存API・WebMCP・標準MCPは保持。新たな「同梱VRM選択」UIは既存の integratedPreviewV02.load を再利用。モデル再表示は全身カメラ再調整の代替だが独立したリセットAPIではない。サーバー/ブラウザでの描画と保存のエンドツーエンド検証は未完了。新UIの各操作についてMCP同等性の監査も未完了。

## Judge 最終判定：リリース不合格、開発プレビューは条件付き提供
通過: Python・JavaScript構文確認、既存データ・MCPソースの保持。
不通過: 全端末の画面操作テスト、GLB登録、素材管理の統合、実機3D/PMX/VMD確認、WebMCP/標準MCP操作同値テスト。
このバージョンをUI完成版と呼ばない。次版は共通素材インポートと画面ベースの自動E2Eテストを最優先とする。
