# Phase E 自由視点操作修正チェックポイント

## 基点
- 入力HEAD: `3a5e6d1`。
- 今回はPhase Eの全実装ではなく、自由視点のUE式操作についての独立修正。

## 修正
- Scene Viewの右ドラッグで視点回転し、右ボタン保持中のみW/A/S/D・Q/Eによる自由移動を許可。
- 左ドラッグでオービット、Shift+左ドラッグで水平・垂直移動、ホイールで距離調整。
- Fキーは読み込んだモデルのバウンディングボックス中央を対象とし、モデル未読み込み時だけデフォルト中心を使用。
- マウス・キーボード入力は編集用Scene Viewのカメラだけを変更。撮影カメラのキーフレームは変更しない。
- フォーカス喪失、pointercancel時に操作状態を解除。
