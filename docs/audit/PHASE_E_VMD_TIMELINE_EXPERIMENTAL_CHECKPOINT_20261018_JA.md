# Phase E: VMDタイムライン試験追従チェックポイント

## 到達点
- カメラVMDネイティブ読み込み後に限り、任意の「試験VMDをタイムラインに追従」を利用できる。
- 既存の `/api/camera/vmd/preview-pose` を利用して、現フレームの試験座標姿勢を撮影カメラのThree.jsプレビューに適用する。
- 通信は直列化し、新しいフレームが選ばれた場合、古い結果を反映しない。再読み込み時の世代番号でも旧応答を無効化する。
- プロジェクトのキー・VMD原本への書き込みをしない。デフォルトOFF。

## 制約と未完了（完成判定不可）
- 各フレームのプレビュー値はHTTP経由で計算するため、低遅延・フレーム精度保証・スムーズな30/60fpsリアルタイム再生は未完成。高負荷下はフレームを飛ばす。
- MMD本体との座標回転互換、VMD透視設定の再現、音楽・外部VMDモーション同期は未検証。
- WebGL環境での画面表示は未検証。標準MCP・WebMCP未接続。
- レール・クレーン・親子リグ、DOF実レンダリング、ショット編集、書き戻し変換などは未完成。

## 次回の優先順位

2. ローカルで連続サンプリング可能なキャッシュもしくはクライアント補間で滑らかなタイムライン再生。
3. VMD再生モードとBAI編集キーの切り替えを正式なレイヤーとして設計・実装。
