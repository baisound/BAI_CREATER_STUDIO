# Phase E カメラ画面 実装監査・限定修正（2026-10-18）

## 根拠
ユーザー提供の v0.16.47 動作確認動画に対するレビュー、`camera.html`, `camera.css`, `camera.js`, `bai_camera.py`, `server.py` と既存テストを確認。

## 今回確認した問題と修正
- 撮影ビューしか存在せず、カメラと被写体の空間関係が把握できない: 独立したシーン配置ガイドを追加。シーン上に被写体代替人形、カメラ位置、ターゲット、キー間カメラ軌跡を表示。
- 自由視点と撮影カメラが混在: シーンガイドは独立の視点パラメータで操作し、撮影キーは変更しない。
- プレビュー操作が常にキー化される: 自動キーON/OFFを追加。OFF時は編集途中の構図をステージし、明示的「現在フレームをキー化」で確定。
- Undo/Redo履歴: 変更後の状態を登録することで初回編集・取り消し・やり直しの状態を整合。
- 視点の右方向の計算がX軸反転していた: 射影と平行移動の双方を修正。
- ドラッグキーの尺末尾外への移動を防止。
