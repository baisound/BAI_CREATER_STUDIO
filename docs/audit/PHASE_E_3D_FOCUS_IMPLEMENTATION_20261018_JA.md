# Phase E 実装チェックポイント — 3D・フォーカス診断ベータ

## 今回追加

- カメラワークスペースから既存統合カタログに登録済みの GLB/VRM を選択。
- Three.js / GLTFLoader を使う自由視点・撮影視点の2系統 WebGL 表示（同じモデルを共有）。
- カメラキーのポーズを3D撮影カメラに適用。モデル内蔵クリップをフレーム/FPSで直接サンプリング。
- 左の3D自由視点でドラッグ見回し・ホイール距離調整・WASD/QE・Fによる位置調整（キャンバスにフォーカス後）。この操作は撮影キーに保存しない。
- 焦点距離mm、F値、撮影距離、顔/胸/腰の選択から幾何学的な許容被写界深度を概算（CoC=0.03mm）。

## 未完成・制限

- 実ブラウザでのGPU描画テストは未実施。自動テストは静的接続検証中心。
- Three.jsは既存画面と同じCDN importmap。オフライン時はWebGLモデル表示できない。
- FBX/PMX/VMDのカメラ画面直接取り込みは未対応。VRMの表情・物理や外部VMDによるモデルアニメーション同期も未対応。
- 焦点診断は**計算上の被写界深度**でありDOFレンダリング／画質評価／フレーム範囲警告ではない。
- 焦点診断値は一時的なUI状態で、プロジェクトへの保存・MCP公開は未実装。
- シーンカメラ操作はUE互換の一部。入力機器差異・モデル間のスケールなど実機試験が必要。
- WebGLが使えない環境でガイドへフォールバックするが、読み込み中やWebGLエラーの一部で再試行が必要。
- 専用カメラVMD読み書き、レール・リグ、高品質被写界深度レンダリング、カメラプリセット管理は未実装。

## 次の実装順序

1. 実ブラウザのWebGL描画とカメラ視野の一致を検証・修正。
2. キー追加/更新と3Dポーズ同期の往復、アニメーション停止・再生・スクラブの確認。
3. 焦点診断値の保存とWebMCP/標準MCP対応、フレーム範囲診断。
4. FBX/VRM/GLBの共通モーション適用基盤とVMDカメラ連携。
