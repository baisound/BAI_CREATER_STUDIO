# CAM-004 実モデル見切れ診断 接続チェックポイント

- ベース HEAD: `cc64262`
- 実装: `camera_3d.js` はアニメーション評価後にGLB/VRMのメッシュ範囲（スキニングしたメッシュは姿勢ごと）を測定し、撮影診断へ中心・半径をイベント配信する。
- `camera.js` は実モデルの値を優先し、未読込時にガイド人体へフォールバックする。
- 安全性: 撮影キーとVMDデータは変更しない。判定は球を用いる保守的な近似で、メッシュ輪郭精密投影や遮蔽検出ではない。
- 未検証: GPUブラウザーでの表示、GLB/VRM各素材のスキニング、重いモデルでの計算速度、MMDとの一致。
- 次: メッシュ投影の精密診断、レンズ・DOF、ショット管理、MCP、統合テスト。
