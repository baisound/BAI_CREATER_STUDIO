# Phase E: 動的ボーン合焦距離追従チェックポイント

- 基点: `3ea3024`
- 対象: オーナー承認済みCAM-005（既存ボーン位置と焦点距離入力・近似DOFの接続）
- 実装: カメラと選択ボーンの距離を計算し、合焦距離入力へ反映。ON/OFF設定を既存schema:1の任意フィールド `focus_tracking` に保存する。既存プロジェクトと互換。
- 非破壊: カメラキーは変更しない。
- 制限: シーン1単位=1mを仮定。VRMモデルごとの縮尺、GPU表示、移動時の見た目、MMD一致、WebMCP/stdio MCPは未検証。モデルやボーン未選択時は値を更新しない。
- 次: ショット/シーケンス編集、既存MCP経路の接続、統合品質検証。オーナー未承認の機能は追加しない。
