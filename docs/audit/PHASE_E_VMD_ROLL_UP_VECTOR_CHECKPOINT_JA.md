# Phase E / MMDカメラロールの試験プレビュー修正

## 起点
- ベース: `c9970c3`
- 作業対象: VMDカメラの姿勢をThree.jsの撮影プレビューに適用する試験経路。

## 今回の変更
- VMDネイティブのXYZオイラー回転を適用した上方向ベクトル (`up`) を計算する。
- Z反転を含む既存の試験座標変換に合わせ、Python APIとブラウザー内サンプラーで `up` を返す。
- Three.js `lookAt` の前に `camera.up` を更新し、従来破棄されていたロールを反映する。
- 通常カメラからの復帰時に古い `up` が残らないよう、`up` 不在ならY軸に戻す。
- Pythonとブラウザー計算のフレーム別一致テストを `up` に拡張する。

## 検証
- 関連ユニットテスト23件通過。JS構文検査通過。
- 実ブラウザー描画およびMMD本体とのピクセル比較は未実施。

## 完成判定を保留する項目
- MMD本体と一致する回転順序・符号・距離の基準値による互換性検証。
- 透視/平行投影の切替（現在のThree.js撮影プレビューはPerspectiveCamera）。
- 連続再生の実FPS検証、撮影リグ・DOF・ショット編集・MCP連携。
- 本変更はVMDカメラ『試験プレビュー』の修正であり、Phase E完成とは扱わない。
