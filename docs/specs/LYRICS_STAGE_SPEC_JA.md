# 歌詞・MV構成・ステージ 要求仕様（B3・草案）

状態: 仕様草案。対象 `LYRIC-001`〜`005`、`LYRIC-007`〜`012`。`LYRIC-006` の拍マーカーは B2。`LYRIC-010` のステージギミックのデータと配置は本書、格闘・扉等のイベント駆動動作は B4 に詳述する。JIZURA や外部素材の取り込みは、実際のソースとライセンス確認後に実装する。

## 目的・依存

歌詞、文字演出、ショット、ステージを歌音声・ダンサー・カメラと共通時刻で扱い、MMD「歌ってみた」MVを構成する。`DATA-008`〜`010`、B2 の拍時刻、Phase E のカメラ、Phase F の動画出力、P2 の基本ステージ配置、B1 のダンサーを参照する。P2 ④で承認された基本的な位置／回転／大きさの配置を再実装しない。権利未確認素材を配布に含めない。

## 利用者の流れ（歌ってみた）

VRM/PMX とステージを配置し、音声と VMD/FBX を合わせる。`SCR-23` から許諾を確認した歌詞・演出素材を取り込み、`SCR-16` でショット構成と歌詞キューを置く。`SCR-06` で 2D 画面固定または 3D 空間の歌詞位置、遮蔽、床や可動物を確認する。`SCR-22` で再利用可能な歌詞スタイルと振付素材を探す。`SCR-17` でカメラ切替境界と文字見切れを検品する。MMD 用の PMX ステージが必要なら変換可能な範囲だけ別ファイルとして出力する。

## 画面・データ・保存／復元

| 画面 | 操作 |
|---|---|
| `SCR-16` `/workspace/16` | シーン／ショット／絵コンテ、歌詞キューとカメラ区間、重複・空白の確認 |
| `SCR-06` `/workspace/06` | ステージ階層、床、文字アンカー、可動物と依存関係の表示 |
| `SCR-08/22` | 演出素材・テンプレート・お気に入り・タグの検索と再利用 |
| `SCR-23` | 外部ソース、ライセンス、変換ログ、PMX 等への出力 |
| `SCR-17/24` | 出力プレビューと、見切れ・欠損・性能の診断 |

- `AssetSource`: 出典 URI／取得時点の版／ハッシュ／作者／ライセンス／帰属表示／許可用途／依存ファイル。権利確認不能なら閲覧と仮プレビューの範囲に留め、配布パックへ含めない。
- `LyricCue`: テキスト、言語、`[inFrame,outFrame)`、スタイル ID、2D/3D アンカー、アニメーション曲線、レイヤー ID。字幕として読む文字と演出文字を別トラックで持つ。フォントと字形の出典を追跡する。
- `SceneShot`: シーン ID、ショット ID、カメラ ID、範囲、絵コンテ素材参照、歌詞／音楽／演技イベント参照。全項目は共通の有理数 FPS とフレーム時刻を使う。
- `StageAsset`: `.blend/.fbx/.glb` 等の原資産 ID/hash、単位、座標系、変換行列、階層、材質／テクスチャ参照、床衝突形状、空間チャンクと LOD、可動ピボット。`.blend` は対応する Blender 変換環境がある場合のみ処理する。
- `MotionRule` (`LYRIC-011`) は歩行／待機／呼吸のルール、適用対象、開始／終了、元モーションへの加算量を別レイヤーとして持つ。`SearchIndex` (`LYRIC-012`) は許諾済み振付・ポーズのタグと特徴量、元素材 ID への参照を保持する。

全素材の原本は不変。保存→再起動→復元で歌詞時刻・文字位置・ショット順・ステージ変換・依存素材・警告が一致する。欠損素材やフォントは代替内容と差分を明示し、黙って元の見た目と同じと表示しない。外部資産は相対参照と hash で追跡し、Undo/Redo は編集操作だけに適用する。

| `LYRIC-005` | 歌詞テンプレートとお気に入り・タグを同じ素材台帳へ保存し、重複参照を避ける |

| `LYRIC-011` | 歩行／待機／呼吸の追加動作を元 VMD と別レイヤーで評価し、OFF・Undo で元の姿勢へ戻る |
| `LYRIC-012` | タグ・ポーズ特徴量・作風で許諾済み素材を検索し、検索結果から原資産・版へ追跡できる |

## 手動 UI・WebMCP・標準 MCP とテスト方針

共通サービスの契約案: `registerExternalSource`、`importLyricSource`、`addLyricCue`、`setLyricAnimation`、`placeWorldText`、`saveSceneShot`、`importStage`、`exportStagePmx`、`configureStageChunk`、`setStageGimmick`、`setMotionRule`、`searchChoreography`。三経路とも対象 ID・revision・権利状態・変換警告を返す。任意外部スクリプトを MCP から実行しない。

実際の歌詞／フォント／ステージ資産とライセンス記録を使い、文字見切れ、2D/3D 遮蔽、時間ずれ、欠損テクスチャ、座標系・単位、変換不能な Blender modifier/物理、チャンク境界、FPS 変更、保存復元、UI／両 MCP 同値を試験する。PMX 出力を実 MMD で確認するまでは互換を未検証と記す。

## 価値

- 使う側: 歌詞と映像構成を同じ時刻で編集し、ステージ・フォント・演出素材の欠損や権利を出力前に発見できる。
- 売る側: 歌唱 MV の制作工程を素材管理から出力までつなぎ、許諾済み素材の再利用価値を高められる。
