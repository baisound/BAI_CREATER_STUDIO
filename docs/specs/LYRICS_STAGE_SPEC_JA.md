# 歌詞・MV構成・ステージ 要求仕様（B3・草案）

状態: 仕様草案。対象 `LYRIC-001`〜`005`、`LYRIC-007`〜`012`。`LYRIC-006` の拍マーカーは B2。`LYRIC-010` のステージギミックのデータと配置は本書、格闘・扉等のイベント駆動動作は B4 に詳述する。`O-LYRIC-01/02/03` は所有者がすべて推奨案Aを承認した。決定と境界は [B3所有者判断資料](B3_LYRICS_STAGE_DECISIONS_JA.md) に記録する。JIZURA や外部素材の取り込みは、対象コミット・依存・ライセンスを固定して確認後に実装する。2026-10-20 に [JIZURA実画面](https://jizura.net/) の v0.10.0、[公式ガイド](https://jizura.net/guide/)、[公式リポジトリ](https://github.com/852wa/JIZURA) を確認した。リポジトリ README は確認時 v0.9.0 の説明であり、実画面との版差を実装前に再確認する。

## 目的・依存

歌詞、文字演出、ショット、ステージを歌音声・ダンサー・カメラと共通時刻で扱い、MMD「歌ってみた」MVを構成する。`DATA-008`〜`010`、B2 の拍時刻、Phase E のカメラ、Phase F の動画出力、P2 の基本ステージ配置、B1 のダンサーを参照する。P2 ④で承認された基本的な位置／回転／大きさの配置を再実装しない。権利未確認素材を配布に含めない。

## 利用者の流れ（歌ってみた）

VRM/PMX とステージを配置し、音声と VMD/FBX を合わせる。`SCR-23` から許諾を確認した歌詞・演出素材を取り込み、専用の `SCR-27` で歌詞キュー、文字配置、演出とMV構成を編集する。`SCR-16` のショットとカメラ区間は参照し、`SCR-06` ではステージ内の遮蔽、床や可動物を確認する。`SCR-22` で再利用可能な歌詞スタイルと振付素材を探す。`SCR-17` でカメラ切替境界と文字見切れを検品する。MMD 用の PMX ステージが必要なら変換可能な範囲だけ別ファイルとして出力する。

入力の正面は JIZURA と同じ「1行＝1フレーズ」の歌詞欄と LRC 時刻である。`/` のカット境界、強調、注釈、間奏など上流記法は対応範囲を版固定して検証する。歌音声は `SCR-10` の既存素材を参照し、`SCR-27` では行頭を Space／タップ、カット頭を Tab、直接時刻編集で合わせる。拍マーカーは `LYRIC-006` の共有データを参照する。行・カットを下部タイムラインに置き、左で行の開始時刻・カット数・固定・その行だけの再抽選、中央でプレビューと拍を確認する。自動構成の再提案は歌詞、音声、手動時刻、固定した行を変えず、案の履歴とシードを保持する。

SRT はユーザーが求めた BAI 独自の互換入力とする。`SCR-27` で選び、`SCR-08/23` と同じ素材台帳へ原本・出典・許諾を登録する。[一般的なSRT形式](https://www.loc.gov/preservation/digital/formats/fdd/fdd000569.shtml)は各発話に開始・終了時刻を持つ。解析プレビューで文字コード、両時刻の順序・重複・空白・音声範囲外・FPS換算を確認してから、**SRT の番号と `[開始, 終了)` ごとに独立したブロック**を下部「歌詞キュー」トラックへ配置し、共通 `LyricCue` の行・カットと対応づける。次の発話までの空白や重複を埋めずに表示する。JIZURA が SRT を直接取り込むと表示しない。ブロック本体を左右へ動かすと**選択した発話の開始・終了を同じ量だけ**ずらし、長さを保つ。左右の端を動かす操作は開始または終了だけのトリムとして分ける。原SRTの両時刻と本文は不変にし、編集オフセット・トリム・本文修正を別レイヤーへ保存する。原時刻と現在時刻の差分を表示し、順序逆転・不正な長さ・音声範囲外は警告して黙って補正しない。移動・トリムは Undo/Redo とキーボードによるフレーム単位補正にも対応する。終了時刻がない入力は正規SRTとして黙って受け取らず、解析エラーと修正方法を示す。口形に使う場合だけ同じ素材IDの確定入力を `SCR-10` に明示的に渡し、口形キーを別トラックに生成する。歌詞キュー修正は口形キーを自動上書きせず、同期差分を示して再生成を選べるようにする。

### 画面分割とモード

歌詞制作は `SCR-27` の**同じページ**で完結する。JIZURA 実画面を参考に、左を歌詞本文・LRC/SRT互換取込・音声参照・行とカットの一覧、中央をプレビュー・再生・共通タイムライン、右を演出操作とする。上部の「かんたん／詳細」はページ遷移ではなく右ペインの表示モード切替で、歌詞、音声、再生時刻、選択中の行を保持する。「かんたん」はおまかせ案、前後の案、選択行の再抽選と固定に絞る。「詳細」は行・カット、2D/3D文字配置、文字モーション、演出パック、絵コンテ参照をタブで切り替える。全設定を一画面へ同時表示しない。狭い幅では左・右を開閉し、中央のプレビューと時間軸を優先する。これは配置と操作順の設計で、JIZURAのソースや演出パックを移植したという意味ではない。

ページを移る操作はデータの所有者が違う場合だけに限る。音声素材の読込・配置・編集は `SCR-10`、ショット順・範囲・カメラは `SCR-16`、完成動画の出力と検品は `SCR-17`、許諾・素材索引は `SCR-08/23` が所有し、`SCR-27` には参照と帰路を置く。リップ用口形キーは `SCR-10` に別トラックで保持する。

字面を使ったリリックモーションも `SCR-27` が編集を所有する。下部で歌詞キューを選び、右「文字配置」で2D画面固定／3D空間固定と基準位置を決め、右「文字モーション」で現在フレームの位置・大きさ・透明度のキーと補間を編集する。下部に歌詞キューとは別の「文字モーション」トラックを置き、中央プレビューで同じショット・音声時刻の前後を比較する。許諾済み演出パックの適用は「演出パック」タブから行い、手動キーは原歌詞・LRC・SRT互換入力とは別に保存する。モックは値・キーを保存せず未実装と表示する。

## 画面・データ・保存／復元

| 画面 | 操作 |
|---|---|
| `SCR-27` `/workspace/27` | 歌詞キュー・2D/3D文字・演出パック・MV構成の編集。音声時刻とショット区間を参照 |
| `SCR-16` `/workspace/16` | ショットとカメラ区間の編集、歌詞キューの参照と重複・空白の確認 |
| `SCR-06` `/workspace/06` | ステージ階層、床、可動物、歌詞の遮蔽と依存関係の表示 |
| `SCR-08/22` | 演出素材・テンプレート・お気に入り・タグの検索と再利用 |
| `SCR-23` | 外部ソース、ライセンス、変換ログ、PMX 等への出力 |
| `SCR-17/24` | 出力プレビューと、見切れ・欠損・性能の診断 |

- `AssetSource`: 出典 URI／上流コミット・取得時点の版／ハッシュ／作者／ライセンス／帰属表示／許可用途／依存ファイル。`O-LYRIC-01=A` により、行/LRC・演出設定の変換契約を先に検証し、必要な上流ソース利用は対象モジュールと依存の権利・ブラウザ適合を個別に監査する。データ互換だけで `LYRIC-001` 完了としない。権利確認不能なら閲覧と仮プレビューの範囲に留め、配布パックへ含めない。
- `LyricCue`: 入力種別（行テキスト／LRC／SRT互換）、原素材 ID／行・カット番号、SRTキュー番号、原開始・原終了時刻、編集後のテキスト、言語、`startFrame = sourceStartFrame + shiftFrames + trimStartFrames`、`endFrame = sourceEndFrame + shiftFrames - trimEndFrames`、スタイル ID、2D/3D アンカー、アニメーション曲線、レイヤー ID。SRTのミリ秒→フレームは共通有理数FPSで換算し、原時刻と丸め結果を保持する。ブロック本体の移動では選択キューの `shiftFrames` だけを変えて長さを維持する。端のトリムは別操作で、原本と隣接キューは不変。行・カットとキューの対応を保存する。字幕として読む文字と演出文字を別トラックで持つ。フォントと字形の出典を追跡する。
- `LyricProposal`: 再提案シード、対象の演出パック ID／版、案の履歴、行・カットごとの固定状態と手動補正。再提案が入力の歌詞・音声・時刻を変えないことを検証する。
- `MvStoryboard`: 既存ショット ID／revision への参照、絵コンテ素材参照、歌詞／音楽／演技イベント参照。ショット ID・順序・範囲・カメラ割当の正本は `SCR-16` と既存のショットサービスに置き、`SCR-27` は複製保存しない。全参照は共通の有理数 FPS とフレーム時刻を使う。
- `StageAsset`: `.blend/.fbx/.glb` 等の原資産 ID/hash、単位、座標系、変換行列、階層、材質／テクスチャ参照、床衝突形状、空間チャンクと LOD、可動ピボット。`.blend` は対応する Blender 変換環境がある場合のみ処理する。
- `MotionRule` (`LYRIC-011`) は歩行／待機／呼吸のルール、適用対象、開始／終了、元モーションへの加算量を別レイヤーとして持つ。`SearchIndex` (`LYRIC-012`) は許諾済み振付・ポーズのタグと特徴量、元素材 ID への参照を保持する。

全素材の原本は不変。保存→再起動→復元で歌詞時刻・文字位置・ショット順・ステージ変換・依存素材・警告が一致する。`O-LYRIC-02=A` により、欠損フォントは元ID/hashと権利、代替候補の行幅・改行・2D/3D見切れの差分を同じショットで示し、利用者が選んだ代替だけを別レイヤーに記録する。黙って元の見た目と同じと表示しない。外部資産は相対参照と hash で追跡し、Undo/Redo は編集操作だけに適用する。

## 手動 UI・WebMCP・標準 MCP とテスト方針

共通サービスの契約案: `registerExternalSource`、`previewLyricSource`（行テキスト／LRC／SRT互換）、`importLyricSource`、`addLyricCue`、`setLyricTiming`、`setLyricProposal`、`setLyricAnimation`、`placeWorldText`、`setMvStoryboardReference`、`importStage`、`exportStagePmx`、`configureStageChunk`、`setStageGimmick`、`setMotionRule`、`searchChoreography`。`SCR-10` は明示的に確定した同じ入力素材IDを参照し、口形トラックを別管理する。ショット本体の編集は `SCR-16` と既存サービスへ渡す。三経路とも対象 ID・revision・権利状態・変換警告を返す。任意外部スクリプトを MCP から実行しない。

実際の歌詞／フォント／ステージ資産とライセンス記録を使い、文字見切れ、2D/3D 遮蔽、時間ずれ、欠損テクスチャ、座標系・単位、変換不能な Blender modifier/物理、チャンク境界、FPS 変更、保存復元、UI／両 MCP 同値を試験する。PMX 出力を実 MMD で確認するまでは互換を未検証と記す。

## 価値

- 使う側: 歌詞と映像構成を同じ時刻で編集し、ステージ・フォント・演出素材の欠損や権利を出力前に発見できる。
- 売る側: 歌唱 MV の制作工程を素材管理から出力までつなぎ、許諾済み素材の再利用価値を高められる。

## 所有者決定

- `O-LYRIC-01=A`: 上流コミット・権利・依存を監査し、行/LRCなどの変換契約から始めて必要なソース部分を段階的に統合する。
- `O-LYRIC-02=A`: 元フォント欠損を示し、代替候補と見た目差分から利用者が選ぶ。
- `O-LYRIC-03=A`: 事前解析と利用者確認後に、対応要素だけを別名PMXへ部分出力し、欠落レポートと `partial` 状態を必須にする。
