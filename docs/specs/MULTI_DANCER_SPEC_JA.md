# 複数ダンサー・フォーメーション 要求仕様（B1・草案）

状態: 仕様草案。A1〜A3 の後に扱う。対象 `DANCE-001`〜`007`、`DANCE-012`。格闘・掴み・Kip Up・連続技（`DANCE-008`〜`011`）は別仕様。P2 ④の単体モデル／ステージ配置と P2 ⑤の VMD 再生を前提にし、開発中の P2 移植へ割り込まない。

## 目的・依存

複数の PMX/VRM ダンサーに別々のモーションと開始時刻を与え、歌ってみた動画で位置交換、隊形、カノン、ミラー、主役交代、手指・マイク等の操作を非破壊で編集する。`DATA-008`〜`010` の保存／復元、`MOTION-003`〜`009` の実モデル／モーション、`CAM-004` の画角確認、`RENDER-001` の同時描画に依存する。`DANCE-006` の「衝突回避」は距離・経路に基づく編集支援であり、精密な物理衝突保証ではない。

## 利用者の流れ（歌ってみた）

1. `SCR-12` の登録済みモデルを `SCR-06` のシーンに2体以上置き、各インスタンスに固有 ID とトラックを持たせる。ステージ・カメラ・BGM は既存の共通時刻へ配置する。
2. `SCR-13` で各人へ VMD/FBX 由来クリップを割当て、開始位置と速度を調整する。ダンサー A/B を指定区間で交換し、足運びと経路のプレビューを確認する。
3. V字／円／列／千鳥の隊形、カノン開始差、ミラー軸、主役交代を設定する。手指やマイクの保持／持ち替えは `DANCE-012` として別キーにする。
4. `SCR-02/16` で全員の見切れ、`SCR-17` で動画を確認し、必要ならダンサー別 VMD を別ファイルで出力する。元モーションは残す。

## 画面

`SCR-06` はシーンツリーと複数選択、配置ギズモ、隊形プレビュー。`SCR-13` はダンサー別トラック、クリップ開始、ミラー、部位マスク、経路警告。`SCR-12` は各モデルの骨格・小道具接続点を確認する。`SCR-16` は主役交代とカメラ割りを確認する。未接続区画は現行の `◇ 未実装` 表示を維持する。長いダンサー一覧は内部スクロール、再生・保存・Undo は固定領域に置く。選択中の人・クリップ・時間を常に示す。

## データ・保存／復元

- `DancerInstance`: インスタンス ID、モデル資産 ID/hash、骨格プロファイル、root transform、可視状態、ロック、トラック ID。モデル資産自体とインスタンスを区別する。
- `DancerMotionTrack`: ダンサー ID、クリップ元 ID/hash、入力／出力フレーム、開始オフセット、時間倍率、部位マスク、ミラー設定、ブレンド、キーの由来。全員で同一の有理数 FPS とフレーム時刻を使う。
- `Formation`: ID、参加インスタンス ID、pivot、隊形タイプ、各アンカー／オフセット、適用区間。位置交換は元位置・目標位置・通過経路と試算警告を別レイヤーで持ち、確定前に dry-run できる。
- `PropBinding`: 小道具資産 ID、保持者、手指／骨接続点、切替フレーム、オフセット。モデルに該当骨がない場合は未対応とする。
- 保存→再起動→復元で人数、各人の位置／トラック／開始時刻、隊形、手指接続、警告が一致する。削除や位置交換は Undo/Redo 可能。ダンサー別 VMD は新規ファイルへ出し、未対応骨・補間欠落を一覧にする。

## 手動 UI・WebMCP・標準 MCP

共通操作案: `createDancer`、`setDancerTransform`、`assignDancerClip`、`previewSwap`、`commitSwap`、`applyFormation`、`offsetDancerClip`、`setMotionMirror`、`setBodyPartBlend`、`bindProp`、`exportDancerVmdBatch`。三経路とも対象 ID・区間・revision・dry-run 結果を同一サービスで扱う。接触警告は計算方法と閾値を返し、警告なしを「物理的に安全」と言い換えない。MCP に任意の原本削除を公開しない。

## ID 別の受け入れ条件・テスト方針

| ID | 合格条件と試験 |
|---|---|
| `DANCE-001` | 実モデル2体以上に別 VMD と異なる開始フレームを割当て、同時再生・保存復元で維持する |
| `DANCE-002` | A/B 交換の dry-run で経路と足滑り候補を示し、確定後も元キーと Undo が使える。交差／障害物のケースを試す |
| `DANCE-003` | V字・円・列・千鳥を区間適用し、人数不足・重複アンカーを警告する。カメラ画角で全員を確認する |
| `DANCE-004` | カノンの開始差、ミラー左右ボーン表、主役交代区間を独立編集し、カメラと共通時刻で再生する |
| `DANCE-005` | 身体部位マスクと強度を各人別に変更でき、未指定部位・他ダンサーのキーを変えない |
| `DANCE-006` | ダンサー間距離と移動経路に基づく接近候補を時間・場所付きで示し、閾値変更と誤検出を試験する |
| `DANCE-007` | 各人の VMD を別名で一括出力し、モデル名・フレーム数・欠落ボーンを報告。再読込し原本 hash 不変を確認する |
| `DANCE-012` | マイク等の小道具を実骨に接続し、持ち替え区間の位置を再生確認。骨欠損・素材欠損を通知する |

実モデル・実 VMD で結果を確認し、単体と複数体の性能差、Windows/Linux、UI／両 MCP の同値、音声とカメラとの時刻同期を記録する。概算の接触警告と実物理挙動は別判定にする。

## 価値

- 使う側: 複数人の歌唱・ダンス演出を1つのタイムラインで調整し、各人の VMD を安全に取り出せる。
- 売る側: 単体モーション閲覧から複数人のMV制作へ利用範囲を広げ、再利用できる隊形・振付ワークフローを提供できる。

## 未決事項（既定案）

- `O-DANCE-01` 位置交換の自動経路: **既定案** 直線補間と接近警告を基本とし、障害物を考慮する自動最適化は詳細設計と実測後に有効化する。確実性のない自動回避を約束しないため。
- `O-DANCE-02` `DANCE-012` の小道具範囲: **既定案** 既存の登録済み小道具を骨へ接続・持ち替えする範囲。小道具生成・編集は扱わない。機能 ID の範囲を守るため。
- `O-DANCE-03` VMD 一括出力の失敗: **既定案** 各ダンサーを個別成功／失敗で報告し、失敗ファイルを完成物に混ぜない。先行成功と原本を保護できるため。
