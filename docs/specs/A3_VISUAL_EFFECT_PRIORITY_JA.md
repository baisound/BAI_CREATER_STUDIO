# A3 見た目が変わるエフェクトの優先候補

更新: 2026-10-20。状態: **所有者が効果の種類と優先を指定。具体的な外部MME素材の選定は照合中**。機能実装・GPU実測の証拠ではない。実装工程は P2 → E → リップ・表情・歌音声 → F の後のMMDエフェクト段階を維持する。A3の互換方針は [所有者決定記録](A3_MMD_EFFECTS_DECISIONS_JA.md) に従う。

## 所有者の指定と要件への統合

所有者は霧、細かな塵、舞う桜の花びら、きらめき、影の強調、ボケ／ブラーを、**画面で違いが分かる効果として優先**するよう指定した。既存の `RENDER-012`（内蔵描画効果）、`RENDER-013`（発光・煙・粒子の時刻付き演出）、`RENDER-014`（対象・強度・順序・キー）に統合する。原MMEの`.fx`そのものをブラウザーで実行するという意味にはしない。

| 優先候補 | 要件ID・初期の見せ方 | 実装候補と検証の要点 |
|---|---|---|
| 霧 | `RENDER-013/014`。まずシーン全体の奥行き霧を色・濃度・範囲で調整し、開始・終了区間を持たせる | `three@0.160.1` の `Fog/FogExp2` を候補にする。奥のステージと手前の人物に差が出るか、背景・透明物・書き出しとの整合を比較する。局所的な体積霧は別の実装検証を要し、初期受入と同一視しない |
| 細かな塵 | `RENDER-013/014`。少量から増やせる空間粒子を舞台に配置 | `Points` またはインスタンス化を候補にし、粒径・密度・風向・速度を固定フレームで評価する。再シーク後と動画出力で位置が一致するか、透過順序と描画負荷を測る |
| 桜の花びら | `RENDER-013/014`。花びらの発生場所・数・落下・回転・寿命を区間で制御 | テクスチャ付き板ポリゴンのインスタンス化を候補にする。近景と遠景の大きさ、モデルとの前後関係、アルファ輪郭、30/60fpsの軌跡を確認する。外部テクスチャは素材ごとの許諾を確認する |
| きらめき | `RENDER-012/013/014`。点光の粒子と必要範囲のBloomを組み合わせる | `Points`またはスプライト、`BloomPass/UnrealBloomPass`を候補にする。閾値・強度を調整して衣装の明部だけが過度に白飛びしないか確認する |
| 影の強調 | `RENDER-012/014`。ライト・影の強さ・柔らかさを対象とショットで調整 | 既存レンダラーのshadow map、ライトと材質の対応を先に監査する。接地影と顔・衣装の陰影が実際に変わり、影の縞・ちらつき・黒つぶれが増えないか確認する。単なる画面全体の暗化を「影」としない |
| ピントのボケ | `RENDER-012/014`。カメラ焦点と連動するDOF | 同梱の`BokehPass`を実装候補にする。焦点面、前景・背景のボケ量、髪や花びらの透過境界、動画との一致を代表フレームで確認する |
| 動きのブラー | `RENDER-012/014`。MotionBlurのシャッター角・区間 | 固定フレーム間の動き情報またはサブフレーム評価が必要かを先に測る。任意シークとレンダー再試行で過去フレームの残像が混入しない設計にし、他の優先候補の後で品質ゲートを通す |

これは**実装順の候補**であり、各効果の実機能を実装済みとは扱わない。まず霧、塵・花びら、きらめき＋Bloom、DOF、影の強調を同じ短い実シーンで比較し、差が明瞭で性能・透過・出力が許容できるものから公開する。MotionBlurは固定フレーム／任意シークの品質ゲートを別に通す。`RENDER-012` の承認済みAutoLuminous風発光もきらめきの発光表現と接続して検証する。

## 部品の根拠と利用境界

この作業環境の`package.json`は `three@0.160.1` を固定しており、同梱ソースに `FogExp2`、`Points`、`InstancedMesh`、`BloomPass`、`UnrealBloomPass`、`BokehPass` が存在する。これらは**実装候補の存在確認**であり、現在のPMX/VRM表示器との接続やGPU実測を示さない。外部効果素材を取り込む前に、そのファイル・依存テクスチャ・版・許諾を別々に調べる。Three.js本体は同梱のMITライセンスに従う。

参考: [Three.js FogExp2](https://threejs.org/docs/pages/FogExp2.html)、[Points](https://threejs.org/docs/pages/Points)、[InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html)、[公式WebGL例](https://threejs.org/examples/)。

## 共通の比較素材と受け入れ

実PMX/VRM、奥行きのあるステージ、単色と透過背景、前後を横切る花びら、明部のある衣装を含む短いシーンを使う。各効果のOFF/ONを**同じカメラ・同じフレーム・同じ品質設定**で保存し、見た目の変化と副作用を記録する。フレーム0・中間・末尾、カメラ切替、任意シーク、30/60fps、動画再読込を比較し、プレビューと書き出しの差を別々に報告する。GPU負荷と品質段階も測り、能力が足りない環境では未対応理由を表示する。

持込MME素材については、以前ChatGPTで選ばれた候補の具体名・出典が分かり次第、この表の用途に対応付け、作者・版・ライセンス・依存ファイル・MMD参照映像を照合する。それまでは外部素材の名前や再配布可否を推測しない。
