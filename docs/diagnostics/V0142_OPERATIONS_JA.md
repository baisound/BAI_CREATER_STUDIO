# v0.14.2 実機診断・操作ログ

- `診断` タブでONにすると主要なボタンクリックを `data/logs/ui_actions.jsonl` に記録。OFFなら記録しない。
- UI操作ログは1MiB×最大4ファイル。フォームの値、名前、パス、マウス移動を記録しない。
- `診断ZIPを保存` は稼働中ファイルの内容をスナップショットとしてZIPに取り込む。サーバー停止不要。スクリーンショットを自動同梱しない。
- `/api/sync` の正常応答をアクセスログから除外。異常な応答は記録。
- `/webmcp.js` をHTTP配信する。WebMCP本体のブラウザ動作は別途実機検証。
- DOMのNotFoundErrorは発生元未確定のため今回未修正。再発時はUIログとブラウザConsoleで発生操作を特定する。
- 画面レイアウト改修とGLB再生停止、PMX ZIP統一、3画面カメラ修正は今後の別工程。
