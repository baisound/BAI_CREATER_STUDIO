# 旧保存を v0.5 の作品へ取り込む操作説明

対象: v0.5（`/studio/v05`）のプロジェクト一覧。設計は[旧保存→v0.5取込設計](../roadmap/LEGACY_STATE_TO_V05_MAPPING_DESIGN_20261104_JA.md)。要件IDは `DATA-008`（状態は「要検証」のまま）。

## 手順

1. 旧画面（`/` または `camera.html`）で、取り込みたい作品を開いた状態にする。旧保存はパソコン全体で1組なので、いま開いている作品が取り込まれる。
2. v0.5のホームで［＋ 新規作成］を押し、空の作品を作る。
3. その作品カードの［現行編集を保存］を押す。
4. 同じカードの［旧保存を取り込む…］を押す。表示された「写るもの／写らないもの」と取込元の名前を確かめ、［取り込む］を押す。

## 対話画面の見かた

上から順に並ぶ。

- 取込元：旧保存の名前、スナップショットを保存した日時（日本時間）、キャラクター、ステージ。別の作品を取り込む誤りを防ぐため、必ず確かめる。
- 写るもの／写らないもの（取込記録に残ります）：写るものは作品のFPS・再生位置・キャラクター・ステージなど。カメラの動きなど、v0.5でまだ保存先がないものは写さず、取込記録に元の値を残す。
- 追加の取込（既定はオフ）：「曲とダンスの画面（SCR-10）の曲とダンスも取り込む」「旧タイムライン編集の動作も取り込む」。この2つは作品ごとではなく、パソコン全体で1つの保存。取り込みたい作品の内容になっているか旧画面で確かめてから選ぶ。保存がないものは選べない。チェックを変えると確認をやり直す。
- 詳細（最初は閉じている）：項目ごとに「写す／写さない／注意」とその理由。
- 用語：「スナップショット」「FPS」「取込記録」は点線の下線に説明が付く（マウスを載せる）。

## ボタン

| 状態 | 押すボタン | 押したとき |
|---|---|---|
| 取り込める | 取り込む | 確認が出る。［取り込む（確定）］で書き込む。［やめる］は何も送らず何も書かない |
| 作品のFPSが旧保存と違う | 作品のFPSを○fpsに変えて取り込む | 同じ確認のあと、作品のFPSを旧保存の値へ変えて取り込む（取消で元に戻る） |
| 確認のあとに保存が変わった | もう一度確認する | 確認をやり直す |
| 空でない作品など、ほかの拒否 | なし | 理由の文に、次に押すボタン名が書いてある |
| 取込済み | 取込を取消 | 確認が出る。［取消（確定）］で、取り込んだキャラクター・ステージ・クリップを（あとで動かした分も含めて）削除する。再生位置はそのまま。表情キーなどを加えていると、止めて内容を知らせる |
| 前回の取込・取消が途中で止まっている | 取込を取消 | 確認のあと取込前に戻す |

結果は対話画面の下の行に出る（例：「取り込みました：写したもの7件、写さなかったもの5件、注意2件」）。取込・取消が終わると、3D場面・タイムライン・作品のFPSの表示は自動で更新される。

## 制限

- 旧の保存ファイル、スナップショット、素材の原本は書き換えない。
- AI用の窓口（標準MCP・WebMCP）から取り込んだときは、開いている画面へ知らせない。作品を開き直すと反映される。
- 取消の事前点検と打ち消しの間に、ほかの画面での編集が入る時間差が残る（ほかの編集APIが同じロックを取らないため）。各処理は版（revision）を照合して競合を検出するが、事前点検の対象までは保証しない。取消の前後は、ほかの画面で同じ作品を編集しない。
- 見た目の大きさの一致とカメラの動きの取込は、まだできない。
