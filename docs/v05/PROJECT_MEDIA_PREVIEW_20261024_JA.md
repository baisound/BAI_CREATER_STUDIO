# v0.5作品の画像・動画・音声プレビュー — 2026-10-24

関連: Issue #63/#69、DATA-008、AUDIO-001、v0.5最短制作経路の順2。

## 接続範囲

保存済み作品IDのタイムライン配置から、登録済み画像、MP4/WebM等の動画、WAV/MP3等の音声クリップを編集画面へ読み込む。作品FPSと保存済み再生位置を使い、フレーム移動、再生、一時停止、停止を同じ時計から操作する。クリックまたは停止時の再生位置は既存の作品別APIへ保存し、再読込後に復元する。作品切替時は前作品の動画・音声を止め、遅れて届いた応答を破棄する。

描画はブラウザの画像/動画要素、試聴は音声要素を使う。複数の画像・動画は開始時刻順に重ねる。動画ファイルに含まれる音声は重複再生を防ぐためミュートし、別の音声クリップだけを再生する。元ファイルの再生時間を超えると無音・空画面の理由を示す。素材パスは既存の登録APIから許可されたIDへ解決し、原本は変更しない。

## 限界

ブラウザの動画シークと音声要素にはフレーム精度の保証がない。実動画出力、音声多重化、複数トラックの正確な合成、3Dモデル・ステージ・モーション・カメラと同じ画面での描画は未接続。配置できたことだけで全形式の再生成功を示さず、読込失敗や未対応形式を画面に出す。既存の3Dプレビュー経路は保持する。

- 同試験と素材管理をまとめた5件成功。作品同期・範囲・素材との最初の結合9件は8件成功・1件失敗。失敗は新プレビューが追加画面の前面に出て素材ボタンを覆ったことが原因。重なり順を修正して素材管理と新プレビューの5件を再実行し、全件成功。
- `npm run typecheck`とJS構文確認成功。隔離試験前後に利用者`data/`7ファイルと`exports/`のハッシュ一致。実利用者の長尺メディア、GPU、Linux、MCP、レンダー出力は未検証。
