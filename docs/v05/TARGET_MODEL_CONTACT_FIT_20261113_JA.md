# 元モデル不明のVMDを適用先PMXで補正する設計

Owner追加指定：VMDごとに元モデルが異なり、元PMXの保存場所は不明。それでもモデルに合わせて調整できるようにする。既存ID MOTION-005/010/011/012/019、Issue #39/#63へ統合する。元骨格を復元できたと表示しない。素材ごとの元骨格情報を個別に保持し、他のVMDへ一律に流用しない。

## 最初に実装する範囲

元骨格を得られないVMDは、対象PMXの実際の骨・脚長・足裏を使った**区間指定の接地補正**として扱う。手足を常時床へ固定しない。ユーザーが接地させる足と区間、床の高さを指定し、その区間だけ補正する。手の補正は既存の明示的な腕IK目標と差分層を使い、目標のない手を勝手に動かさない。GLB/FBXには元骨格があるため別経路で実チェーン長を使い、衣装や髪を含むmesh全高を体格の根拠にしない。

上位3操作は「補正する素材/モデル/区間を確認」「接地補正を作って比較」「適用・保存し同じプレビュー/MP4で使う」。3D操作パネルの既存の足診断区画を「体格・接地の補正」とし、元モデル不明・対象VMD/PMX・対象Fを短く表示する。詳細の根拠/残差は折りたたむ。既存の読み取り診断、手動FK/IK、候補VMD検査、Undo/Redoへの到達性を保つ。

## 計算と保存の契約

- まず2秒以内の指定区間を扱う。対象は読み込み済みの単一PMX/VMDの明示割当。左右どちらの足かを指定する。停止中に作成し、途中の作品/素材/割当/revision変更で破棄する。
- 足裏は対象足のウェイトを持つ実頂点から測り、つま先骨だけで接触を証明しない。骨/頂点/IKがないモデルは理由を示して拒否する。床の高さは明示値を使い、未知のステージ床を推測しない。
- PMXの足IK制限と実チェーン長を使う。現在の足裏位置から、指定区間の最初のX/Zと床Yへ近づける差分キーを既存のIK評価前に適用する。跳躍等の大きい移動、到達不能、過大な補正、膝の反転、対象外骨の変化は候補から除外する。
- 元動作・他の足/手/表情は保持する。区間の前後に短いフェードを置く。完全な接地はフェードを除く内側で判定する。FKへ切替済みの脚には足IK補正を重ねない。
- 一時候補はブラウザー内の既存の差分層の評価経路で比較し、破棄で元へ戻す。保存は`motion_edits`へ1回の原子的な操作で層とキーを追加する。instance/clip/PMX・VMD hash/FPS/区間を既存契約に結び、最大キー数/層数/競合を検査する。原PMX/VMD/GLBは変更しない。
- 標準MCP/WebMCPも同じ保存APIを使い、保存後の再読込、無効化/Undo、プレビューとMP4が同じ差分キーを参照する。VMDへの別名ベイクは既存候補作成/`validatePmxVmdCandidate`を再利用し、未検査の候補をMMD再現合格としない。

## 受入条件

1. 異なる脚長の同一系列PMXと同じVMDで、補正内側の足裏高さ・滑り・到達残差が指定許容内へ改善する。
2. 区間外、非対象の足/手/表情、跳躍・踏み替えを保持する。大きい変更が必要な区間は拒否し、原本・保存済み層を保持する。
3. ランダムシーク/途中再生/保存再読込/Undoで同じ姿勢。差分の二重適用がない。
4. 実プレビューとMP4が同じ補正を評価し、足裏の画素/座標も確認する。物理OFFの骨補正と物理ONは別々に確認する。
5. 手動UI/API/両MCP、Windows/Linuxの検証状況と、元モデル不明ゆえの限界を区別する。

全VMDの意味的な接地区間の自動推定、元モデルの正確な体格復元、未指定の手の接触位置推定、衝突/接触力や一般の物理完成はこの単位の合格に含めない。既存の腕IK操作は維持する。

## 3視点批評を受けた固定事項（実装前）

Critic1は初手・認知負荷、Critic2は作業/検証経路、Critic3は可読性/アクセシビリティを確認。Root Judgeは以下を採用し、設計段階の着手可とする。実装/実画面の合格ではない。

- 区間は**作品上のフレーム `[開始F, 終了F)`**。秒と作品FPSを併記し、現在位置から設定可能にする。床Yは世界座標のシーン単位とし、3D上に床の目印を出す。長いモデル/素材名は全文を確認できる表示を備える。
- フェードは指定区間の**内側**に置き、その区間だけを変更許可範囲とする。既定は前後各0.1秒を作品Fへ切上げ。内側に2F以上の完全接地区間が残らない場合は拒否する。区間外は元VMD＋既存有効補正のまま不変とする。
- 基準姿勢は元VMD＋既存の有効層。許可変更は対象足IK、実際のIKチェーン/足先の子、PMX定義の付与先。反対の足・手首・頭・表情は独立に不変確認する。候補作成中の既存層、作品/配置/シーン/FPS、原本hashの変更は保存時に検出して拒否する。
- 完全接地部の各Fで、足裏の高さ・水平位置・IK到達誤差の最大値を検査する。許容は`max(0.0001, 対象脚長×0.003)`シーン単位。補正移動量は対象脚長の10%以下。対象外の観測点の最大差は0.00001シーン単位、表情値差は0.000001以下。膝はPMX IK制限を守り、曲げ平面を比較できる元姿勢では平面反転を拒否する。
- 「未作成／計算中／候補・未保存／保存済み／拒否」を文字で区別。「補正候補を作成」→「補正前／候補の比較」→「補正を保存」の3操作にする。破棄は候補を作る入口へfocusを戻す。保存/比較/破棄はキーボードで操作可能にし、入力エラーは該当箇所へ戻す。
- 過大補正/不達は区間を短くする・床高を確認する・既存の手動IKへ移る導線を示す。欠損IK/FK脚/到達不能/途中競合は**無保存で終了する負例試験**を必須とする。
