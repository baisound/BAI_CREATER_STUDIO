# v0.5 実PMX表情・口モーフ時刻キー（Issue #96）

## 利用者に見える範囲

同じ作品の3DプレビューでPMXモデルを選ぶと、読み込んだ実PMXに存在するモーフ名から表情・口を選べる。作品の共通シーク位置を時刻欄へ入れ、0〜1の強さを保存する。保存済みキーは選択して値を直すか削除できる。原PMX・VMDは書き換えない。

キーは`scene/instances`の作品別revision付き`face_keys`に保存する。従来ファイルにこの欄が無くても空配列として読む。シーンモデルを削除したとき、そのインスタンスのキーを一緒に除く。古いrevision、ロック済みモデル、範囲外値、登録PMXにない名前を保存APIが拒否する。登録原本が欠けても、孤立キーの削除はできる。

共通時刻のシークでは、まず既存のVMD/動作を評価し、その後に保存表情キーを適用する。最初のキーより前は元の動作の顔を使う。キー間は線形補間し、最後のキー以降は値を保持する。限定MP4の各3Dフレームも同じ順序で評価する。保存キーが実モデルから消えていれば出力を止め、顔だけ抜けた完成品を作らない。原素材のhash検査と720p・300F上限は既存の書き出し契約を継続する。

## 2026-10-24 追補：共通タイムラインの表情・口行（Issue #96）

保存済みキーを作品の既存タイムラインの「表情」「口」行に表示する。各モデル・モーフを別の高さに並べ、キーを押すと同じ作品の3Dプレビューが開き、時刻・値・実モーフを編集できる。横ドラッグまたは左右矢印で時刻を移す。既存の吸着オン/オフとグリッド間隔、時間倍率を共有する。移動は`face-move`で元キーの値・行を保ったままrevision付きで保存し、同一モデル・モーフ・移動先時刻の衝突を拒否する。行のロックはAPIでも保存・移動・削除を拒否する。元のPMX/VMDは変更しない。

## 2026-10-24 追補：表情キーのUndo/Redo

作品別sceneファイルに、表情キー編集の逆操作を最大32件保存する。追加・値/行の変更・時刻移動・削除を、共通タイムラインと3Dプレビューの「表情キーを戻す」「表情キーをやり直す」から1操作ずつ復元する。変更後の新規編集はredo履歴を消し、モデル削除は関連キーと履歴を消す。旧sceneファイルの履歴欄は省略可能。各操作はscene revisionを照合し、ロック中のモデル/表情・口行、占有済み移動先、存在しない実PMXモーフへの復元を拒否する。原PMX/VMDと古いsceneファイルは上書きしない。

Python 11件で保存再読込、移動/追加/削除/値と行の変更のUndo/Redo、旧revision、ロック行、編集後のredo消去を確認。隔離Chromeの実PMXで4→5秒へ移した「まばたき」をUndoで4秒、Redoで5秒へ戻し、タイムラインのキー位置と保存revision 4→5→6を確認した。原PMX/VMDと利用者data 7件のハッシュは前後で一致。限定MP4のGLB・保存カメラ・実PMX/VMDは再実行で3件成功。最初のMP4再実行では隔離Chromeの作品一覧読み込みが従来の45秒待機で切れたため失敗し、描画起動待機を75秒、描画プロセスの最短タイムアウトを180秒へ調整して再実行した。既存の限定MP4は保存scene revisionとキーを読んで描画するが、Undo/Redo直後のMP4を別途デコード比較する試験は未実施。

値のタイムライン上での縦編集、複数キーの一括操作と一括Undo、視線、自動リップ、長尺、他PMX/Linux/MCP実運用と全区間同期は残る。ここでのUndoはPMX表情キーに限定し、アプリ全体のUndoとは統合していない。
