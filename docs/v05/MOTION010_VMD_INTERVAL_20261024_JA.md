# MOTION-010 修正区間だけの別名VMD候補

2026-10-24、Issue #106。既存の通常候補に加え、v0.5作品の3D編集画面で「修正区間のみ」を選べるようにした。元PMX/VMDは読み取り専用で、作成時は未採用候補のまま。前段の実PMX全骨・全フレーム検査に合格した候補だけが明示採用できる。

## 保持条件

修正レイヤーが一つの共通区間を持ち、その開始・終了がVMD 30fpsフレームに一致し、対象骨の元VMDに両境界のキーがあるときだけ出力する。開始境界の補正は0であることを確認する。対象区間の内部だけに候補キーを作り、境界を含む区間外の既存骨レコードとモーフ等の非骨区画はbyte単位で比較する。候補の局所姿勢を作品の全フレームで照合し、位置1e-3 MMD単位・角度0.01°を超える場合は生成しない。実PMXのIK/grant後の一致は画面の別検査で判定する。

境界キーが無い、境界が30fpsへ正確に写せない、開始時に補正が残る、複数レイヤーの区間が異なる、またはVMDの30fps制約で誤差が増える入力は、元データを変更せず理由を示して拒否する。通常候補は従来の経路として残す。通常候補を「全フレームをキー化したVMD」とはまだ呼ばず、その要求は未完了として追跡する。

## 残る条件

区間外キーを絶対に変えないため、修正区間モードは保守的に拒否する入力がある。複数の異なる修正区間、元VMDに境界キーが無い入力、物理ON、実GPU、Linux、標準MCP、Owner採用は未確認。通常候補の全VMDフレームキー化と、元VMDの長さが配置クリップより長い場合の出力範囲も未整理。MOTION-010全体は「要検証」。画像・動画の納品成果物は作っておらず、Eagle登録対象なし。モデル区分: 設計・実装・検証に標準モデル区分を使用。
