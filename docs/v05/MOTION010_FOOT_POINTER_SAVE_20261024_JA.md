# MOTION-010 足IKの実ポインタ補正を保存・復元する検査

2026-10-24、Issue #106。[足首位置に置く3Dハンドル](MOTION010_FOOT_HANDLE_SNAP_20261024_JA.md)の次のゲート。新しい操作コードは追加せず、実PMX/VMDを使った画面試験を、実マウスドラッグからキー保存・Undo/Redo・画面再読込まで伸ばした。

隔離作品のF240で、既存の左足IK補正キーと保存済みIK編集方法を読み込んだ。足首位置のハンドルを実マウスでドラッグすると、未確定プレビューで左足IKターゲットと左足首がともに移動し、右足首は変わらなかった。「このFをキー化」で同じ骨・フレームのキーを更新し、作品revisionが1増加。表示中の足首姿勢は仮表示と一致した。Undoを1回行うと直前の保存姿勢とキーへ戻り、Redoで補正後の姿勢とキーへ戻った。IK編集方法はこの操作で変わらず、画面再読込後も足首姿勢が一致した。
