# MOTION-010 腕ハンドルの連続仮表示と右腕保存

2026-10-24、Issue #106。腕の手先・ひじハンドルを動かしている間、描画フレームごとに最新のポインタ位置から腕・ひじ2骨を仮評価する。保存APIはマウスを離して［このFをキー化］するまで呼ばない。Escはドラッグ開始前の仮表示へ直ちに戻し、マウスを離しても再適用しない。手先が届かない場合の差分表示と1操作2キー・1 Undoは既存経路を使う。

右腕の強い複合補正を別名VMD候補へ通した際、検証器が行列分解後の四元数の微小な長さ誤差を角度差として数え、実PMXで0.02338°の不合格を報告した。比較前に両四元数を正規化し、非有限・ゼロ長は拒否する。単体試験で同じ向きの微小ノルム差を0°相当、真の0.5°差を0.5°と測ることを確認した。誤差上限0.01°は変えていない。

|---|---|---|---|

隔離Chrome/SwiftShader、実VMD1本、作品F240、物理OFFで実ポインタを使用。候補検査は作品600F＋VMD300F × 全骨、位置上限1e-3・角度上限0.01°。左右腕のFK/IK切替、既存の脚FK/IK・膝ハンドルも回帰成功。`node --test tests/studio-v05-vmd-candidate-angle.test.mjs`、`npm run typecheck`、Node構文確認、`git diff --check`は成功。元PMX/VMDと利用者`data/`・`exports/`のSHA-256は前後で一致。候補は未登録・未配置。
