# MOTION-019 / CAM-019：タイムラインのPMX二次物理

Issue #238 / #39 / #63。前回の撮影用コピーでは未有効だった髪・紐・衣装の物理を、同じ保存シーン・時刻のプレビュー、CinemaOperatorコピー、MP4へ接続する。

## 設計・受入契約

- 既存作品は物理OFFを維持。選択PMXに対して「この作品でMMD物理を使う」を保存し、手動UI/共通API/両MCPから同じ設定を扱う。元PMX/VMD、旧画面の設定と完成動画は保持。
- Studioの現行VMD/GLB適用・FK/IK/接地補正を評価した後、既存の`pmx-physics-preview.js`と同じAmmo/MMDPhysics・基準姿勢初期化・髪/紐の骨長維持を使う。PMXメタデータはコピーのみ。
- 物理姿勢は作品先頭から固定60Hzで非同期に生成し、動的骨の局所位置/回転だけをメモリーへ記録。任意シークは同じキャッシュを補間する。表示FPS/逆シーク/非0In/ブラウザー時刻で積分経路を変えない。各モデルは独立した物理world。
- 動的骨キャッシュは最大600秒/128MiB。範囲・容量を超える作品は省略せず準備を拒否。キャンセル/作品変更/再読込は所有するworldと旧キャッシュを解放する。演算器版と保存設定を撮影コピーの依存へ含める。
- モデルの表示区間がある場合はその終端、常設モデルは作品終端まで準備。表情・口の現在値は既存経路を保持。FK等の未保存仮編集では物理を一時停止して明示し、保存した補正では再準備する。
- 有効化したモデルの読込・物理準備に失敗した場合、成功表示や物理なし出力へ進まない。身体だけを既存どおり使うには物理をOFFへ戻す。

上位3操作：①対象PMXで有効化し保存、②同じ時刻で再生・シーク、③CinemaOperator/MP4へ出力。既存の3D操作パネルへ設定と準備状態だけを追加する。

生成PMXと実登録PMXで、物理ON/OFFの差、骨長/有限値、F0/中間/末尾/逆シーク/再読込、30/29.97/60fpsと非0In、複数モデル/クリップ切替、保存補正とOFF旧作品、手動/両MCP、実Blenderコピー/MP4を確認する。Windows/Ubuntu・実GPU/実素材・未検証を分けて記録し、CAM-019/物理全体を完成にしない。

実装：PMX別の保存設定、絶対時刻60Hzキャッシュとtype2位置保持、合計128MiB上限、非等方倍率/傾斜配置の拒否、保存補正/口形更新の再準備、失敗/中止/OFF回復を接続。途中の物理姿勢は公開せず、元PMX/VMDと補正・口形・表情マップの変更を準備前後に照合する。

予備検証：Python保存/異常入力1、計算/取消/容量3、実Chrome/AmmoのOFF互換・ON差・逆シーク/再読込・静的PMX再準備・補正保存通知・両MCP・非0In45F MP4と同時刻画像比較1、型チェック成功。実Blender試験の初回は試験中の評価器編集を依存保護が検出して拒否。実Blender/両OS/実PMX等は続く検証段階であり、現時点では未完。

3視点批評のP1：保存FK/接地で旧cacheを使う経路と、無割当PMXの旧姿勢混入を修正し回帰を追加。対象名・未保存/準備/使用可・中止/再準備/OFFと出力からの設定入口を配置。
