# v0.5動画内音声の限定MP4接続（2026-11-05）

対象はロードマップ順3、Issue #81/#69、`RENDER-006` と `DATA-002`。動画クリップの元素材に音声トラックがある場合、保存済みの `source_start` と `duration` で音を切り、作品の `start` に置いて独立音声・楽曲と同じFFmpegグラフへ混ぜる。音声トラックがない動画は従来どおり無音で出力する。音声素材なのに音声トラックがない場合は理由を返して停止する。作品プレビューの動画要素もミュートせず、クリップが有効な区間で再生・停止する。入力hash、revision検査、別名ジョブ、完成MP4のH.264/AAC再読込は既存経路を維持する。

## 確認した範囲

- `tests/studio-v05-media-render.test.cjs` は隔離作品へ動画内音声付きMP4を登録し、元動画の先頭に無音を含む素材を `source_start=1` 秒で切って作品 `start=0.5` 秒へ置く。保存後の元位置をAPIで読み直し、78FのH.264/AAC完成MP4を再読込する。
- 原本の0.6秒は無音、1.1秒は実音。完成物の0.1秒は無音、0.6秒は実音（8 kHz復号PCMのRMSで判定）。この隔離入力では、元位置と作品開始時刻の双方を反映した。Chrome画面で動画要素の `muted=false` を確認した。ブラウザーから実際に聞こえる音と長尺同期精度は未計測。
- 既存の画像・独立WAV・無音動画の60F出力、二度目の別名出力、3Dを欠かす要求の拒否と旧完成物の保持も同じ試験で成功した。
- `CHROMIUM_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe`、`BAI_TEST_CONCURRENCY=1` で `node tests/run-guarded.cjs tests/studio-v05-media-render.test.cjs` は1件成功。利用者の `data/` 5ファイルと `exports/` 0ファイルは前後でhash一致。`npm run typecheck`、Python・Node構文確認も成功。隔離試験は実GPUや所有者の実動画を使っていない。

最初の試験起動はPlaywright既定ブラウザーが見つからず失敗し、インストール済みChromeを指定して再実行した。音声元区間の試験は生成素材の無音区間を実測して修正した後に成功した。失敗試行を合格件数には含めない。

実MP4/WebM/OGVの音声、複数動画・独立音声が重なる実作品、可変フレームレート、長尺の先頭・中間・末尾で1映像フレーム以内の音画同期、WebMCP・標準MCP、Linuxは未検証。`RENDER-006` 全体と順3全体は完成扱いにしない。次は300Fを超える3D出力を実測してから上限の変更を判断する。
