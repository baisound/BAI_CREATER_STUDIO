# PMXの髪・紐が伸びる表示の修正

Issue #39/#63、AUDIO-001・MOTION-010/019の既存プレビューに関するOwner追加報告。元モデル/動作/制作中の画像・ログは公開せず、詳細な再現証跡はOwnerのローカル確認フォルダーへ保管する。

## 実装した変更

物理ジョイントはPMXの基準姿勢で構築し、構築後に表示していた動作姿勢へ戻す。動作を適用した姿勢で、基準姿勢のジョイント座標を解釈していた不整合を修正した。

加えて、髪・紐などの名前で識別できるアクセサリーの動的剛体を、**アプリ内のコピーだけ**PMXの標準の位置合わせ付き物理（回転は物理、位置は骨へ合わせる方式）へ適応する。これにより、揺れを残しながら骨長とウェイトが引き伸ばされることを防ぐ。衣装全体の物理を停止せず、元PMXの剛体種別・骨・ウェイト・GLB/VMDを書き換えない。プレビューには「髪・紐は長さを保持して揺らします」と表示する。

これは原PMXの自由移動を完全再現するモードではない。髪・紐の伸びを抑えるプレビューの対応であり、未知の骨名の全モデル、伸縮を意図した表現、衣装/衝突/全物理の完成を保証しない。タイムラインの3D動画出力へMMD物理を新たに追加した変更でもない。

## 検証

- 合成した髪チェーンで、回転済みの姿勢から初期化しても姿勢が変わらず、実Ammo物理の回転が続き、連続再生/シーク後も骨長を保つこと、入力の物理メタデータが不変であることを確認。`tests/studio-pmx-physics-bind.test.cjs`。
- 代表の実PMX/GLBを隔離コピーし、約60秒の全フレームの連続物理と、開始/中間/終端/往復シークで髪・紐の範囲を測定。修正前の同じ判定は失敗し、修正後は合格した。元PMX/GLB/テクスチャのhashは不変。実素材の結果JSON/前後画像はローカル証跡へ保持する。`tests/studio-pmx-physics-integrity-real.test.cjs`は環境変数で指定した素材だけを読み取り、公開fixtureへ素材をコピーしない。
- 初期化修正だけの短い試験は合格したが、全尺では残存不具合を検出した。剛体の回転オフセットがあるため局所骨長の倍率だけで判定せず、PMXのジョイント位置/移動制限と、全チェーンの到達範囲も測定した。反復数/刻み幅の調整や頻繁な物理リセットだけで直った扱いにせず、それらの試行は撤回した。
- 最終コードは標準の物理刻み/反復へ戻し、基準姿勢での構築＋対象アクセサリーの位置合わせ方式を採用した。合成物理・音声時計・既存リターゲット・タイムライン/カメラ/表情の回帰6件と型検査が成功。実行証跡はOwnerのローカル確認フォルダーに保管し、公開コミットへ含めない。

実素材全形式/全物理・Linuxブラウザーは未検証。元骨格が不明のVMDの体格差補正は、この髪・紐の対策とは区別し、[対象PMXでの接地補正設計](TARGET_MODEL_CONTACT_FIT_20261113_JA.md)で継続する。
