# MOTION-010 実PMX検査済みVMD候補の採用と復元

2026-10-24、Issue #106。対象はv0.5作品で保存済みのPMX＋VMD補正を別名VMD候補へ焼いた後の明示的な採用経路。候補を作成しただけ、または構造検査だけでは登録・配置しない。

## 利用者に見える動き

1. 作品の3D編集画面で別名VMD候補を作り、［実PMXで全骨・全Fを検査］を実行する。物理OFFで作品フレームとVMD 30fpsの全標本を照合し、位置1e-3 MMD単位・回転0.01°以下のときだけ［検査済みVMDをこの作品へ配置］が有効になる。
2. 配置ボタンは候補と原PMX/VMDのSHA-256、補正・作品配置・シーンのrevision、クリップ時刻と対象PMXをサーバーで再確認する。別名VMDは`data/mmd/vmd/MOTION010-<候補ID>.vmd`へ登録し、**同じクリップID・時刻・尺・対象PMX**の素材参照だけを切り替える。元VMD、候補、保存済み補正レイヤーは保持する。
3. 焼き込み済み補正レイヤーは`baked_into_candidate`として無効化し、プレビュー・MP4書き出しで二重適用しない。別の不整合レイヤーは従来どおり書き出しを停止する。［元VMDへ戻す］は原VMDのSHA-256を確認して同じクリップへ戻す。別名VMD素材と検証記録は残す。

検証報告はブラウザが実PMXのIK/grant評価後に作成し、サーバーは標本数・閾値・素材指紋を検査して記録する。サーバー単独でGPU/物理評価を再実行した証明ではない。登録済み候補ファイルと索引、作品配置は別ファイルのため、途中失敗後の再試行で索引・メタデータを再照合する。原本や既存クリップを削除しない。
