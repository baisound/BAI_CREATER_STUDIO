# v0.5作品の3Dシーンと音声の共通時計 — 2026-10-24

関連: Issue #39/#40/#50/#63/#69、DATA-008、AUDIO-001、MOTION-003/006。最短制作経路の順2に対する部分接続。

## 接続範囲

保存済み作品の画像・動画・独立音声プレビューのフレーム時計を、既存の複数モデルWebGLプレビューに通知する。同じ作品IDの3D画面から1F前後、再生、一時停止、停止を操作できる。3D画面を開いた時点のフレーム、途中のフレーム進行、作品切替後の時刻を既存のモーション評価に渡す。音声クリップが無くても、3D画面を開いてモデルを読み込んだ作品であれば、モーション等の保存済み範囲の時計を進められる。

3Dのモデル配置と動作対象は既存の作品別scene/instancesとmulti-motion-planを利用する。既存のGLB/PMX/VRM/FBXローダーやウェイトには変更を加えない。3D画面は元からある別画面のままで、画像・動画を重ねる編集ビューポートと画素単位では合成していない。WebGL読込件数とモーション読込エラーを分け、骨の不足した動作は画面に理由を残す。

## 限界

試験用GLBには人体骨が不足し、GLB動作の読込は既存プレイヤーが拒否した。このため実ダンスの変形品質・顔・PMX/VMD・カメラ・ステージの位置合わせ・3Dを含むMP4出力は未確認または未接続。ブラウザ時計と音声素子のズレが全区間で1F以内かも未検証。3Dと画像・動画の画素合成、同一カメラ出力、旧作品の完全移行が終わるまで順2/3は完了扱いにしない。
