# 検証済み連番からMP4を再生成（2026-11-19）

RENDER-006/010、A2 F-03の承認済み復旧。MP4のバイト途中からの再開ではなく、保存した同じ制作状態の検証済みPNGから新しいH.264/AAC動画を作る。

## 採用する方法と終了条件

Solution Review：既存PNG checkpointを再利用する方法を採用。全動画に一律のPNG保持を追加すると容量/速度の既存経路を変えるため、作品の出力設定でH.264 MP4の保持を選択可能にする。保持は既定OFF、最大2GiB/ジョブ。保持した先頭PNGと同じ3D撮影を別ジョブへ複製、音声は元の絶対標本範囲で再生成し、全フレームからMP4を再エンコードする。FFV1だけを正本にする別の復旧基盤や新しい形式は追加しない。

元ジョブの保存状態/素材/描画実装・ツールhashを照合し、不一致/改変/欠番は投入拒否。通常の再試行は保持データのない旧ジョブにも残す。元checkpointと旧完成物は自動削除しない。

上位3操作：保持を選び設定保存、失敗履歴の保持枚数と再生成操作、完成MP4の受取。既存画面内だけで行う小規模拡張。

今回の終了条件は保存復元、非0In/有理数FPS、失敗/再起動からの再生成、実完成物の映像/音声/フレーム数・旧版保持、改変/条件差の拒否、手動/両MCPと両OSの代表確認、PR/main/8765同期。HDR/EXR/全codec/全モデル・全停止点/長尺の網羅は広げない。技術結果は同日STATUS JSONへ保存する。

モデル区分：高性能（設計照合・実装・検証）。サブエージェントなし。
