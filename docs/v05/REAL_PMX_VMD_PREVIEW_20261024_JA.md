# 実PMXとVMDの作品別プレビュー確認 — 2026-10-24

関連: Issue #39/#50/#63/#69、DATA-008、MOTION-003/006。最短制作経路の順2に対する部分確認。

## 変更と確認範囲

既存の3D配置画面でモデルに付く移動ハンドルを、モデルの表示範囲を求める対象から外した。無限に広い選択面がカメラの自動フィットを狂わせる問題を防ぐ。作品別プレビューに読み取り専用の骨姿勢・描画範囲診断を加え、実素材の変形を計測できるようにした。素材、骨、ウェイト、保存済み作品は書き換えない。

隔離サーバーへ既存登録PMX、登録済みテクスチャ、短い頭振りVMDをコピーし、作品のシーンにPMXを配置してVMDクリップと対象モデルを保存した。Chrome/SwiftShaderでF0とF120をシークし、頭骨の位置・回転の最大差0.1733、WebGLキャンバス画素の差、有限のモデル範囲とカメラ位置を確認した。ページ再読込後のF120頭骨姿勢は許容差0.0001未満で一致した。VMD読込件数1、PMX読込件数1を確認した。

実行: `BAI_REAL_MMD_DATA=<登録素材を含むdataディレクトリ> node tests/run-guarded.cjs tests/studio-v05-real-pmx-vmd.test.cjs`。隔離Chrome試験1/1成功、ガード対象の利用者データ7ファイルとexportsは前後一致。PMX原本SHA-256 `542a4daa561f0b0da578fc303af9b8c6dc4acdd8d380771a170e96e95a205488`、VMD原本SHA-256 `3ae724f9d1d36a7e74a911d6b1bbfad7d2459e5e256fcac43521ebebd0a3d234` は試験前後一致。テスト素材のバイナリはGitへ追加しない。
