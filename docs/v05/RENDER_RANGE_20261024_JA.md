# v0.5 書き出し範囲の保存 — 2026-10-24

## 対象

Owner指定の「タイムラインのイン点〜アウト点を書き出す。未設定なら0フレーム〜最終フレーム」に対する範囲データの接続。Issue #49 / #69、`RENDER-001` の準備段階。**実動画レンダー、音声多重化、形式選択、キューは未接続**。

## 保存と時刻

- 作品IDごとに `data/studio_v05_render_ranges/<project-id>.json` へ、イン点とアウト点を**フレーム番号**で保存する。既存の配置ファイルと原素材は変更しない。
- 未設定のイン点は0。未設定のアウト点は保存済み配置クリップの最も遅い終端から求めた最終フレーム。終端は半開区間 `[start, end)` として扱い、例えば60 fpsで0〜5秒の配置なら0〜299フレーム、出力契約の終了境界は300。
- 作品の保存済みFPSを使う。作品にFPSがまだない場合は既存の作品既定値60 fps。クリップが空なら範囲表示は仮の0〜0とし、レンダー用範囲は発行しない。
- 保存時は範囲ファイルと配置ファイル両方のrevisionを照合する。競合や範囲外入力は書き込まない。配置を後から短縮して既存のアウト点が最終フレームを超えた場合は、元の値を保持して無効と表示する。
- 画面のI/Oボタンは`#v07timeline`の**保存済み作品の再生位置**を読む。旧試作タイムラインの独立時刻は使わない。範囲表示は出力画面でも同じAPIから読み直す。

## 次の接続

`BAIStudioRenderRange.jobRange()` は有効な配置があるときだけ `projectId`、配置revision、開始フレーム、終了境界、FPS分子・分母を返す。レンダー処理はまだこの契約を消費しない。作品の共通シーン/音声/カメラの同時刻プレビューと、実際のオフスクリーン描画・音声エンコード・再読込が必要。UIのレンダーボタンと未接続の形式・解像度・FPS・透過設定は無効にしてある。
