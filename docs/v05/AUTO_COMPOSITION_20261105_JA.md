# 保存カメラが無い作品の自動構図（2026-11-05）

対象は v0.5 の順3（Issue #39/#63/#81、RENDER-005/006）。既存の viewport.fit() と16:9の合成枠を、保存カメラの無い作品で実際に照合した。製品コードの変更は不要だった。

## 実素材の隔離試験

tests/studio-v05-auto-composition-real.test.cjs は、所有者の実PMXとS01 GLBステージを読み取り専用で隔離サーバーへ複製する。ステージを原点からずらして回転・縮小し、2体を固定した。背景には試験中に作るマゼンタ画像を置く。作品にはカメラを保存せず、APIで camera: null を再読込して確かめる。プレビューで自動構図を使ったことを検査し、F0を720p MP4へ出力して3D画素を比較した。

実行環境はWindows、Chrome、実GPU NVIDIA RTX 4070 SUPER/D3D11。BAI_REAL_MMD_DATA は所有者の data を読み取りだけに用いた。

| 観測 | 値 | 判定 |
|---|---:|---|
| プレビューの3D枠 | 622×350、縦横比1.777 | 16:9の出力枠と一致 |
| 3D画素の重なり IoU | 0.892 | 閾値0.85超 |
| 3D画素の重心ずれ | 0.0028 | 閾値0.01未満 |
| 画素数 | プレビュー892、MP4 924（320×180） | 差は縮小・描画による |
| 試験 | 1成功、0失敗、0スキップ | 合格 |
| run-guarded 原本照合 | data 5ファイル、exports 0ファイル | 前後一致 |

実PMXのSHA-256は 542a4daa561f0b0da578fc303af9b8c6dc4acdd8d380771a170e96e95a205488、S01 GLBは a54a7451a580eb88df9e6b13308d406cad9000abc72410fd4a006197dd7cae35。試験は原本と索引のhashも個別に照合する。

## 範囲

今回確認したのは、保存カメラなし・横長の欄・F0・1フレーム・実PMXと実GLBステージの組合せ。ステージが大きい場合にキャラクターが画面内で小さくなる問題は、順6の初期構図設計に残る。縦長の欄、時間で動くカメラ、長尺、Linux、WebMCP/標準MCPは未確認。
