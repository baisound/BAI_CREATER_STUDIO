# LIP-001 発話の読み・明示無音の画面編集（Issue #187）

## 操作と保存境界

v0.5のSRT原本パネルで発話を選び、読みを `未確定`/`提案`/`確定` にしてかなを入力するか、その発話を明示無音にできる。保存ボタンでだけ独立した作品revisionを更新する。原SRTの本文と `[startMs,endMs)` は編集せず、画面の発話行に保存状態を示す。再読込後は同じ発話のかなと無音指定が復元される。原本のハッシュ照合が失敗した場合は読み保存を無効にする。

不正な読みはAPIで拒否し、画面を保存済み状態に読み直してエラーを示す。これは読みの確定/無音指定まで。かな→口形候補、VMDレイヤーと書出し、音声との同期、WebMCP/標準MCP、統合production.lipは後続で、LIP-001完成とは扱わない。
