## 変更

作品一覧・最近の作品で選んだ**実作品ID**を、編集画面の保存済みタイムライン作品セレクターへ渡す。反対にセレクターを変更した場合も作品カードの選択を更新する。最後に選んだIDをブラウザ内へ記録し、再読込時はカタログに存在するIDだけを復元する。新規作品を作ると、そのIDを選択して一覧とタイムラインへ反映する。

保存済み配置・再生位置の読み込みは選択時のIDを固定し、別作品へ切り替えた後に届いた古い応答を破棄する。出力範囲画面も同じセレクターを参照する。作品カードの選択だけで既存素材・配置・スナップショットを改変しない。
