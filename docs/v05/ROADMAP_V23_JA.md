# UI刷新ロードマップ（枝番23以降への追加）

- **枝番23 設計コミット:** 複数モデル共有シーン、識別子、モーション割当、ライフサイクルを設計として登録。複数モデル機能そのものは実装しない。
- **枝番23 実装コミット:** 先行して単一モデルの保存済みクリップと共通タイムラインのシーク連携を修正・テスト。
- **後続候補 MM-01:** 素材IDとシーンインスタンスIDの移行対応・共通シーンホスト。
- **後続候補 MM-02:** 複数モデルの追加／削除・共有レンダラー・独立Transform。
- **後続候補 MM-03:** モデル別のモーション適用・複数レイヤー・表情／口の優先度。
- **後続候補 MM-04:** API/MCP/WebMCP機能整合・回帰試験・GPU負荷試験。

後続候補は既存承認済みロードマップの作業を勝手に割り込んで変更しない。採用時に依存関係と実装順序を照合する。
