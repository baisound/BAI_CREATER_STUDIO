# MOTION-010 実PMXの足IKターゲット選択と再生補正

2026-10-24、Issue #106。同じv0.5の3D編集画面で、読込済みPMXの実IK定義からターゲット骨と追従骨を一覧にし、ターゲットを選ぶと局所位置の3Dハンドルへ切り替える。骨名だけでIKと推測せず、Three.jsが実際のPMX再生に使う`geometry.userData.MMD.iks`を参照する。IK定義がないモデル、重複名のターゲットは選択候補にしない。既存の作品F、クリップ、モデル、保存キー、ロック・重みの制限を共用する。

実素材では左足ＩＫ・左つま先ＩＫ・右足ＩＫ・右つま先ＩＫの4定義を確認した。F240の左足ＩＫへ局所X +0.3の未確定補正を与えると、モデル表示スケール0.08の世界座標でターゲットと左足首が約0.024移動し、ターゲットと足首の到達差は0.000503だった。右足首は不変。保存後の0→4→4→2→4秒のシークと画面再読込でも足首姿勢が一致した。元PMX/VMDの骨・ウェイト・ファイルは変更しない。

## 累積不良と修正

初回の保存再読込試験で、足IKターゲットに位置差分が累積した。補正ありのPMX評価器が`MMDAnimationHelper._saveBones`を補正**後**に呼んでいたため、元VMDにキーがない骨の次回シーク基底が補正済みになっていた。素のVMD姿勢を保存してから補正とIK/grantを一度評価する順に修正した。頭骨などVMDキーを持つ骨の既存動作も回帰試験で確認した。
