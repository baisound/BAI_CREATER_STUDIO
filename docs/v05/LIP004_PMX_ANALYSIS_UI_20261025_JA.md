# LIP-004 v0.5口モーフ形状の読み取り画面（Issue #175）

## 接続範囲

v0.5の同じ3D制作画面の「PMX表情・口」の下に、折りたたみ式の「口モーフの形状を確認」を追加した。選択中の登録PMXだけ解析できる。各口モーフの型、要素数、移動頂点数、移動距離の中央値/p95、共有頂点が多い相手を表示する。グループ・無変位等には手動確認を示し、解析値を自然さの判定や保存済み母音強度として扱わない。選択モデルや作品の変更・再読込時は古い解析結果を消し、応答の遅延も選択状態と照合して破棄する。表示は読み取りのみで、作品キーを変更しない。
