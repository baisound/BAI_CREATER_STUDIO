# LIP-001 モーフ専用VMDの厳密なバイナリ往復（Issue #187）

## 実装

`morph_vmd_codec.py` が VMD 0002 のモーフ専用バイト列を生成し、`vmd_readback.py` が全レコードを再読込して比較する。モデル名20バイト、モーフ名15バイトのCP932フィールドには終端NULを必要とし、長名・符号化不能文字を拒否する。骨レコード0件、モーフレコードは `(名称, 30fps整数F, float32重み)`、カメラ・照明・セルフシャドウ・IK等の後続5セクションは各0件。重複する `(F, 名称)`、非有限・範囲外重み、負F、空名を拒否する。モーフ名とFの昇順へ整列し、生成後に全キーを比較する。

この段階では作品のSRT・読み・下書き・PMXモーフ対応を出力へまだ接続していない。ファイルの保存先、採用、画面操作、PMX上の実際の表情品質も未実装・未検証。既存の骨VMD writer/readbackは変更しない。

## 試験

- `python -m pytest -q tests/test_morph_vmd_codec.py`: 8/8。日本語名と重み0を含む3件を生成・全件再読込し、Three.js付属の独立 MMDParser でもモデル名・骨0・モーフ3・カメラ0を確認。CP932不可/長名、同F同名、範囲外・非有限値、トランケート・非空後続を拒否。
- Python構文・差分検査成功。試験は人工キーであり、実PMXへの適用と見た目は未確認。

モデル区分: 設計・実装・試験とも標準モデル。
