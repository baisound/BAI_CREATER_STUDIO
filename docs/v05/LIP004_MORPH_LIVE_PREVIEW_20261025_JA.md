# LIP-004 PMX口形の保存前一時プレビュー（Issue #175）

## 動作

口形対応表の7枠から一つを選び、入力中の手動重み0〜1で、選択中の登録PMXの実在口モーフを同じ3D画面へ一時表示する。開始時に現在時刻の保存済み動作・表情を評価してから、その一つの口モーフ値だけを差し替える。「元の表情へ戻す」、重みや割当の編集、時刻移動、モデル/作品の切替で一時表示を解除する。再生中は開始できない。試写値はシーンの表情キーやMorphMapには保存されず、保存済みフレームの動画キャプチャにも混ぜない。

## 試験

`BAI_REAL_MMD_DATA` 指定の `node tests/run-guarded.cjs tests/studio-v05-pmx-morph-analysis-ui.test.cjs` は隔離Chromeで1/1成功。実PMX Aのグループ型「あ」に重み0.8を一時表示して実描画PNGとモーフ値が基準から変化し、0.4へ編集・再表示すると別の描画になった。編集時、「元の表情へ戻す」、作品タイムラインの0.2秒への移動でモーフ値0へ戻り、復元ボタンが無効になることを確認した。その後の下書き/確定保存、再読込、Bモデルの0件判定、隔離原本変更時の失効表示も同じ試験で成功。作品シーンrevisionと表情キーは不変、原PMX A/Bと実データ7ファイル・exports 0ファイルの監視ハッシュは前後一致した。`npm run typecheck`、JS構文、差分検査も成功。

0.8と0.4は差の検証値で、自然な発話形として採用した値ではない。Ownerによる見た目の選択、VRM、WebMCP/標準MCP、Linux、統合productionの保存・耐障害性は未確認。LIP-004全体は未完成。
