# CAM-019：PMX・動き・表情のシーン橋渡し

Issue #238のOwner指定を継続。既存の登録→準備→実Blender→Bake送信→候補比較/採用を維持する。新しい操作画面は増やさない。

## 実装契約（検証前）

- Studioの既存MP4と同じ評価器で各作品Fのワールド頂点をサンプリングする。PMXのVMD、FK/接地補正、表情/口と親子配置を別のBlender計算へ置き換えない。Blender側は骨編集用モデルではなく撮影用の形状キャッシュ。
- BlenderF=作品F+1、FPSは作品と同じ。頂点はY-up→Z-upへ1回変換し、正規化/配置を重ねない。表示区間は半開区間。準備開始Fが途中でも同じ評価時刻を使う。
- 三角形/UV/基本色/拡散テクスチャをコピーし、各Fの評価済み形状をMDDへ保存。トゥーン、輪郭線、ライティング等の見た目はStudio出力を正本とし、Blenderの材質完全一致は対象外。撮影カメラのみ戻す。
- 元素材、テクスチャ、動作、表情/口、scene/arrangement/FK revisionを固定。準備前後とBake受取/比較/採用で条件を照合する。被写体/キャッシュ/親子/材質/表示の変更を戻す前に拒否する。
- 静的GLB経路を維持。キャッシュは最大512MiB、頂点総数100万、メッシュ256個、範囲0.1〜120秒。超過は短い区間の再準備を案内。未読込/未割当/評価失敗を隠さない。
- 準備は隔離ブラウザー/データを変更しない読み取り経路で実行。失敗したコピーは保存済みセッションとして公開しない。ログと既存コピーを保持する。

上位3タスク：①同じ作品と区間を準備、②CinemaOperatorで撮影/Bake、③送信済みカメラを比較/採用。既存のOperate画面へ対応範囲・準備中・形状固定の説明だけ追加する。

## 受入ゲート

生成PMX/VMDの動き・表情・口、途中出現/消失、非0開始F、異なるFPS、ワールド変換を実Studio/Blenderの頂点で照合する。実アドオンBake、B1採用、保存復元、MP4、両MCP、依存変更/キャッシュ改変の拒否を確認する。実素材は非公開のローカル証拠に限る。Windows/Ubuntu・実GUI/自動試験・未検証を分ける。

現状：PMX/VMDの動き・表情/口を含む形状コピーと実アドオンBake往復を代表検証。CAM-019全体は未完。

確認した制限：現行タイムライン/MP4のPMX VMDはplayer.jsでphysics:false。実動作プレビューの二次物理とは別経路。この橋渡しはタイムライン/MP4の評価結果を固定し、二次物理を新たに再計算しない。二次物理再現の完成とは扱わず画面にも表示する。

## 操作と実装済みの変更

「制作 → カメラ・演出 → CinemaOperator」で同じ作品と開始/終了Fを指定して準備します。動くPMX/GLB/VRMはStudioで評価してからコピーし、BlenderのStudioタブで実CinemaOperatorを開いて撮影・Bakeします。「現在のBakeを候補へ送る」→Studioの「送信済みBakeを受け取る」→比較→「カメラ行へ配置・保存」で同じモデル/動作/表情と再生・出力できます。未採用の候補と元作品を保持し、採用は素材編集のUndo/Redo対象です。

Blenderは撮影用の形状コピーです。骨・表情の元編集はStudioで行って再準備します。テクスチャは撮影コピーだけ最大4096pxに縮小し、同じ画像とUVを共有します。Studio出力は原本を使います。0.1〜120秒、モデル32個・各100MiB/合計200MiB、形状キャッシュ（MDD/PNG/JSON）512MiB以内・頂点100万・メッシュ256個、材質/UVの上限があります。作業blendや原本コピーはこのキャッシュ容量とは別です。

座標：各作品Fの評価済みワールド頂点(x,y,z)をBlender(x,-z,y)へ変換。作品F=pをBlenderF=p+1へ配置。開始F=aのMDD第i標本は時刻i/fps、BlenderF=a+i+1でmodifier.eval_frame=iを直接指定します。範囲は両端を含み、表示は元timelineの半開区間です。Blenderは非表示メッシュの評価を省略するため、頂点一致は表示中の標本で確認し、非表示標本は表示状態を判定します。

入力原本/テクスチャ、project毎の保存JSON（FK/IKモード・口採用・モーフ対応など）と評価器hashを固定。作成前後、起動、Bake受取、B1比較/採用で照合します。Blender側もMDD内容、modifier設定・曲線、UV・材質・画像・NodeTree action状態やmuteを照合。失敗コピーを選択可能なセッションとして公開せず、既存のコピー/完成動画を保持します。処理ログをコピーのフォルダーへ保存し、タイムアウトでは所有するブラウザー子プロセスを終了します。

- 生成PMX：VMD骨移動・表情・口、途中出現/消失、F0–59とF9–38の全頂点一致、Blenderで表示中の頂点差<1e-6、逆シーク再現、30fpsと29.97fpsの別区間準備。modifier/MDD/UV/材質/culling/action/muteの変更拒否と復元、表情VMD/画像/口採用/FKデータだけの変更拒否を検査。
- 実登録PMX（非公開）：実モデルの60Fをコピー。実GUIで50mmへ変更し、nativeBake/現在状態送信/Studio比較/採用/保存/60F720p MP4を確認。Windows RTX4070SUPER。素材原本の前後hashを照合。実データや実アドオンはGitへ含めない。
