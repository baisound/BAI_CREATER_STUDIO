# LIP-004 PMX口モーフの読み取り数値検査（Issue #175）

## 範囲

`tools/pmx_morph_analysis.mjs` は既存のThree.js MMDパーサが読んだPMXから、口パネル（panel=3）のモーフだけを測る。頂点モーフ（type=1）の同一頂点オフセットを合算し、移動距離が正の頂点について中央値、95パーセンタイル、移動頂点数を出す。2モーフの重なりは共有移動頂点数とJaccard比（共有/和集合）で表す。グループ・非頂点・無変位モーフは `manualRequired=true` とし、候補強度を自動で出さない。

明示的に選んだ基準モーフの中央値を、対応付けたA/I/U/E/Oの各中央値で割り、`[0,1]` に制限した数値候補を返す。モーフ名から母音を推測せず、これは形状の自然さや適切な発音の判定ではない。出力にはPMX原本のSHA-256と解析値のSHA-256を含む。CLIは読み取りのみで、原本や作品の表情キーを変更しない。

## 実データ

`node --test tests/pmx-morph-analysis.test.mjs` を `BAI_REAL_MMD_DATA` 指定で実行し、2/2成功。人工データでは中央値・p95・共有頂点・候補比・無変位/グループ/不正頂点の拒否を照合した。

前後の原本ハッシュは一致した。`npm run typecheck`、`node --check tools/pmx_morph_analysis.mjs`、`git diff --check` も成功。実PMX A/Bはいずれも提供データを読み取っただけで、画面表示・保存・再起動復元・VRM・Linux・MCPは今回未検証。特に実PMX Aの母音群はグループなので、この数値経路だけで母音強度を確定しない。次に登録済み素材ID/hashへ結び付けたAPIと画面の手動確認・保存を進める。
