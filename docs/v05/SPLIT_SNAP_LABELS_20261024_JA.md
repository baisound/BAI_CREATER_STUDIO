# v0.5 タイムライン分割・吸着・名称編集（Issues #82/#84/#83）

2026-10-24。保存済み動画・独立音声・楽曲クリップをハサミモードでクリックした位置で分割する。左は元ID、右は新IDとして、作品の開始・長さと元素材の開始位置を別々に保存する。右の元位置は分割分だけ進む。選択・移動モードでは両片を独立にドラッグでき、左右端を元素材の範囲まで戻して隠れた区間を再び使える。先頭/末尾に近すぎる切断、ロック、古いrevision、無効IDは書き込まずに拒否する。元ファイルは変更しない。

タイムライン上部に選択/移動とハサミのモードボタン、吸着オン/オフ、倍率、最小グリッド間隔を置いた。倍率に応じて細目盛りと大目盛りを描き、吸着オンでは表示される細グリッドへ配置・移動・端調整・切断位置を揃える。オフではマウス位置を0.0001秒単位まで保存する。高倍率では0.1秒までのグリッドを表示できる。モードと吸着は編集セッション内の操作状態であり、作品の保存値にはしない。

各トラック名はラベルをダブルクリックして編集する。画像行は安定ID `image:<番号>`、その他は内部のトラックIDをキーに表示名だけを保存する。英語・日本語と髙を許容し、絵文字・制御文字をサーバーで拒否する。空欄の保存は既定名へ戻す。クリップの内部参照・重なり順・原本には触れない。
