# v0.5 HOME日時と再生位置・時間倍率（Issues #88/#89）

2026-10-24。HOMEの「最近編集した作品」と作品一覧は同じ作品カードを使う。保存値は変更せず、カード上のタイムゾーン付き日時だけを日本時間に変換して `YYYY-MM-DD HH:mm:ss JST` と表示する。UTCの小数秒とオフセットは表示しない。タイムゾーンのない旧デモ日付は日付だけを表示し、日時が不正な場合は「日時不明」とする。

保存済み作品のプレビューが再生する各フレームを主タイムラインへ通知し、目盛りと各トラック上の再生位置カーソル、秒数表示を更新する。連続再生のフレームごとにサーバーへ書き込まず、一時停止・停止・シーク時は従来どおり保存済み再生位置へ反映する。作品IDが違う通知は無視する。倍率は `−`、`＋`、スライダーで4〜160 px/秒に変更する。スライダーのつまみは操作中に作り直さず、離して確定したときに時間軸を描き直す。表示中の時間位置は倍率変更後も保持し、クリップの保存時刻は変えない。
