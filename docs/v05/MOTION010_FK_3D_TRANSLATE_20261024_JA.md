# MOTION-010 実PMX骨の3D位置ハンドル

2026-10-24、Issue #106。[位置差分の数値補正](MOTION010_FK_POSITION_20261024_JA.md)と[3D回転ハンドル](MOTION010_FK_3D_ROTATE_20261024_JA.md)を同じv0.5編集画面で接続した。「骨の3D操作」で回転/位置を切り替え、選択した実PMX骨をドラッグして局所位置差分を仮表示する。「このFをキー化」で、既存の作品別FKキーへ保存する。ドラッグだけでは保存しない。

位置ドラッグは、対象骨の保存補正を一時的に外して同じ作品Fの素の局所位置を評価し、ドラッグ後の局所位置との差を求める。元レイヤーを復元し、既存の数値仮表示経路へ渡す。再評価後の位置差が0.001モデル単位を超える場合は仮補正を破棄する。回転操作も含め、同じ作品Fの既存キーや仮補正が持つもう一方のチャネルを保持する。Escはドラッグ前の位置/回転へ戻し、新しいキーを作らない。

既存の安全条件を共通に使う。実PMX＋VMD、骨名一意、モデル未ロック、表示時刻と対象Fの一致、補正データ不一致なし、単一レイヤーかつ重み100%・なじませ外でのみハンドルを有効にする。モデル全体の配置ハンドルとは同時に表示せず、撮影画面では骨ハンドルを作らない。元PMX/VMDの骨格・ウェイト・素材は変更しない。
