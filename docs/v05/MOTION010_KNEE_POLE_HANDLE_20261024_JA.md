# MOTION-010 実PMX膝ポール3Dハンドル

2026-10-24、Issue #106。[解法設計](MOTION010_KNEE_POLE_DESIGN_20261024_JA.md)に沿い、v0.5の同じ骨編集画面へ「膝方向を編集」を追加した。実PMXの左右標準足IKについて、膝・太もも・足首の親子2リンク、膝の有限な角度制限、作品のIK編集方法を確認した場合だけ選べる。押すと現在の作品フレームで評価した膝位置へ3D位置ハンドルを置き、太もも骨の既存補正キーがあれば回転・位置を読み込む。選択だけでは姿勢・保存データを変更しない。

ドラッグ先を股関節から足首へ向かう軸の垂直面に投影し、既存のPMX CCDを評価しながら太ももの局所Y回転差分を有界探索する。膝方向の差が改善しない、足首目標残差が0.001シーン単位を超える、反対側の足首が1e-4を超えて動く、到達方向差が15°を超える場合は仮補正を破棄する。採用した差分は既存の作品FKキーの回転チャネルへ渡し、他チャネルを保つ。ドラッグ中はハンドルのみ動き、PMX姿勢はマウスを離した後に評価する。
