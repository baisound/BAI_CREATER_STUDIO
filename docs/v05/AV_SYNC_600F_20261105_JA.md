# v0.5音画同期の600F隔離測定（2026-11-05）

対象はロードマップ順3、Issue #39/#63/#69、`AUDIO-001` と `RENDER-006`。音画の差を完成MP4の復号結果から測る試験を追加した。作品設定やAPI応答だけを同期の証拠にしない。

## 測定方法と結果

`tests/studio-v05-av-sync-600f.test.cjs` は60fps・600Fの合成動画を作る。動画には10Fごとの白い1Fフラッシュ、内包音声には同じ時刻の短い1kHzパルスを入れる。合成GLBも同じ作品の3Dシーンへ配置し、保存範囲 `F0..F599` を720p H.264/AAC MP4に出力する。完成MP4を映像600Fと48kHz PCMへ復号し、白フラッシュとその近くの音声RMS最大フレームを60地点（F0からF590）で比較する。

隔離試験は60地点すべてで差1映像フレーム以内だった。F0を含め、F590は末尾まで10Fの位置にある。白フラッシュは期待フレームにあり、前後フレームは黒いことも確認した。完成MP4は600F、3D連番も600枚で、登録動画の入力SHA-256はジョブ記録と一致した。現在のFFmpeg時刻グラフに追加修正は不要だった。

`CHROMIUM_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe`、`BAI_TEST_CONCURRENCY=1` で `node tests/run-guarded.cjs tests/studio-v05-av-sync-600f.test.cjs` は1件成功。利用者の `data/` 5ファイルと `exports/` 0ファイルは前後hash一致。

## この試験の限界

合成MP4の60地点と一つの3Dシーンについての結果であり、全600Fに独立した音イベントがあるわけではない。所有者の実曲・実動画、独立音声と動画内音声の重なり、可変フレームレート、長尺・異なる作品FPS、実GPU、Linux、WebMCP/標準MCPは未検証。したがって `RENDER-006` の全素材・全作品への1F以内の保証、順3全体の完成を主張しない。
