# v0.5 共通編集パネルのサイズ調整

対象：Issue #63。Ownerが2026-10-24に承認した、左欄の幅と下のタイムライン欄の高さをドラッグで変更する改善。タイムライン編集・動き/表情・カメラ/演出は同じ編集グリッドを使う。「簡易素材」は初期状態のタイムライン編集と同じ内容だったため、重複タブを外し、素材欄は編集画面の左側に残した。以前の試作ワークスペース設定で`assets`を指定した場合は`edit`へ開く。

## 操作と保存

- 左欄と中央の境界を左右へドラッグすると左幅が変わる。中央と下のタイムラインの境界を上下へドラッグするとトラック欄の高さが変わる。両境界は矢印キーでも16pxずつ変更でき、Shiftキー併用で32pxずつ変更できる。
- タイムラインの「パネル配置を戻す」で両方を初期値へ戻す。変更値はブラウザ内の`bai.v05.paneLayout.v1`にのみ保存し、作品・素材・原本へは書き込まない。破損した値は無視し、表示領域に合わせて最小幅・高さを制限する。
- 4つの編集系タブは同じ値を共有する。730px以下では既存の縦積みレイアウトを使い、ドラッグ境界は表示しない。モバイル全体の調整はOwner指定により後順位。

## 確認と残件

`npm run typecheck`とJS構文検査が成功。隔離Chromeで`node tests/run-guarded.cjs tests/studio-v05-pane-layout.test.cjs`は1件成功。ドラッグ、タブ間共有、再読込、キー操作、リセット、重複タブの除去、旧`assets`指定からの復元を確認した。最初の試験は再読込後にホームが開いた状態で編集欄のボタンを押そうとして失敗したため、試験を編集タブへ戻す操作に修正して再実行した。実データ5ファイルとexportsのハッシュは前後一致。

素材一覧・GLB表示との合同Chrome試験は最初4/5件成功で、ビューポート変更直後のヘッダー再計測より前に検査した1件が失敗した。再計測完了を待つ判定へ試験を修正して再実行し、5/5件成功。実データ5ファイルとexportsのハッシュは合同試験の前後でも一致した。

素材の実配置、3D表示、音声・動画の再生、カメラ・モーション編集はこのパネル調整によって完成しない。狭い画面での全操作、Linux、MCP/WebMCP、実GPUは未検証。実装・レイアウト判断は標準モデル区分。
