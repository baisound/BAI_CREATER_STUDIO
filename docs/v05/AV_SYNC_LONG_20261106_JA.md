# 長尺の全区間に分布する音画同期の検証（2026-11-06）

対象: 順3、Issue #39/#81、`AUDIO-001` / `RENDER-006`。600Fで使っていた映像・音声指標を長尺へ拡張する。製品の時刻計算は今回変更しない。

`tests/studio-v05-av-sync-600f.test.cjs` に `BAI_SYNC_FRAMES`（600〜13,800、10F単位）を追加した。60fpsの合成動画に10Fごとの白フラッシュと同時刻の1kHz音声パルスを入れ、動画内音声と合成GLBを同じ作品の720p MP4へ出す。完成MP4の全映像を小さな領域へ復号し、48kHz PCMと比較する。各指標で期待した映像Fと音声RMS最大Fの差が1F以内かを検査する。

13,800Fでは230秒全体の1,380地点（F0〜F13790）を検査する。各指標の前後が黒いことも確認し、期待したFにフラッシュがあるかを照合する。すべての映像Fに独立した音イベントがあるという意味ではない。

## 未検証の範囲

実歌音声・実動画、独立音声と動画内音声の重なり、異なるFPSとサンプルレート、可変FPS、実MCP/Linuxは別に残す。合成GLBは静止物なので、この試験だけで動く3Dモデルと音声の時刻一致や振付の自然さを判定しない。今回の検査結果を全作品への同期保証や順3完了へ広げない。

## 実行結果

Windows・Chromeで `BAI_SYNC_FRAMES=13800` と `CHROMIUM_PATH` を指定した `node tests/run-guarded.cjs tests/studio-v05-av-sync-600f.test.cjs` は1成功・0失敗・0スキップ（約207秒）。13,800Fの完成H.264/AAC MP4を復号し、1,380地点全てで時刻差0Fだった。作業コピーのdata 5ファイルとexportsなしは前後hash一致。Node構文と差分空白検査も成功。モデル区分: 標準モデルで試験拡張・結果記録。
