# MOTION-010 足IKの到達差を実姿勢から表示

2026-10-24、Issue #106。v0.5の骨編集画面でPMXのIKターゲットを選ぶと、同じフレームで評価したターゲット骨と追従骨の世界位置差をシーン単位で表示する。差が0.001を超える場合は、目標と一致していないことを示す。原因は到達距離・PMX関節制限・CCD収束など複数あり得るため、距離だけから原因を断定しない。保存形式と解法は変更しない。

## 確認

- `npm run typecheck`、変更JSの構文検査、`git diff --check`が成功。
- `BAI_TEST_CONCURRENCY=1 node tests/run-guarded.cjs tests/studio-v05-pmx-fk-gizmo-real.test.cjs`が隔離Chrome/SwiftShaderで1件成功。実PMXの左足IKへ遠い位置を仮指定した際、目標と左足首の実測差は0.0857シーン単位で、画面の4桁表示と一致し、未一致を表示した。取消後は足首姿勢が元と1e-5未満で一致し、到達表示も目標付近へ復帰した。従来の頭FK、足IKドラッグ、保存、Undo/Redo、再読込の同試験も成功した。
- 最初の試験は実モデルの縮尺に対して期待差0.1シーン単位が過大で失敗した。実測差と画面の一致を判定するよう修正して再実行した。`run-guarded`の利用者`data/`と`exports/`の前後ハッシュは一致し、試験内の原PMX/VMDハッシュも一致した。

## 未確認

0.001は表示用の目安であり、脚の実到達可能域の証明ではない。膝ポール操作、角度制限の個別表示、ドラッグ中のPMX姿勢更新、左右・別PMX名の一般化、腕IK、実GPU・物理ON・Linux・標準MCP実呼出し、Owner採用は未確認。AC-M-02とMOTION-010全体は「要検証」。画像・動画の成果物はなくEagle登録対象はない。
