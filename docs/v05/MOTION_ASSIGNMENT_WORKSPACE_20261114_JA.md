# モーションのその場割当と3D編集領域の改善

上位3タスクは①選択モーションへ対象モデルを保存、②同じ時刻の3Dを広く見ながら調整、③閉じてタイムラインへ戻り再表示する。Operateの既存配色/入力を保ち、既存APIで作品へ保存する。

## 受入契約

- 選択クリップ欄に適用先モデル、適用・保存、割当状態/失敗/モデルなしを置く。動き・表情・口に対応。同一素材の別instanceを区別し、原本/カメラ/他クリップを変えない。
- 選択/作品切替と非同期取得の世代を照合し、旧応答を新しい選択へ使わない。保存中の対象を固定し、配置revision競合は再読込へ案内。未保存と保存済みを区別し、保存後に最新の配置/3Dを更新する。
- 明示的な3D編集の入口は広い作業領域を使う。ヘッダー・閉じる/戻るをスクロール外へ固定。モデル/動き、表情/口、リグ/接地、配置/視点の設定に到達可能にし、長い設定だけ内部スクロールする。
- タイムラインの自動3D合成と、任意の撮影/MP4キャプチャを保持。明示的に閉じた表示は同一作品の自動再読込で勝手に再表示しない。Esc/クリックで終了し入口へfocusを戻す。
- カメラ比較・物理・FK/IK・表情/口の既存機能を削除せず、保存・プレビュー・出力の意味を変えない。

検証予定：生成2体PMX/VMDで手動割当/解除、姿勢と保存復元、モデルなし/別形式、連続選択/作品切替/競合、3D表示の閉じる/再表示、1440/1024/狭幅/低高さとキーボード、既存物理/カメラ/MP4・両MCP。実ユーザーテスト/SR等の未検証を区別する。

実装済み：適用先はメタ情報より先に表示。同じ素材の別instanceを種別/番号で区別。下書きはページ内で作品+クリップごとに保持し、保存前の3D確認は無効化する。送信対象とrevisionを固定し、選択変更後に古い結果を表示しない。保存中は同clipを選び直しても二重送信しない。Enter保存/再読込後は新しい適用先へfocusを戻し、別選択や背面inert時は奪わない。

大画面の終了はGPU表示/一時候補も解除し、保存済み設定を保持する。同作品の自動再表示は抑制、明示再表示・作品切替・ページ再読込では解除。キャプチャ用ページへは抑制を持ち込まない。表示方式の切替でも未保存仮編集/カメラ比較は解除し、再比較へ案内する。

全機能の配置：モデル・動き=割当/物理、表情・口=モーフ/PMX・VRM対応表、リグ・接地=FK/IK/接地/変換候補、配置・視点=XYZ/再読込/注目/カメラ保存復帰。共通時刻/再生は全タブ外、終了は固定ヘッダー。低い画面の3D入口と非同期初期化も修正。

途中検証：新UIの2体/手動保存・解除/UndoRedo/表情/下書き/遅延選択・保存/409/読込中の終了/モデルなし・30F MP4と1440/1024/800低高さ/540を検証。既存合成の画素、共通時計、接地（保存/Undo/両MCP/実MP4）を含む直列4試験PASS。物理は別回帰1PASS。初期の4ブラウザー並列では接続拒否/旧install失敗があり、並列ゲートは失敗として保持。直列で区別し、最終の両OS/実Blender・型ゲートは続行中。

3視点のP1送信範囲/表示抑制/読込世代、P2未保存3D確認/保存後focus/終了範囲を反映。初見・状態・視覚のコードレビューに追加必須指摘なし。最終実機採否は試験完了後。モデル区分：高性能（複数モジュールの保存・表示・選択設計と実装）。機械記録は同名STATUS JSON。
