# モーションのその場割当と3D編集領域の改善

上位3タスクは①選択モーションへ対象モデルを保存、②同じ時刻の3Dを広く見ながら調整、③閉じてタイムラインへ戻り再表示する。Operateの既存配色/入力を保ち、既存APIで作品へ保存する。

## 受入契約

- 選択クリップ欄に適用先モデル、適用・保存、割当状態/失敗/モデルなしを置く。動き・表情・口に対応。同一素材の別instanceを区別し、原本/カメラ/他クリップを変えない。
- 選択/作品切替と非同期取得の世代を照合し、旧応答を新しい選択へ使わない。保存中の対象を固定し、配置revision競合は再読込へ案内。未保存と保存済みを区別し、保存後に最新の配置/3Dを更新する。
- 明示的な3D編集の入口は広い作業領域を使う。ヘッダー・閉じる/戻るをスクロール外へ固定。モデル/動き、表情/口、リグ/接地、配置/視点の設定に到達可能にし、長い設定だけ内部スクロールする。
- タイムラインの自動3D合成と、任意の撮影/MP4キャプチャを保持。明示的に閉じた表示は同一作品の自動再読込で勝手に再表示しない。Esc/クリックで終了し入口へfocusを戻す。
- カメラ比較・物理・FK/IK・表情/口の既存機能を削除せず、保存・プレビュー・出力の意味を変えない。

検証予定：生成2体PMX/VMDで手動割当/解除、姿勢と保存復元、モデルなし/別形式、連続選択/作品切替/競合、3D表示の閉じる/再表示、1440/1024/狭幅/低高さとキーボード、既存物理/カメラ/MP4・両MCP。実ユーザーテスト/SR等の未検証を区別する。

状態：設計。モデル区分：高性能（複数モジュールの保存・表示・選択設計）。変更前後画像と3視点批評・Root判定は同名STATUS JSONへ記録する。
