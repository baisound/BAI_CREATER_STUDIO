# 実動作プレビューの表示高さ

Ownerの指摘（Issue #63/#69）：外側と内側のヘッダー、説明、ナビが表示を圧迫している。UX-001/003/006/008・AUDIO-001の表示/到達経路を改善した。モデル・カメラ・動き/表情やミキサー各行のタイムライン連動は、別の進行中項目として保持する。

## 実装済み

- 外側の2段ナビを72pxへ詰め、見出しを短く、説明を「操作について」へまとめた。実プレビューiframeを残りの高さへ広げた。
- `v05embed=1` の埋込だけ、内側アプリのtopbar/sidebar/画面操作/モード切替/説明を「画面・表示設定」へまとめる。通常のworkspaceは保持。補助パネルも同メニューから再表示できる。
- 低い画面で3Dと再生行が重ならないよう行の縮小を防ぎ、下段の配置/保存まで内部スクロールで到達する。
- 画面移動中に音声resume待ちが完了しても再生を再開しない。既存の30fpsクロック・前後移動・再生/停止を保持し、他の試聴音との排他も行う。
