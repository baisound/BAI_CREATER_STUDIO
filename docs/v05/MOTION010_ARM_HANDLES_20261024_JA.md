# MOTION-010 左右腕の手先・ひじ3Dハンドル

2026-10-24、Issue #106。[腕・ひじ2キーの仮表示](MOTION010_ARM_PAIR_PREVIEW_20261024_JA.md)を、同じv0.5編集画面の実PMX骨ハンドルへ接続した。左右の腕→ひじ→手首の一意な親子経路があり、既存PMX IKと競合しない場合だけ、手先またはひじ方向を選べる。ハンドルは評価済み手首・ひじの世界位置へ置く。ドラッグ後、手先目標またはひじポールを3D二関節解へ渡し、腕・ひじ2キーを同時仮表示する。範囲外の手先は到達可能な端と指定位置との差を画面へ示す。Escと［仮補正を破棄］、［このFをキー化］、Undo/Redoは既存の共通経路を使う。

保存済み腕キーを再編集する際は、対象腕・ひじの補正だけを一時除いて元VMDを同じ作品Fへ評価し、2キーの局所差分を再計算する。計算後は元の表示へ戻し、全骨の最大位置・角度差1e-6以下を確認する。位置差分付きの腕キー、複数補正レイヤー、重み100%以外、なじませ区間は上書きせず理由を示す。PMXのIKリンクと競合する腕骨も対象外。

## 検証

- `npm run typecheck`: 成功。
- `BAI_REAL_MMD_DATA`、`CHROMIUM_PATH`、`BAI_TEST_CONCURRENCY=1`を設定した`node tests/run-guarded.cjs tests/studio-v05-arm-ik-geometry-real.test.cjs`: 隔離Chrome/SwiftShaderの実PMX＋VMDで、左右の手先・ひじを実マウスでドラッグして2キー仮表示した。左手先の範囲外指定は差0.2012シーン単位を表示。左手先はEsc・保存・Undo/Redo・再読込、左ひじは手首保持・保存・Undo/Redo・再読込まで確認。右手先は左手首不変、右ひじは右手首・左手首不変とEscを確認。手首残差は1e-3未満、未編集側の手首差は1e-4未満。元素材と利用者`data/`/`exports/`のハッシュは前後一致。
- 右腕試験の初回は診断終了時の四元数角度差4.215e-8が当初の1e-8閾値を超えた。位置・回転の規定1e-4より十分小さい1e-6へ閾値を修正した。修正後の初回は最後のブラウザー資源取得に`ERR_NO_BUFFER_SPACE`が出たため不合格として記録し、再実行でコンソール検査まで1件成功した。
