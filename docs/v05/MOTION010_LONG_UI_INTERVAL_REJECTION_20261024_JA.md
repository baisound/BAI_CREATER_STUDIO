# MOTION-010 長尺区間候補の画面拒否

2026-10-24、Issue #106。203.63秒の実VMD `神っぽいな.vmd` と201骨PMXを隔離した60fps・204秒作品へ配置。v0.5画面で90秒の頭FKキーをY10°・X位置0.12へ保存し、長尺の全クリップ一定候補を検査・明示採用・元VMD復元した後、同じ画面のレイヤー設定を作品F5338〜5463、前後各2Fのなじませへ変更した。

画面で「修正区間のみ」を選んで候補作成を押すと、元の動く頭骨曲線と候補の局所姿勢差が上限を超えるためHTTP 422となり、画面に「候補作成不可」と誤差超過理由が表示された。ダウンロードリンクは隠れ、配置ボタンは無効のままだった。拒否前後の隔離候補ディレクトリ内ファイル名・SHA-256は全件一致し、補正revisionと作品クリップの元VMD asset IDも不変。元PMX/VMDのハッシュも一致した。

拒否時の422はブラウザのコンソールにも記録される。初回の保護付き試験は、その期待した422をハーネスが未許可エラーと判定して8件中1件失敗した。試験でこの422だけを許容し、全8件を再実行して8件通過、0失敗・0スキップ。実データ `data` 7件・`exports` 0件の前後ハッシュも一致した。今回は試験と文書のみ変更した。

隔離試験ではカメラ範囲12000Fを設定した。短い旧カメラのまま90秒へシークする場合、長尺の別区間・別補正量、物理ON、実GPU、任意PMX、Linux、標準MCP実通信、Owner採用、MOTION-010全ACは未確認。画像・動画成果物はなくEagle登録対象なし。モデル区分：試験・文書に標準モデル区分を使用。
