# VST一覧の見切れ防止

Owner追加指摘：細いチャンネルにVSTを追加すると高さが足りず見切れる懸念。UX-006/008・AUDIO-002の一覧へ常時の縦スクロールバー、安定したバー領域、内部スクロールを設定。追加ボタンは一覧の外に固定する。インサート領域は122pxで、少なくとも2行の領域を確保。重複した信号経路の各列表示を外し、全体見出しへ集約して150px以上のフェーダーとM/Sを維持する。

100/112pxのチャンネル幅は維持。幅内で省略するプラグイン名は、選択した右欄へ全文表示する。言語処理が過去の「未接続」title/aria-labelを復元する不具合も修正した。

隔離Chromeの1440×900/1024×768で、検出済みTDR Novaを参照する8インサートをバイパス状態で保存し、一覧内部のスクロール、末尾選択、固定追加ボタン、8個上限時無効化/削除後再有効、M/S表示、150pxフェーダー、右欄の名前、言語更新後のラベルを確認。試験1成功、JSエラー0。これは8段VSTの音質・負荷試験ではない（実VST音声処理はPR #298の代表試験）。
