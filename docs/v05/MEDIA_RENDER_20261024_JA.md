# v0.5作品の実MP4書き出し — 2026-10-24

関連: Issue #49/#63/#69、RENDER-001/004/006、AUDIO-001。v0.5最短制作経路の順3に対する部分接続。

## 接続範囲

- 保存済み作品のタイムラインとIn/Outのrevisionを検査し、範囲をフレーム単位で固定してジョブを作る。未設定の範囲はF0〜最終フレーム。範囲または配置が変わった要求は409で拒否する。
- 登録済みの画像・動画・独立音声クリップから、黒背景の720p/1080p H.264映像とAAC音声をFFmpegで合成する。作品FPSを使用し、出力は最大10分、80クリップ。素材の原本と既存完成物は上書きせず、ジョブID別のMP4を作る。
- 起動前にH.264/AAC encoderを列挙し、短い実エンコードとffprobe再読込を行う。入力素材の存在・形式・長さを確認し、登録hashがある場合は一致を検査する。完成後に入力hashを再確認し、MP4のcodec、解像度、フレーム数、長さを再読込してから完成扱いにする。
- ジョブ状態、進捗、失敗理由、完成MP4のプレビューと保存リンクを作品別に表示する。中断ジョブはサーバー再起動後に中断と表示し、過去の完成物を保持する。

## 現在の制限

3Dモデル・ステージ・動作・カメラ・字幕を含む配置は、その内容を黙って欠落させないよう拒否する。動画内音声も独立音声と混同せず拒否する。素材長を超える配置も拒否する。WebM/OGV等の実デコードは未検証。ブラウザプレビューの時刻精度とレンダーの画素一致、音声同期差が全区間で1フレーム以内かは未検証。オフスクリーン3D描画、透過連番、全codec、MCP、Linux、長尺実素材、明示置換と旧版退避は未接続または未検証。したがってRENDER-001/004/006と最短制作経路全体は完成扱いにしない。
