# v0.5素材一覧の実データ接続（Issue #37 / #63）

更新日：2026-10-23。対象要件：DATA-001/008/016。`/studio/v05/index.html`の素材画面と既存登録APIを接続する段階の記録。機能台帳の完了判定は変更しない。

## 今回接続した範囲

- 固定の見本13件を素材一覧から外し、`GET /api/assets`の登録情報と`GET /api/studio/v05/assets`の分類をIDで結合する。検索、分類、並び替え、登録元、形式、容量、利用状態を実データで表示する。APIが失敗したときはエラーを出し、見本には戻さない。
- 既存の登録済み画像を原本配信URLで表示し、保存済みサムネイルがあれば使用する。音声・動画はブラウザ標準の再生要素で開く。画像形式のエフェクト素材も画像として表示する。
- 新分類のGLBステージ・小物、画像、音声、動画、エフェクト素材を既存の`POST /api/library-assets/upload`へ送る。クライアントでも分類・拡張子・容量を確認し、サーバー側の署名検査と重複判定を維持する。結果と失敗理由を詳細欄に残す。
- 素材詳細のボタンから既存のv0.5タイムライン選択へ実IDを渡す。配置保存は既存の`/api/studio/v05/arrangement/place`を使う。モデル・モーションには`actual-motion-ui-v22.js`で3D実描画を明示起動して接続する既存経路がある。今回の追加試験は登録済みGLBを作品のモデルとして保存・表示・再読込した範囲に限る。各素材の再生可否を配置成功から推定しない。
- 作品トップの素材件数を取得結果に合わせる。未測定の工程進捗の固定数字は表示しない。

## 未接続と既知の操作障害

- PMX/VRM/FBX/VMD/GLB動作のv0.5画面からの直接登録は未接続。既存の素材取込画面への案内を残す。3D回転見本、お気に入り、専用波形、動画ポスターのこの詳細欄への接続も未完了。既存の旧画面の機能を削らない。
- PNGのタイムライン配置は保存済みデータの確認まで。音声・動画配置の実再生は未接続。モデル・モーションの既存3D実描画経路は明示起動、対応形式と対象モデルの指定が必要で、今回確認したのは小型GLBのモデル表示のみ。PMX・FBX・VMDを組み合わせたダンス実動作と最終書き出しまでの通し条件は未達。
- 画面共通の固定診断パネル`#v42-focus-scan`（`focus-live-scan-v42.js`、`z-index:1000`）が、1280×720で素材詳細の選択ボタンを覆う。1440×900でも下部右側、390px幅では素材一覧の大部分と重なる。ポインタ操作の受け入れ条件は不合格。Ownerのレイアウト承認待ちのため、配置CSSは今回変更しない。提案は診断を撮影画面内の折りたたみ領域へ移し、他画面では非表示にすること。
