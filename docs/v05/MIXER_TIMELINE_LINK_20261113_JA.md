# ミキサーとタイムラインの実トラック連動（追加Owner指定）

Owner報告：現在のミキサーがタイムラインと連動していない。PR #298の処理は種類別バスで、タイムラインの行名・素材名・再生位置と画面の対応が不足している。単なるバス名変更で済ませず、実際の行ID・ミュート・音量/VST処理・共通時計を接続する。AUDIO-002 / DATA-002 / UX-006、Issue #69/#63。

## 実装内容

- 安定した `audio:N` / `music:N` / `video:N` の行IDを使い、保存済みtrack-layoutの名前とarrangementの素材名・元区間を表示する。バス設定は高度設定に保持し、既存データと音を失わない。
- 行ごとの音量・ソロ・VST設定を作品別に保存する。従来の3種類のバス＋masterの保存は後方互換で保持する。
- 行ミュートはタイムラインの保存設定を正本として両画面から同じAPIで扱い、既存の種類全体ミュートも保持する。二重保存して表示だけ同期させない。
- 行の混音→行VST/音量→種類別バス→masterの順で処理する。同じ処理後PCMを共通時刻の作品再生とMP4へ使う。
- ミキサーの再生・一時停止・シークは作品プレビューの時計を使い、独立した音声プレイヤーの時刻へ分岐させない。
- 行追加/削除/名称変更/素材配置/Undo/再読込、複数行の音量・ミュート・ソロ・VST、保存中の作品切替、MP4を隔離検証する。

## 保持する未完作業

実動作プレビューのヘッダー圧縮はPR #301でmainへ統合済み。モデル・カメラ・動き/表情をタイムラインから既存GPU/VMD/モーフ評価へ結ぶ作業は引き続き未完。今回の音声行連動とは区別する。

## 操作と互換性

ミキサーの名前はタイムラインの行名、入力ボタンはその行の素材名。入力ボタンからタイムラインの配置位置へ移動できる。「タイムライン再生」「一時停止」「停止」「再生位置（F）」は作品プレビューの同じ時計を使う。処理の有効化と保存は作品ごとに保持する。

Mはタイムラインと同じ `muted_lanes` を即保存。音量・S・VSTは「作品へ保存」で反映する。「変更を戻す」は後者が対象。種類全体のミュート中は理由を可視表示し、解除設定へ移動できる。旧3種類のバスと独立音声試聴は「種類別バス」に保持。旧クライアントがバスだけ保存しても行設定を失わない。空行・削除済み行の保持設定は実処理しないため、未使用VSTの欠落で作品全体を停止しない。
