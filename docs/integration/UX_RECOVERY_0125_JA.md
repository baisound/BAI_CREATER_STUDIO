# v0.12.5 UI復旧と実機課題

## 確認した不具合
- PMX/VMDペインが非表示のFBXインポートペイン内に誤ってネストされており、タブを押しても表示不可だった。閉じタグを追加して兄弟ペインに変更。
- コンビネーション一覧が長い設定の末尾に配置されていた。編集一覧を上部へ移動。
- チェイン再生の停止操作がなかった。停止ボタンを新設。
- 制作保存と読み込みが折りたたまれておらず見つけにくかった。操作を固定領域に移動。
- GLB/VRMは227件のカタログ定義すべてが再生可能ではない。原本参照のあるものだけを区別。

## 未検証・残課題
- ブラウザでの実レンダリング、各PMX/GLB/VRMとVMD再生は環境依存。
- 統合GLBの既存FBX専用コンビネーションへの追加は未対応。
- 操作導線の本格再設計とWebMCP/標準MCPの追加操作対応は別途必要。
- PMXテクスチャの階層付き相対パスや外部依存のローダーは引き続き要検証。

## 受入テスト
1. PMXタブのクリックでファイル入力が可視になる。
2. コンビネーション編集一覧が上部に表示されスクロールする。
3. 再生ボタン後に停止ボタンでチェイン状態がfalseになる。
4. 保存と読み込みボタンがスクロールせずに使える。
5. お気に入りの保存場所は左上「★お気に入り」と表示。
