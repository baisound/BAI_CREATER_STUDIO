# v0.14.6 3Dプレビュー操作改善

## 概要
統合素材（GLB/VRM）の3Dプレビューに、シークバーと3画面カメラの独立操作を追加した。既存のFBX/PMX/VMD再生コードは保持。

## 操作
- アニメーション入りGLBを選び「▶ 再生」。同じボタンか「■ 停止」で停止する。
- 「再生位置」スライダーでタイムライン上の時刻へ移動する。
- 3視点ONの場合、各視点の中でドラッグすると対応するカメラだけが回転する。
- 「カメラ：独立操作」から「カメラ：全画面同期」に切り替えると3視点へ同量のドラッグ・ズーム操作を適用する。
- 「カメラを初期位置へ」で正面・側面・斜めへ戻す。

## 内部設計
- 3つのPerspectiveCameraと3つのターゲットを保持し、描画時のビューポート番号からカメラを選択。
- 同一canvas上でpointerdown位置から操作対象を決定。wheel操作も同じ区画へ適用。
- アニメーションは既存AnimationMixerの時間を明示してシーク。
- 手動UIからの操作はAI/外部MCP接続を必要としない。

## 未完了・注意
- ブラウザ上の3D描画・マウス操作・PMX/VMDの再生品質は未実機検証。
- 転写モーションの再生状態によってシーク表示が異なる可能性があるため、実ブラウザで検証する。
- 標準MCP・WebMCPは既存のプレビュー操作機能を維持。新規の独立カメラ操作とシークの専用MCPツール追加は未対応（共通API化が必要）。
- 音声/動画録画や物理演算のフレーム正確なシークは本版の対象外。

## 確認手順
1. GLBアニメーションを3Dプレビューで開き、再生と停止。
2. 停止後スライダーで先・後の時刻へ移動。
3. 3視点ONで右のビューをドラッグし、左のビューが変わらないか確認。
4. 同期モードに切り替え、右のビューをドラッグし、3ビューが反応するか確認。
5. カメラリセットと、転写後の3画面同期再生を確認。
6. 既存のコンビネーション・お気に入り・素材再利用機能を回帰確認。
