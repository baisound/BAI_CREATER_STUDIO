# Phase 00 Stage 4 — 試験的GLB→VRMボーン転写・同期比較

## 概要
- 統合素材からアニメーション入りGLBを選び、登録VRMを転写先として選択。
- 共有される人型ボーン名に限定し、クォータニオン回転トラックを相対回転として対応付ける**試験的**処理。対応ボーン4件未満なら中止。
- 左=元GLB、中=転写VRM、右=同時表示。各フレームの共通再生時刻でアニメーションを評価。
- 元のGLB/VRMは編集せず、VMD/GLB書き出しもまだ行わない。

## 本質的な制約
VRMにはHumanoid定義（VRM 0.x / 1.0）が含まれる場合がある。対応表はそれを優先し、取得できなければ英語ボーン名から限定的に推測する。GLBソースは同名エイリアスに依存するため、規格外の骨格は転写できない。基準姿勢・ボーンローカル軸・骨長・ルートモーション・IK・足接地・衣装物理・表情は正確に補正できない。同期比較は視覚確認の補助であり、変換品質の保証ではない。

## 手動・AI操作
- 手動UI：「統合素材」→GLBの「3D確認」→転写先VRM選択→「VRMへ仮転写」。
- WebMCP: `mixamo_integrated_retarget(asset,target)`、前段の`mixamo_integrated_preview`。
- 標準MCP: `mixamo_integrated_retarget(asset,target)`、HTTP同期コマンドでブラウザへ依頼。ブラウザが開いていない場合は実行されない。
- 名前は登録済みアセットのみ。上書き処理は行わない。

## 検証
Python・JSの構文検査、既存ユニットテスト、登録済み素材のAPI整合性を実施。実ブラウザでのGLB→VRM転写品質は繰り越し。
