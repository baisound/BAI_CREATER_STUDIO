# Phase 00 第2段階 — 安全な素材統合

## 実装範囲
- 20261015_v02からモーション定義 **227件** とモデル **3件** を共通カタログへ移植。
- 実アセットは **15ファイル** のみ移植（GLB9、FBX3、VRM3）。SHA256を計算して原本のバイト列を保持。
- UIに「統合素材」タブを設置。検索・カテゴリ絞り込み・原本取得。メニューのスクロールと説明を備える。
- API: `GET /api/integrated-v02/catalog`, `GET /api/integrated-v02/asset/<filename>`。後者はカタログに記載されたファイル名だけを許可。
- WebMCP: `mixamo_integrated_v02_search`, `mixamo_integrated_v02_models`（読み取り専用）。標準MCPの実行ハンドラーも実装。

## 移植しなかった内容
監査用ZIP、スクリーンショット、絶対パスを含む個別ユーザープロジェクト、node.exe、重複Node依存、古いログ・仮出力。元の添付ZIPは削除しない。原本から再移植可能。

## 未実装・繰り越し
GLB/VRMの実再生・FBXからの転写、三画面比較、Kip Upを含む接地精度、VMD品質検証は未実装。WebGL/PMXの実機検証は次工程へ持ち越す。標準MCPのツール一覧公開は次工程で実施（現段階は実行ハンドラーのみ）。

## 共通化指針
全画面統合ではなく、タブで目的を分離。原本ライブラリを単一レジストリに統合した後、リターゲットエンジン・QAを段階移植する。
