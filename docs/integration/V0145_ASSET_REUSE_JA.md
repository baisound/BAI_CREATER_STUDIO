# v0.14.5 共通素材の再利用改善

## 対象
- `/api/assets` の共通素材一覧を使ったPMX/VMDの直接選択・表示
- PMXを素材一覧で押すと、登録スロットA/Bへ `loadPmx` を呼び出して表示
- VMDを押すと該当VMDを既存の選択欄で選択。再生にはPMXの読み込みが必要
- GLB/VRM登録・PMX/VMD登録の成功時は `studio:asset-imported` を通知し、一覧を再取得

## 既知の制約
- FBXの共通素材一覧選択は専用制作タブへの切り替えのみ。個々のFBXへの直接モーション適用は未実装
- PMX ZIPの入出力経路は既存方式を保持。完全なバックエンド統合は未完了
- UI/標準MCP/WebMCPで共通素材一覧取得は対応。PMX直接選択のMCP操作は未対応
- 実ブラウザでの3D描画、テクスチャ、再生は未検証

## 受け入れ試験
1. PMX ZIPをA/Bへ登録後、素材一覧に現れること
2. PMX素材を選ぶと該当スロットで表示されること
3. VMD素材を選ぶと選択欄に反映されること
4. GLB/VRMを登録すると素材一覧が手動更新なしで増えること
5. コンビネーション・お気に入り・診断ログが従来通り動作すること
6. 上記のうち実ブラウザの3D描画はユーザー環境で追加検証すること
