# BAI Creator Studio / Motion Studio — 時系列統合設計書

文書版: 2026-10-18 第1次統合。出典・不明点は `REVIEW_SCOPE_AND_CHECKPOINT_JA.md` を参照。

## A. 判断の効力と設計原則（確定）

1. **人がUIだけで完結**する。AIは追加の操作手段であり必須ではない。用途別ワークスペース・目的別タブ、固定ヘッダー/操作エリアと各ペイン内部スクロール、注釈、ホバー説明、明確な空状態を採用。1画面への全機能詰め込みは禁止。
2. **同等操作**: UI・バックエンドAPI・WebMCP・標準MCP（Codex/Claude Code）・仕様・テストは機能追加時にセットで設計。全操作をAIからも実行可能にし、MCPのみの機能を作らない。
3. **非破壊編集**: 原本のFBX/VRM/PMX/VMD/GLB等を変更せず、クリップ、ポーズ補正、カメラキー、エフェクトをプロジェクト側で記録。操作はUndo/Redo、保存・再読み込み、検証可能。
4. **検証の区別**: 文書、テスト追加、試作、実データ検証、ユーザーが触れる完成状態は別。検証していないのに完成と報告しない。
5. **進行優先順位**: Bの残課題を維持しつつ E → F → リップシンク/表情/MMDエフェクト → C → D → G → H。番号は厳密な締切や完全順序を示さず、ユーザーの後発指示を優先。

## C. コンポーネント境界と共有サービス

- **Asset Library**: FBX/VRM/PMX/GLB/VMD/動画/音声/背景の登録、素材ID、参照関係。元データを変更しない。
- **Scene/Actor**: 登録モデルを配置・表示。複数ダンサー、カメラ、ライト、ステージが参照する。モデル骨格と表情モーフの機能有無は個別に表示。
- **Motion/Retarget**: 役割ベースのマッピング、レスト変換、モーション補間、足接地/IK/再生QA。検査用プレビューと適用を明示的に分離。
- **Timeline/Sequencer**: 共通FPS、尺、現在時刻、クリップ、骨補正、Camera、Lens、表情、音声、FX、字幕トラック。フレームの整数値と再生時間を別管理し、300フレームに固定しない。
- **Camera**: Viewport自由視点は撮影キーを変更しない。撮影視点はSceneモデルの位置・アニメーションと同期。シネマティック制御、区間補間、VMD入出力、レンズ/DOFはカメラ固有トラック。
- **Render/Export**: 出力解像度/FPS、背景色・透過、FFmpeg/高品質連番、ジョブ履歴、尺/フレーム数/alpha/映像品質を検査。編集ソフト向けのメディア＋プロジェクト情報は明示された交換契約を使用。
- **Expression/Audio/Effects**: リップシンク、表情、音楽同期、MMD FX相当、JIZURA/リリックをレイヤーで合成。互換対象と近似実装を区別し、再生とレンダリングの一致を検査。
- **Interface**: 手動UI、HTTP API、WebMCP、標準MCPは共通のサービス・権限・検証・トランザクションを利用。

## D. カメラ詳細設計（正本への参照）

**正本:** `docs/camera/BAI_CAMERA_INTERACTION_DESIGN_V1_JA.md` (`a463199`)。この時系列文書はカメラ入力の詳細を重複管理しない。

撮影の Pan=その場左右首振り、Tilt=上下首振り、Dolly=光軸前後移動、Truck=左右並進、Crane/Pedestal=上下並進、Orbit=注視中心周回、Zoom=焦点距離変更。旧実装の`pan`はTruck相当なので互換レイヤーを維持。隣接キー間の補間がカメラ移動プリセットより優先、未指定ならLinear。35mm/80mmなど焦点距離とF値の組合せに分かりやすいラベル。カスタム登録/利用を可能にする。実モデルが表示できない場合は原因と読み込み導線を表示。
