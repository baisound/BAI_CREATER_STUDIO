Mixamo格闘ビューワー（ローカル保存対応）

1. ZIPをすべて展開します。
2. WindowsにPython 3.9以上がなければインストールします。
3. 「起動.bat」をダブルクリックします。
4. ブラウザーで http://127.0.0.1:8765/ を開きます。
5. Mixamo FBXをインポートすると、同じフォルダーの data/files に自動保存されます。次回からは起動するだけで復元します。
6. モーションの手動対応表も data/manifest.json に保存されます。

注意：
・3DのThree.jsはCDN経由のため、初回を含めインターネット接続が必要です。FBX自体は外部に送信されません。
・data フォルダーを削除すると保存したFBXと割当情報が失われます。
・FBX本体は同梱していません。ご自身でMixamoから取得してください。
・サーバーは127.0.0.1（自分のPC）だけに公開します。
・モーション同士の連結やボーン適合は簡易対応であり、完全なレタゲットではありません。
・停止するときはBATから開いたコマンド画面で Ctrl+C を押します。
