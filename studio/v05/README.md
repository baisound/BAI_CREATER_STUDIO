# BAI Creator Studio UI Mock v0.5

設計書 `BAI_Creator_Studio_AI_Design_Spec_v05` に沿う操作可能なHTML試作。

## 起動
`start_server.bat` をダブルクリックしてローカルHTTPサーバーを起動（Pythonが必要）。`http://localhost:8000/` を開く。

## 画面
ホーム、ダッシュボード、プロジェクト一覧、専用素材管理、統合3D・映像編集（v0.4を維持）、動き・表情、カメラ・演出、音声編集、書き出し、設定。

## モックで可能
作品作成・検索・選択、素材カテゴリAND検索、お気に入り、音声ミキサーのフェーダー・M/S、構図補助線・セーフエリア、レンダーキューの試作、JSONによる作品リストUI状態の保存・読み込み、v0.4のトラック編集・上下移動・縮尺操作。

## 制約
3Dエンジン、VRM/VMD再生、VSTホスト、実録音、レンダリングは未接続。JSON保存は製品版プロジェクトデータではなくモックの一部状態のみ。ワークスペース保存も部分的。画面テキストの翻訳JSON管理はv0.4を踏襲し、新設画面の一部は日本語仮ラベルです。
