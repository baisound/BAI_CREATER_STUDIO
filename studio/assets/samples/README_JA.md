# 仮の画像（サンプル）

新UIモックで「完成するとこう見える」を示すための仮画像です。実データではありません。

- 出どころ：オーナー提供の25画面デザイン参考画像（引き継ぎ資料 `06_REFERENCE/images/`）から小さく切り出したもの。
- 加工：AIっぽい青紫〜マゼンタの色味だけ彩度を下げています。WebP・合計約0.55MB。
- 画面上では必ず「サンプル画像」と表示します。
- 本物の素材サムネイル（MOTION-016）が実装されたら置き換えて削除します。
- 再生成：`python tools/crop_sample_images.py <参考画像フォルダー> studio/assets/samples`（参考画像そのものはリポジトリに含めません）。
